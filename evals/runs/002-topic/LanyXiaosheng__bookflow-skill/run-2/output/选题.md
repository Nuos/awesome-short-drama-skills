## 一、一句话卖点

**婆家把她的嫁妆抬进当铺，想换钱给世子娶平妻。他们不知道，柜台后面验货压价的那个人就是她。京城最大当铺的东家，攥着整个侯府的当票。**

## 二、选题说明

### 1. 题材

| 项 | 内容 |
| --- | --- |
| 主分类 | 古代言情 |
| 情节标签 | 宅斗、打脸、隐藏身份（掉马）、和离、追妻火葬场、经商 |
| 赛道归属 | 古言宅斗打脸，可升级成「改编向中篇」 |
| 背景 | 架空朝代，京城侯府 + 当铺两条线 |
| 基调 | 爽文。女主不受虐，从第一场戏起就是她在压价 |

**标题变体**

- A 直白爽点型：侯府当掉我的嫁妆那天，掌柜跪下叫我东家
- B 悬念留口型：全京城的当票都在我手里，包括我夫君那张
- C 场景直击型：柜台三尺高，侯府老夫人踮着脚求我收当

**定稿：网文标题用 A**，它的冲突、身份和反常识动作三件事一眼都能看到。**短剧剧名用 B**，它更短，悬念也更足。C 用来做导语和投流素材的画面。

### 2. 写给谁看

- **核心读者**：女频读者，25–45 岁，平时看番茄免费短篇和竖屏短剧，爱看婆媳矛盾、渣夫、宅斗打脸、隐藏大佬掉马。
- **情绪需求**：「被婆家当外人、被嫌出身穷」这种憋屈很多人都有。这本书给的回报是一种具体的爽：**经济上我比你们全家都硬**，翻身靠钱和规矩，不靠男人。
- **次要读者**：爱看鉴宝、捡漏、商战的读者。当铺验货这套「专业爽」能把他们也吸进来。

> 以上是根据赛道经验做的读者假设，还没有平台数据支撑，发布后要靠 24h/72h/7d 的数据来验证。

### 3. 主角和对手

**女主｜孟昭**

- 明面：孤女，外祖父生前跟侯府订过婚约，靠这个嫁成世子夫人。嫁妆就几箱「俗物」，侯府上下都看不起她。
- 暗里：外祖父是京城老字号「万通当」的大朝奉，铺子连同城中三家分号都留给了她。外人只知道万通当有个从不露面的东家。
- 能力：眼毒，会验货，懂当铺规矩。为人讲规矩不讲情面，记账一笔一笔，记仇也一样。
- 欲望：拿回自己的东西，体面地和离，把万通当从幕后挂到明面，写上自己的名字。
- 恐惧和软肋：外祖父的死跟一笔旧当有关，她一直没查清楚。这条留作中长篇的暗线。

**对手阶梯（一层压一层，每层都对应一张当票）**

| 层级 | 对手 | 他们的秘密（女主手里的当票） |
| --- | --- | --- |
| 1 | 婆母 侯夫人秦氏 | 侯府早就外强中干，靠偷偷典当祖产撑门面 |
| 2 | 表小姐 韦絮儿（要进门的平妻） | 拿来充门面的头面是赝品，还当过偷来的东西 |
| 3 | 世子 周慎行（丈夫） | 欠了赌债，私下当掉了御赐之物，这是能抄家的罪 |
| 4 | 老侯爷 | 侯府地契早就押出去了，爵位体面全靠借来的钱撑着 |
| 5 | 聚宝钱庄东家及其背后的户部官员 | 放印子钱、做假账、想吞并万通当，牵出外祖父的死因 |

**男主｜霍临**：每月初一来当同一块玉佩、月底准时赎回的神秘客人，真实身份是皇城司里查户部贪墨案的官员。他在感情线里不当救世主：他手里有官面上的线索，她手里有当票账，两人靠交换信息结盟。
- 短篇阶段：只露面三次，留个钩子，不展开感情线，保证短篇的主线始终是女主和侯府算账。
- 中篇和短剧阶段：从第 4 层对手开始升为正式男主，先合作、后相爱。

### 4. 核心冲突

**侯府想吸干她，可侯府的命脉全押在她的柜台上。**

- 侯府要的东西：拿她的嫁妆换聘礼娶平妻，事后再把她「病逝」掉，吞她的财产。
- 她要的东西：拿回嫁妆，和离，让侯府按当铺规矩还债。
- 冲突为什么锋利：对手每伸一次手要钱，就得把秘密送到她柜台上。他们越想压她，她手里的筹码就越多。

### 5. 开篇钩子

**开局死局**：大婚刚满一年。侯府要在三天后迎表小姐进门做平妻，聘礼钱不够，婆母做主把她的嫁妆抬去当铺换现银。

**反杀动作**：嫁妆进了万通当，坐在高柜台后验货的正是她。她隔着纱帘，按当铺老规矩一件一件往低里压：

> 「虫吃鼠咬，光板没毛，破旧凤钗一支，当银三两。」

婆母急着要钱，只能认。当票一落笔，侯府就在她账上欠下了第一笔。

**开篇钩子句（前 200 字要落地的意思）**：

> 婆母把我的嫁妆抬进当铺时，不知道柜台后头验货的人是我。

**短剧第 1 集冷开场**：高柜台从低往上拍，婆母踮脚递东西，纱帘后伸出一只手按住凤钗。镜头切到女主脸上，她面无表情地报价。集尾：掌柜送走侯府的人，回身跪下：「东家，这单收不收？」女主：「收。死当。」

整个开局正好对上模板「惨境先上桌 → 恶人立刻出现 → 女主马上掀桌」，不过有一处差异：**掀桌是悄悄掀的，读者先知道，对手还蒙在鼓里**。这层信息差就是后面一连串掉马戏能拉住人的原因。

### 6. 爽点从哪来

1. **身份差掉马，分四次掉**：先让侯府丫鬟撞见，再到平妻起疑，再到世子当面认出，最后满京城公开挂牌。每一次都是一个强卡点，短剧可以直接放付费点。
2. **信息差**：当票就是一本京城秘密账。谁家空了、谁偷了东西、谁当了御赐之物，她全都知道。
3. **专业爽**：验货、辨真假、压价、捡漏。三句台词就能打完一次脸，画面也直观，适合竖屏。
4. **规则爽**：当期、利息、死当、绝卖，对手是被自己签过字的规矩打败的。女主赢在合法合规，不靠暴力，审核风险也低。
5. **火葬场**：世子最后发现，他嫌弃的穷媳妇养着整个侯府。他最后一次来当铺，当的是侯府牌匾，女主在当票上写「死当」。

**可复制的爽点单元**：一件当品 = 一个人的秘密 = 一次打脸。这个单元能一直续下去，是篇幅撑得住的关键。

### 7. 打算写多长、为什么撑得住

**分两步走：先用短篇测题，数据好再升级。**

| 形态 | 篇幅 | 覆盖内容 |
| --- | --- | --- |
| 网文·番茄短篇（首发测题） | 约 1.2–2 万字，8–12 章 | 对手阶梯 1–3 层：嫁妆当铺 → 平妻赝品 → 世子御赐当票 → 和离 |
| 网文·中篇（升级） | 约 8–10 万字 | 加第 4–5 层：侯府地契清算 + 钱庄商战 + 外祖父旧案 + 感情线 |
| 竖屏短剧 | 约 60–80 集，每集 1–2 分钟 | 短篇内容约等于前 25–30 集，中篇覆盖全剧 |

> 字数门槛、短剧集数和付费点位置都是行业常见做法和个人规划，不是平台承诺。发布和改编前要以平台当前规则为准。

**为什么撑得住：**

1. **引擎能续**：爽点不靠一次性的大反转，靠「当品单元」循环。每 3–5 集或每 1–2 章结一个小单元，本单元的打脸就地兑现。
2. **对手有阶梯**：五层对手一层比一层高，从后宅一路打到朝堂，每升一层赌注都变大，不会在原地反复虐同一个人。
3. **掉马分级**：身份一层一层揭开，不会第 3 集就把底牌全亮完。
4. **有暗线兜底**：外祖父的死因是贯穿全书的悬念，到中长篇阶段接得住，防止写到后段只剩打脸。
5. **短剧好拍**：主场景集中在当铺正堂（高柜台是标志性画面）、侯府正厅、后宅、街市四处。人物关系简单，单集冲突靠台词和道具（当票、凤钗、牌匾）就能完成，制作上可控。
