# 选题 · 《这份人情，我收回了》

## 一、一句话卖点

被全家吸血二十八年的长女，突然能看见所有人欠她的"人情红线"——只要说一句"这份人情，我收回了"，她给出去的东西就会原样回到她身上；代价是每收回一笔，她就再也不会心疼那个人。

---

## 二、选题说明

### 1. 题材

- **主引擎：** 家庭偏心 / 追悔莫及（女频家庭逆袭）
- **辅引擎 A（升级机制）：** 轻系统流——一本会自己记账的红色"人情簿"
- **辅引擎 B（世界新鲜度）：** 县城红白事"记账先生"的民俗传承
- **体量定位：** 都市现实 + 一个规则清楚的轻奇幻设定。不修仙、不重生、不霸总代打。

为什么选这条：逆袭/复仇、都市情感、家庭伦理、打脸这几类，在 2025 年的行业报告里都排得很靠前（中国网络视听协会《微短剧行业发展白皮书（2025）》、DataEye 2025 微短剧报告）。但"扶弟魔长女翻身"的同类作品已经很多，几乎都写成一个套路：受辱 → 断亲 → 对方后悔。这个选题把"人情债"直接做成能看见、能收回的规则，并且给收回加了代价，所以每次断亲都是要付代价的选择，不是白拿的爽。

### 2. 写给谁看

- **核心读者 / 观众：** 25–45 岁女性，尤其是家里的长女、被要求"懂事"的人、在婚恋或职场里一直付出却被当成理所当然的人。
- **扩展人群：** 县城和下沉市场的家庭观众。份子钱、人情簿、"你是姐姐要让着弟弟"这些都是不用解释就懂的东西。
- **情绪需求：** 不只是"打脸"，是"把我给出去的拿回来"。观众爽的是**清算**，不是靠更有权势的男人撑腰。

### 3. 主角和对手

**主角：许青禾，28 岁，省城设计公司的资深设计师，家里的长女。**

- 表面身份：一个省吃俭用的"老实姐姐"。给弟弟交了七年学费，托关系帮他找了工作，自己攒首付买的婚房马上要被家里拿去给弟弟当婚房。
- 隐藏的牌：外婆是镇上最后一位红白事"记账先生"，留给她一本红色人情簿。弟弟婚礼那天，人情簿认了主。从此她手腕上缠满红线，连着每一个欠她人情的人，线越粗欠得越多。
- 欲望：拿回属于自己的东西，第一次为自己活。
- 恐惧 / 错误信念："只要我付出得够多，他们就会爱我。"
- 为什么不能一口气全收：
  1. 每收一笔，她对这个人的感情就被抽干，记得发生过什么，但再也不会心疼。最粗的那根线连着她妈。
  2. 人情簿只认她**心甘情愿给出去**的东西。被偷、被抢、被骗走的不算人情，那些仇只能靠证据和脑子去讨。
  3. 她自己身上也有别人系来的线。她也欠着别人。

**对手阶梯（每升一级，难题的性质都变）：**

| 层级 | 对手 | 难点 |
|---|---|---|
| E1 近身吸血者 | 弟弟许嘉豪、弟媳一家 | 直接、贪心，但他们拿走的全是她心甘情愿给的，所以收得回来 |
| E2 情感守门人 | 母亲王秀芬 | 不是坏人：她自己就是被"养儿防老"这一套养大的。收不收她这一笔，是整季最大的悬念 |
| E2' 职场守门人 | 前男友 / 上司陆峥 | 用她的方案升职。一半是她当年甘愿让出去的（能收），一半是他偷的（收不了，得靠证据） |
| E3 组织权力 | 老家的宗族和人情网 | 用"孝道""规矩"联手压她，能改变整个县城的舆论和规则 |
| E4/E5 镜像敌人 | 县城首善周怀仁 | 另一个持账人。三十年来到处施恩、放"人情贷"，整个县城都欠他。他懂规则，从不收她任何东西；当年她家渡过的难关，也是他设计的，好让她家欠他一份大人情 |

周怀仁是许青禾的镜像：她付出是因为爱，他付出是为了投资。她怕自己收到最后变得谁都不爱，而他已经是那个样子了。

### 4. 核心冲突

- **外在：** 家人、职场、宗族、周怀仁一层层压她，要她继续当那个"懂事的人"。周怀仁手里还捏着系在她和她妈身上的线，随时可以反向收账。
- **人际：** 每收一笔就断一份感情。弟弟后悔了、哭着喊"姐"，她已经不心疼了。追悔莫及在这里是真的回不去。
- **内在：** 她要讨回所有欠她的东西，可讨完之后，她还剩下谁？她还能不能再爱人？
- **季问题：** 许青禾会不会收回妈妈那一笔？她能不能在不变成第二个周怀仁的前提下，扳倒整个人情网？

### 5. 开篇钩子

**第一集冷开场（竖屏前 3 秒）：** 弟弟婚礼，司仪笑着请"最伟大的姐姐"上台。台上，妈妈当着三百桌宾客把一张房产过户协议塞进她手里："你是姐姐，你的就是他的。签了。"

- 她低头，看见手腕上缠满红线，连着台下的每一个人，最粗的一根连着台上的弟弟。
- 弟弟催她："姐，快签啊，大家都看着呢。"
- 她把协议撕成两半，对着话筒说："这份人情，我收回了。"
- 红线"啪"地绷断。弟弟手机响了，是她当年托关系帮他进的单位打来的：录用撤销。
- **集尾：** 弟弟发疯一样冲过来喊"姐"。她看着他，面无表情。手机里姐弟俩的合照，她自己那一半褪成了灰白。她发现自己是真的一点都不心疼了。下一秒，她手腕上浮出一根她从没见过的黑线，另一头连着主桌那个慈眉善目的周善人，而他正冲她微笑。

这一集一次交付了三样东西：公开受辱、规则第一次兑现、代价第一次显形。最后那根黑线把格局一下子拉到家庭之外。

### 6. 爽点从哪来

1. **收账爽（主爽点）：** 每笔人情都对应一个具体的东西，比如学费、工作、婚房首付、让出去的功劳、替人背的锅。收回时，这个东西当场、看得见地回到她身上。
2. **追悔爽：** 被收账的人记得一切，也知道自己失去了什么，可她已经不心疼了。这比"跪下认错"更狠，因为回不去。
3. **斗智爽：** 偷来、抢来的东西人情簿管不了，她得靠证据、设局、反用规则去讨。主角始终在主动做事，不靠外挂躺赢。
4. **规则对弈爽：** 周怀仁懂规则，从不接她的任何东西。她要想办法让他心甘情愿收下她的一份"人情"。这是全季最大的一局棋。
5. **清算群爽：** 季末不是她一个人收账。她要把整个县城欠周怀仁的人情一起清掉，让他三十年的人情帝国塌掉。

**爽点要克制：** 每笔收账都有代价，主角不能每集都收；收账之间的空当用证据战和布局来填。代价递进为：同事（小）→ 弟弟 → 前男友 → 舅舅和宗族 → 妈妈（季问题）→ 周怀仁那根反向线（会伤到她妈的命）。

### 7. 打算写多长、为什么撑得住

**篇幅：**

- **竖屏短剧：** 先做 3 集 pilot 验证，过了再展开首季约 60 集，每集 1–2 分钟。主投红果这类免费长连载平台，同时在抖音上做切片引流。集长和集数开拍前要按当时的平台规则再确认。
- **网文：** 女频现言约 80 万字，分 4 卷：家 → 职场 → 县城 → 周怀仁。
- 两种形态共用同一套人设、规则和"人情账单"，网文可以展开内心戏和民俗细节，短剧只抓收账和翻牌的瞬间。

**为什么撑得住：**

1. **素材可以一直续：** 她这辈子帮过的每个人都是一笔潜在的账。每个债主就是一个 3–7 集的小单元：开账 → 试探 → 收回或不收 → 代价 → 新问题。光首季就能排 8 笔大账。
2. **代价限制了外挂：** 收账会掏空她的感情，所以每一次都是选择，不会变成刷怪。越往后，账越大，人越亲，悬念越强。
3. **规则有盲区：** "只认心甘情愿给出去的"这条规则，天然把敌人分成两类：能收账的和只能斗智的。爽法不会单一。
4. **牌可以分层翻：** 能看见红线 → 能收回 → 收回的代价 / 她也欠别人 → 外婆是上一代记账人、世上不止一个持账人 → 周怀仁三十年前就布局让她家欠他 → 人情到底能不能清零（"收回"和"放下"的区别）。每一层都会让观众重新理解前面的剧情。
5. **反派会学习：** 周怀仁懂规则，会针对她调整打法：不接她的东西、拿她在乎的人当人质、反向收她的账。主角的优势会被削掉，逼着她进化。
6. **结局有得兑现：** 已经想好了主线必须兑现的东西：她拿回所有被骗被抢的东西；妈妈那根线是收还是留，由她自己做主；周怀仁的人情网被她清掉。结局还留着一个口子：人情簿还有下一任吗？

## 附：选题自检（内部评分，非平台官方标准）

| 维度 | 分（0–5） | 理由 |
|---|---:|---|
| 一眼看懂 | 5 | 婚礼逼签房产 + 手腕红线，3 秒就懂 |
| 情绪强度 | 5 | 公开羞辱 + 至亲吸血，共鸣面极广 |
| 升级跑道 | 4 | 五级对手，每级难题性质都不同 |
| 翻牌跑道 | 4 | 六层可以分段揭开 |
| 新鲜度 | 4 | "收回人情会抽干自己的感情"这个代价，加上记账先生的民俗，同类里少见 |
| AI 视觉优势 | 4 | 红线人情网、绷断回流、照片褪色、人情簿显字，真人拍特效很贵，AI 能稳定出 |
| 生产可复用 | 4 | 主场景只有婚宴厅、老宅、公司、周家祠堂，角色集中，红线特效能模板化 |
| 合规 / 版权 | 4 | 原创设定；要避开美化家暴、也不能把"断亲"写成鼓励现实中极端做法；民俗要正向呈现 |
| **总分** | **34 / 40** | 达到 ≥30 的 pilot 门槛，三项关键维度都 ≥3 |

**决策：** 可以进 pilot（3 集）。

**最大风险：**

1. 观众可能觉得"不心疼了"太冷，不够爽。缓解办法：第 2–3 集要让"不心疼"的那一刻同时是她第一次被别人真心对待的时刻，让失去感情和得到新东西同时发生。
2. "录用被撤"这类收账效果容易被质疑不合现实逻辑。要定死"回流"的边界：只回流她当年亲手给出去的那部分，并且要通过一个现实中说得通的事件发生。

**最便宜的验证方式：** 先只拍第 1 集的婚礼收账段（60–90 秒），在抖音投两版封面和标题。看三个数：完播率、评论里有没有人提"我也想收回"、要不要看下一集的意愿。
