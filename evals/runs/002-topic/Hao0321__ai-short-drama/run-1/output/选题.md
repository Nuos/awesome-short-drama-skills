# 选题 · 《失物招领》

> 状态：选题已定，可进入 Pilot（建议先写 3–5 集验证）。本文件只定选题，不含大纲与正文。
> 前提假设：用户未指定平台，按「华语国内 · 番茄类女频网文 + 抖音／红果类竖屏短剧（AI 仿真人）」做最小假设。本次未做实时榜单检索，题材饱和度判断基于经验，正式立项前可补一次 Scout 对标。

## 1. 一句话卖点

**她专门帮别人找回丢失的东西，直到发现——自己才是那件被偷走的失物。**

展开版：被豪门调包、在孤儿院长大的真千金，在地铁失物招领处当临时工。她一摸失物，就能看见它是怎么丢的。直到假千金来认领一枚长命锁，锁里那段被偷走的十秒，是她自己。

## 2. 选题说明

### 2.1 题材

| 项 | 定位 |
|---|---|
| 主引擎 | **真假千金／身份夺回**：被错置的人拿回名字、尊严和选择权 |
| 辅引擎 A（升级机制） | **技能权威打脸 + 单元案**：每件失物是一桩可验证的小案子，3–5 集结一案 |
| 辅引擎 B（新鲜变量） | **冷门职业 + 带规则的异能**：地铁失物招领处，「物件记得自己是怎么丢的」 |
| 主不对称 | **信息差**：她看得见真相，但拿不出证据 |
| 类型标签 | 女频现言 · 轻悬疑 · 真假千金 · 打脸逆袭 · 治愈单元 |

**能力的三条规矩**（新鲜度主要来自这里，也是限制外挂的硬约束）：

1. **只有「还有人真心想找回」的东西才会开口。** 被彻底放弃的东西是哑的。
2. **只能看见它离开主人那一刻，约十秒。** 丢过几次，就叠着几层；越旧的那层越深，越难读。
3. **看见不等于证明。** 她看到的只算线索，不能当证据。每读一次，她还要替物主承受一次「失去」的情绪冲击，当众失态，旁人看来就是疯子或骗子。

还有一个盲区，也是她的心结：二十四年来，没有一件跟她自己有关的东西对她开过口。她因此一直相信，这世上没人在找她。

### 2.2 写给谁看

- **核心读者／观众：** 18–40 岁女性，爱看真假千金、身份夺回、打脸，但已经看腻了「女主连挨十集虐、靠男人出头」的套路。
- **次级人群：** 喜欢单元悬疑、「每集破一个小案」的泛人群（男性观众也能进），这批人追的是「她怎么把看见的变成证据」。
- **共鸣点：** 每个人都丢过东西，也都怕过自己是「没人要的那个」。打脸给爽感，失物物归原主给泪点，两种情绪轮换，不会只剩一个调。

### 2.3 主角和对手

**主角 · 沈拾（24 岁）**

- 公开身份：澄江市地铁三号线失物招领处的外包临时工，孤儿院长大。「拾」是院长起的名，意思是捡来的。
- 隐藏真相：二十四年前在医院被调包的陆家真千金。
- 想要什么：先是保住饭碗、不被冤枉；后来想要证据，证明自己是谁；最后要弄明白当年是谁把她弄丢的，为什么。
- 为什么不能直接亮牌：能力拿不出证据，说出来没人信；对方手里握着一切能当证据的东西（亲子鉴定渠道、出生档案、监控、舆论）。
- 性格与人物弧：嘴硬，手很稳，帮别人找东西特别较真，轮到自己就不敢要。人物弧是从「我是一件没人要的东西」，走到「什么该找回、什么该放下，我自己选」。

**对手梯队**（每升一级，难题的类型跟着变，不只是敌人更强）：

| 层 | 对手 | 他让主角面对什么问题 |
|---|---|---|
| E1 近身羞辱者 | 失物招领处主管、闹事乘客、来认领失物的网红 | 日常饭碗与名誉：随时被冤枉、被开除 |
| E2 守门人 | **陆知微**，假千金，陆记珠宝的品牌门面 | 舆论与家族门槛：她不是无脑恶女，是怕失去一切的人，会学习，会反制 |
| E3 组织权力 | 陆家二房／陆记集团内部势力 | 规则与证据：能改档案、压鉴定、买通渠道 |
| E4 幕后对手 | 当年调包的策划者（身份为季中揭露项） | 知道她的能力规则，开始制造「没人想要的东西」和「假失物」来骗她 |
| E5 镜像敌人 | 另一个能读物的人，读的却是「被丢弃之物」 | 同样被丢过，选择了相反的路：不是找回，是报复 |

**盟友 · 周屿**：地铁派出所民警，只信证据。他是把她的「看见」变成「证明」的那只手，也是感情线。感情线不替她出头，只跟她合作破案。

### 2.4 核心冲突

**她看得见真相，却拿不出证据；对方拿得出「证据」，却守着一个谎。**

- 外在：一个临时工，要从百年珠宝世家手里夺回被调包的身份，对方掌握档案、鉴定和舆论。
- 人际：生母陆夫人到底知不知道调包？假千金陆知微也是被安排的人，她该恨谁？
- 内在：她不信有人在找她，所以不敢要。能力越强，她越得面对「我值不值得被找回」。

季问题：**二十四年前，是谁把她弄丢的？这些年，到底有没有人在找她？**

### 2.5 开篇钩子

第一集只证明三件事：她被压着、她有牌、命运有一件事从此改了。

1. **前 3 秒：** 网红千金陆知微开着直播，把一枚金长命锁拍在失物招领台上：「锁上的珠子被你们的人抠了。」主管当场要沈拾道歉赔钱、卷铺盖走人，直播间刷屏骂「临时工手脚不干净」。
2. **翻盘：** 沈拾一摸长命锁，周围的时间凝住。她走进十秒前的车厢回放，看清是谁、在第几节车厢、用哪只手动的手。可她看见的东西不算数，只能报出车厢、时间和动作，逼警方调监控。监控一放，全场哑火。这是第一笔爽债，当集就还。
3. **集尾钩子：** 人群散了，锁还在她掌心，却「第二次开口」了，这次是更深的一层：二十四年前的产房，一只手把这枚锁从婴儿脖子上摘下来。婴儿左腕上，有一道和沈拾一模一样的月牙形疤。

钩子成立的原因：观众在第一集就拿到了「她是真千金」的信息差，剧中人谁都不知道。于是追更的动力从「她是谁」变成「她怎么证明、谁会先发现」。

### 2.6 爽点从哪来

| 爽点来源 | 怎么兑现 | 频率 |
|---|---|---|
| **看见 → 证明的翻盘** | 每件失物都是一次可验证的打脸：她先看见，再找物证、监控或人证，当众把真相钉死 | 每个单元（3–5 集）至少一次 |
| **身份夺回的爽债** | 陆家每一次羞辱、抢功、泼脏水都记账，按「技能 → 人脉 → 证据 → 身份 → 当年真相」一层层还 | 主线，每 3–5 集还一笔 |
| **观众信息差** | 观众和她一起先看见真相，等着剧中人一个个追上来 | 全剧持续 |
| **物归原主的泪点** | 把东西还给真心想找回它的人：亡夫留下的旧手表、走失老人的公交卡。这是爽剧里少见的治愈情绪 | 与打脸单元交替 |
| **规则对抗的智斗** | 对手摸清能力规则后反制（制造假失物、让关键物证变得「没人想要」），她得用新办法破局 | 中后段主要爽点 |

### 2.7 打算写多长、为什么撑得住

**篇幅规划**

- **短剧：** 先做 5 集 Pilot 验证，过线后首季约 **60 集、每集 1–2 分钟**，大约 12 个失物单元，外加身份主线。确切集长和集数等定了平台和商业模式再调。
- **网文：** 全本约 **120–150 万字，分 4 卷**。第一卷约 30–40 万字，对应短剧第一季。

**撑得住的理由**

1. **单元供给几乎无限。** 城市里每天都有人丢东西，每件失物天然带着一个人、一段关系、一个案子。不用硬编「下一个人来骂她」。
2. **失物可以逐级升格。** 钥匙、手机 → 遗嘱、证据 → 走失的人 → 一个家族的秘密 → 她自己。东西的分量一路往上走，阶梯是从设定里长出来的。
3. **揭露可以分层。** 能力本身就是多层记忆（丢过几次就有几层），揭露天然可以切开，不会第一卷就把牌翻完。
4. **真身份揭穿后故事还在。** 回了豪门不等于被接纳；调包是谁策划的、为什么；那个读「被丢弃之物」的镜像敌人。三个大问题能撑到后两卷。
5. **反派能学习。** 能力有清楚的规则和盲区，对手摸透以后就能反制，后期是智斗，不是重复打脸。
6. **生产可复用。** 主场景固定（失物招领处、地铁车厢、陆家老宅、派出所），主要角色少而稳定，每个单元只换一件道具和一两个客串角色，AI 角色一致性好控，成本也好控。

## 3. 选题自检（Greenlight）

| 维度 | 分 | 依据 |
|---|---:|---|
| 3 秒看懂 | 4 | 「临时工被冤枉 + 一摸失物见真相」一眼懂；能力要靠第一个画面讲清楚 |
| 情绪强度 | 5 | 当众被冤偷窃 + 被弃身世，两种痛同时在场 |
| 升级跑道 | 4 | 五级对手，失物分量逐级升格 |
| 揭露跑道 | 5 | 多层记忆的设定天然支持分段揭露 |
| 新鲜度 | 4 | 失物招领职业和「只有被真心想找回的东西才开口」是新的；真假千金底盘偏饱和，扣 1 分 |
| AI 原生奇观 | 4 | 「凝固的十秒回放」：她走进静止的过去现场，真人拍摄要靠昂贵特效，AI 做得又便宜又稳 |
| 生产可复用 | 4 | 固定主场景加单元道具，角色少 |
| 合规／IP | 4 | 城市和地铁线路虚构；婴儿调包只在回忆中出现；不涉及医疗或法律建议 |
| **总分** | **34/40** | 达到 ≥30 的 pilot 门槛，关键三项都 ≥3 |

**决策：GO PILOT**

**最大风险：** 真假千金底盘同质化。如果前 3 集观众只看到「又一部真假千金」，新鲜度就会失效。对策：第一集的主画面必须是「凝固十秒」的能力奇观，真假千金信息放在集尾，作为钩子出现。

**最便宜的验证方式：** 只做第 1 集，出两个版本测前 3 秒留存和看完率。A 版开场是直播冤枉；B 版开场直接是「凝固十秒」。

**合规备注：** 不使用真实地铁运营方的名称和标识，也不用真实医院名称；发布时按平台要求加 AI 生成内容标识。
