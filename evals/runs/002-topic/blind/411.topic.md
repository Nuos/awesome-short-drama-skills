## 1. 一句话卖点

**被休三年的前妻，替前夫的新妇写和离书，两任妻子一起把他告上登闻鼓。**

---

## 2. 选题说明

### 题材

- 主分类：古代言情（架空朝代）
- 情节标签：和离 / 大女主 / 打脸 / 律法翻案
- 赛道归属：`赛道-古言重生打脸` 的近邻，不走重生，用职业能力代替预知
- 双形态：番茄短篇小说先行；竖屏短剧作为改编方向预留

### 写给谁看

- **小说**：番茄女频读者，25–45 岁为主。爱看和离、打脸、大女主，对“两个女人抢一个男人”的雌竞套路已经看腻。
- **短剧**：女频付费短剧观众。要每集都有对峙，台词能截成短视频切片，场景少、反转密。
- 读者要的情绪：**被体面地欺负过，现在体面地打回去。**

以上读者画像是按赛道经验推断的，没有平台后台数据支撑，上线后用真实数据校正。

### 主角和对手

**女主 · 褚宁，人称“褚三两”**

- 京城西市一间代书铺的掌柜，专替女子写和离书，一封只收三两银子。
- 三年前，她陪丈夫熬过寒窗，供他读书考中进士。丈夫入仕第二年，以“无子”为由一纸休书把她赶出门。
- 她就是从那张休书开始啃律书的。现在全京城的和离书，一半出自她手。
- 性格：冷静、嘴毒、算账极细；不哭，只拿条文说话。

**主要对手 · 贺允章，女主前夫**

- 新任京兆少尹，京城户婚官司归他的衙门管。
- 读书人出身，懂律法，人前体面，从不亲手做脏事。
- 休妻之后续娶钱庄独女，拿岳家的银子铺路升官。
- 他最危险的地方：**他也会用律法，而且他手里有官印。**

**次要对手**

- 贺老夫人：贺允章之母，“无子”这件事真正的经手人。
- 贺允章的上峰：一路替他压案子，最后一层保护伞（具体身份留到大纲阶段定）。

**关键盟友 · 温七娘，前夫的新妇**

- 温记钱庄独女，嫁过来一年，嫁妆被挪走大半，丈夫正盘算让她“病逝”。
- 她找上褚宁，不是来示威的，是来求救的。
- **这对关系是本题的差异化核心：前妻和新妇不争男人，联手拆他。**

### 核心冲突

**褚宁要帮温七娘和离，贺允章不肯放人，也不肯放过褚宁。**

- 和离要男方点头。贺允章不签：放了温七娘，就得吐出嫁妆，丢了钱庄这座靠山。
- 他手里有官印，能直接封掉褚宁的铺子，还能反咬她“妇人代书，挑唆人家夫妻”。
- 两个女人只剩一条路：拿到让官府**强制判离**的证据，把案子越过他的衙门，告到上面去。
- 越告越深，查出两任妻子“无子”的真相是同一个人、同一碗汤药，褚宁三年前那场休妻也要翻案。

一句话：**一个懂律法的官，对两个被他用律法踩过的女人。**

### 开篇钩子（前 300 字内完成）

按 `开头钩子模板` 的“惨境先上桌 → 恶人立刻出现 → 女主马上掀桌”：

1. **死局先上桌**：京兆府贴出告示，“妇人不得代书讼状”，褚宁的铺子三日后查封。签字的人正是她前夫。
2. **反常识来客**：同一天傍晚，一个穿金戴银的年轻妇人进门，把五十两银子推到她面前。
3. **身份炸开**：

   > 我写和离书只收三两。她放下五十两，说要和离的人，叫贺允章。
   > 那是我前夫。

4. **女主掀桌**：褚宁没有赶人，把银子推回去，只收三两：“这单我接。他封我的铺子，我拆他的家。”

钩子要立住三件事：她惨在哪（铺子要被封，前夫又一次拿律法踩她），谁在压她（贺允章），她怎么翻盘（接下前夫新妇的和离案）。

### 爽点从哪来

| 爽点来源 | 具体兑现 |
| --- | --- |
| 关系反常识 | 前妻帮新妇离开同一个男人。读者以为要看两女撕扯，结果看到两个女人联手。 |
| 专业碾压 | 每一回合都是一步“律法招”：对方出一条律，女主拆一条律。懂行的官，输给自己当年看不起的前妻。 |
| 当众打脸 | 核心名场面都放在人前：寿宴上递和离书、钱庄当众冻结贺府支银、两任妻子在登闻鼓前同时击鼓。 |
| 真相兑现 | 两任妻子都“无子”，原因是同一碗避子汤。这个揭秘放在试读 30% 卡点。 |
| 旧账清算 | 褚宁当年被休本身就违律，最后连自己的休书一起翻案。 |
| 拒绝回头 | 贺允章失势前想“复娶”前妻堵她的嘴，她当面拒绝。有追妻火葬场的味道，但不走感情线。 |

**律法支点（需人工核验）**：本题借用唐律中“七出三不去”“和离”“义绝”“登闻鼓”等制度，放进架空朝代。其中两条是关键：

- “三不去”之一“前贫贱后富贵”：妻子陪丈夫从贫贱到富贵，不得出妻。褚宁正是这种情况。
- 《唐律疏议·户婚》关于“无子”出妻的年龄限制：妻四十九岁以下无子，不应出妻。

这两条只是创作支点。**定稿口径：对外一律称“架空律法”**，简介、导语、宣传语里不出现“唐律”字样，不标榜历史考据。正文里的条文按故事需要改写成架空朝代的律条，不必逐字照搬原文。

### 打算写多长，为什么撑得住

**首版：番茄短篇，约 1.8–2.2 万字，10–12 章。**先用短篇验证题材，跑出数据再决定是否扩写。平台的字数门槛和征文要求，以发布时页面上的当前规则为准。

**为什么 2 万字撑得住：**爽点不靠一个反转，而是四轮“出招—反扑”逐级升级，每一轮的对手层级和赌注都比上一轮高：

1. **和离书**：先礼后兵，寿宴上递和离书。贺允章拒签，反手封铺。
2. **断银路**：温七娘调动钱庄，冻结贺府的支银。贺允章反咬“七出”，要先休了她，吞掉嫁妆。
3. **翻真相**：查出避子汤，这是 30% 试读卡点。褚宁的旧案和新案在这里并成一案，贺允章动用上峰压案。
4. **登闻鼓**：两任妻子越级击鼓，当众对质，判义绝，追回嫁妆，贺允章革职问罪。

每轮都有一次当众打脸，加一个更大的威胁，章尾钩子不愁。

**为什么能扩成短剧，以及后续长线：**

- **场景少**：代书铺、贺府、钱庄、公堂/登闻鼓，四个主场景就能撑起主线，拍摄成本低。
- **对白驱动**：冲突靠台词和律条对峙推进，不靠打戏和特效。1–2 分钟一集也能每集一个反击。
- **天然单元剧结构**：主案大约够 25–30 集。之后每来一个求和离的女人，就是一个新单元（8–10 集一案），主线是褚宁一路往上，翻出“妇人不得代书”背后的更大势力。小说同理，可以从短篇升级成中篇或长篇连载。
- 扩写是数据过关之后的选项，不是现在的承诺。

### 禁区与风险

- **不写雌竞**：温七娘和褚宁之间可以有试探和防备，但不能变成抢男人。
- **避子汤线**只写后果和证据，不渲染身体伤害细节，避开平台审核风险。
- **女主不开挂**：她赢靠的是律条、账目和证人，不靠突然冒出来的权贵靠山。感情线如果要加，放在角色阶段决定，且不能替她出手。
- 不使用 BookFlow 默认禁用的 AI 高频人名（林晚、苏念、顾言、陆衍、沈清等）。
