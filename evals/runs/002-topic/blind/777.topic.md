# 选题 ·《首富的良心，当在我家》

> 网文暂名：《我家当铺，子时开门》
> 本文件只定选题，不含大纲和正文。

---

## 1. 一句话卖点

**城中村废柴继承了一间快被法拍的老当铺，才发现全城首富二十年前把"良心"当在了这里，还有三十天到期：首富白天要拆他的铺子，到了夜里却得跪在柜台前求他续当。**

---

## 2. 选题说明

### 2.1 题材

- **主类型：** 都市奇幻 × 扮猪吃虎（身份、规则双重信息差）
- **辅助引擎：**
  - 倒计时复仇：三十天当期，期满良心归位，首富会自己吐出当年的罪
  - 单元奇谈：每晚来一位客人当一样东西，每个故事独立成章，又都扣在主线上
- **新鲜变量：** 当铺不收金银，收的是**看不见的东西**：才华、运气、记忆、寿数、一段感情、良心。每张当票都有赎期，到期不赎就成了死当。
- **一句话差异：** 同类"隐藏大佬"靠身份压人，这个主角手里是**规矩和当票**。他打不过任何人，只是全城有头有脸的人，都有一样东西押在他柜台后面。

### 2.2 写给谁看

| 载体 | 读者／观众 | 他们要的情绪 |
|---|---|---|
| 网文（番茄、起点都市脑洞类） | 18–35 岁男频为主，悬疑奇幻向的女频读者也能接住 | 小人物握住大人物的把柄；每章都有新奇设定 |
| 竖屏短剧（红果、抖音类，AI 仿真人或 2D 漫剧） | 下沉市场爽剧观众，以及喜欢奇幻悬疑的年轻用户 | 白天被踩、晚上反转的强对比；"他也有今天" |

核心情绪承诺只有一句：**白天看不起你的人，晚上都得来你柜台前排队。**

### 2.3 主角和对手

**主角：沈当归，24 岁，"归来当"第三代掌柜**

- **大家眼里的他：** 爷爷刚过头七，留给他一间破当铺和一身债。未婚妻退婚，邻居嫌他是钉子户，干什么都倒霉，是街坊口中的废物。
- **真实底牌：** 当铺每晚子时开门，能收无形之物。爷爷留下的账本记着这座城二十年的秘密，地下的死当库里封着上百年没人赎回的才华、记忆和寿数。
- **他想要的：** 守住铺子撑过三十天，等首富的良心归位，让他亲口说出当年对沈家做过什么。
- **他为什么不能直接亮牌（核心限制）：**
  1. **当事保密：** 掌柜一旦泄露客人当了什么，当物立刻毁掉。他不能公开揭发首富，只能设局让对方自己露馅。
  2. **不自当、不自赎：** 掌柜不能为自己典当，死当库里的能力也不能用在自己身上，只能借给别人。他本人从头到尾都是普通人。
  3. **验当有代价：** 每收一件当物，掌柜都要亲身走一遍那段记忆或痛苦，次数越多越伤人。
  4. **账本不全：** 规矩要靠一桩桩收当慢慢解锁，他是边学边打。

**对手阶梯（每一级换一种问题，不只是把数值调大）：**

| 级 | 对手 | 他带来的问题 |
|---|---|---|
| E1 | 退婚的未婚妻苏晚一家、收债的混混 | 日常羞辱、公开退婚 |
| E2 | 陆晋，首富独子 | 买下沈家债务推动法拍，用舆论和法律拆铺；他不信这套规矩 |
| E3 | 陆振海，全城首富 | 他懂规矩，白天拆铺，夜里续当，还会找规矩的漏洞反制 |
| E4 | "万象"平台的祁先生，爷爷当年逐出门的弟子 | 把典当做成 App，用户协议里藏着骗当条款，靠透支千万人的运气牟利。他是主角的镜像：同样懂规矩，选了相反的路 |
| E5 | 当铺本身 | 当铺到底在替谁收东西？（季终级真相，先留着） |

**为什么对手不直接除掉主角：** 掌柜一死，铺里所有活当立刻到期，原物归还。陆家只能走法拍拆铺这条"合法"路线，因为铺子一毁，活当就转成死当，良心永远回不来，这正是陆家想要的。这条规矩让冲突始终落在"守铺 vs 拆铺"上，不会变成武力对决。

### 2.4 核心冲突

- **外部：** 三十天倒计时。陆家要在当期结束前把当铺法拍拆掉；沈当归要守到期满、拒绝续当，让良心归位。
- **人际：** 沈当归每晚收的客人里，有白天羞辱他的人，有陆家的人，也有他在乎的人。帮谁、收谁的什么、拒绝谁，每一次都是选择。
- **内在：** 他从小倒霉，以为自己天生就是废物。真相（R4）是他自己的好运也押在这间铺子里，按规矩他赎不回来，只能等一个肯替他付代价的人。

### 2.5 开篇钩子

**短剧第 1 集／网文第 1 章：**

1. **冷开场（前 3 秒）：** 白天，法拍公告贴上门，"当"字招牌被人砸碎在地。苏晚当众把订婚戒指拍在柜台上："当了吧，就当我们没认识过。"陆晋站在她身后笑。
2. **压力：** 债主限三十天腾空铺子，街坊围观起哄，沈当归一句话都还不了嘴。
3. **转折：** 子时钟响，碎掉的招牌自己亮起来。暴雨里，白天签法拍令的首富陆振海独自走进门，在柜台前跪下："沈掌柜，我来续当。"
4. **集尾钩子：** 爷爷的账本自己翻开，墨迹浮出来——
   `当户：陆振海　当物：良心　当期：二十年　剩余：三十天`

**第一个小爽点放在第 2 集（第 2–3 章）：** 第二天白天，陆晋带人来清场。沈当归当着众人的面只说两个字："不续。"当晚陆振海失控，陆家父子当场翻脸。观众第一次看清：被踩的人手里攥着什么。

### 2.6 爽点从哪来

| 爽点来源 | 怎么兑现 | 为什么不会腻 |
|---|---|---|
| **昼夜反差** | 白天羞辱他的人，晚上来柜台前当东西、求续当 | 每次来的人和当物都不同，羞辱和回收的方式也跟着变 |
| **当票即爽债** | 每张当票都有赎期，羞辱和承诺天然带着到期日 | 回收时间写在规则里，读者能自己数日子等兑现 |
| **死当库借力** | 把百年死当（棋艺、医术、嗓子、记忆）借给被欺负的好人，让他们当场翻盘 | 借出的能力有期限、有代价，也可能被对手反收 |
| **设局逼供** | 因为当事保密，主角不能明说，只能设局让对手自己露馅 | 爽感来自智斗，不是喊口号；对手会学习，下一局得换招 |
| **揭露阶梯** | R0 招牌自亮 → R1 第一次收当 → R2 死当库、账本 → R3 沈家与陆家的旧案 → R4 主角自己的运也押在铺里 → R5 当铺替谁在收 | 一次只揭一层，每一层都改写前面的读法 |
| **情感反转** | 例如苏晚深夜来当"对沈当归的感情"，验当时他才发现她当初是被逼的 | 打脸之外还有遗憾、和解和失而复得，不只有一种情绪 |

### 2.7 打算写多长，为什么撑得住

**篇幅规划：**

| 载体 | 首轮 | 全程 |
|---|---|---|
| 网文 | 第一卷约 25 万字，正好写完三十天倒计时、良心归位 | 4 卷，约 120–150 万字，对应 E2 → E5 四级对手 |
| 竖屏短剧 | 先做 3 集 pilot 验证，通过后扩成首季 30 集，每集 60–90 秒，对应第一卷 | 按卷分季，每季独立收束一个主要对手 |

不按 80–100 集一口气铺：首季用三十天倒计时自带的密度，试出数据再续季。

**撑得住的四个理由：**

1. **单元加主线双引擎。** 每晚一位客人、一件当物，就是一个独立小故事，素材几乎取之不尽。主线有倒计时、陆家和万象平台三条线压着，保证每集都在往前推。硬规矩：**每个单元客人必须和主线有关联**，不写纯散篇。
2. **当物种类决定换题材的能力。** 才华能写职场逆袭，记忆能写情感虐，寿数能写生死抉择，嗓子和容貌能写娱乐圈。爽点形态一直在换，不会反复同一种打脸。
3. **规矩有代价、有盲区。** 主角不能自用、不能泄密，验当会伤身，外挂就不会失控，每一局都有悬念。
4. **对手会升级、也会学习。** 从不信规矩的陆晋，到钻规矩空子的陆振海，再到把规矩做成平台的祁先生，每一级都逼主角换打法。第一卷收尾时陆振海伏法，同时把"万象"推到台前，关一扇门，开一扇更大的门。

## 3. 立项评估（内部参考）

| 维度 | 分 | 依据 |
|---|---:|---|
| 一眼看懂 | 5 | "首富把良心当在我家"一句就能讲清楚 |
| 情绪强度 | 4 | 退婚、法拍、砸招牌，第一场就有羞辱 |
| 升级空间 | 4 | 五级对手，每级问题类型不同 |
| 揭露空间 | 5 | R0–R5 能分层揭，最大秘密反扣主角身世 |
| 新鲜度 | 4 | 灵异当铺本身不算新，新在"良心当期倒计时、昼夜双场、当票即爽债"的组合 |
| AI 奇观 | 4 | 夜间当铺、发光的当物、验当时走进别人的记忆，真人拍预算高，AI 能稳定出 |
| 制作复用 | 5 | 当铺内景是固定主场景，角色少而稳定，很适合资产化 |
| 合规／版权 | 4 | 全部原创；需要处理好奇幻和迷信的边界，以及法拍题材的写法 |
| **合计** | **35/40** | 决策：**推进 pilot** |

**主要风险与对策：**

- **灵异当铺是老设定。** 第 1 集必须在 60 秒内亮出"良心＋三十天"，不能靠氛围慢慢铺。
- **单元剧会拖累追更。** 每个单元结尾都必须推动一次主线倒计时或一条对手线。
- **主角不能亮牌，爽感容易被拖。** 第一个小爽点不晚于第 2 集；每 3–5 集收一笔大账。
- **平台合规。** 当铺写成架空奇幻规则，不写现实中的祭祀和法术操作；拆迁写成商业法拍纠纷，不涉及行政强拆；万象平台只写成虚构设定，不做现实网贷产品的教程或背书。

**最便宜的验证方式：** 先写网文前 3 章，并做 3 集短剧 pilot，只测一个变量："首富跪求续当"这个集尾钩子能不能带动第 2 集的点击和续看。

> 注：本选题没有查当前平台榜单。正式立项前建议做一轮榜单扫描，确认"都市奇幻＋当铺"近期的同类作品密度。
