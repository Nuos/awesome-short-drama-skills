# 选题：《封条》

## 一、一句话卖点

十三年前，陆家逼死她爸、抄了她家；十三年后，法院摇号摇中了她，派她去抄陆家。

## 二、选题说明

### 1. 题材

都市女频，大女主事业复仇爽文。

主卖线是**身份反差加权力反转**：主角从当年被抄家的人，变成手握对方全部资产处置权的人。辅线是一桩旧案翻案，感情线只做调味，不抢主线。

一句话说清读者来吃什么：**看她一张一张往仇人的东西上贴封条。**

### 2. 写给谁看

- 网文端：番茄、七猫这类免费阅读平台的女频读者，25-40 岁，爱看大女主、打脸、断亲、复仇，讨厌窝囊女主和恋爱脑。
- 短剧端：红果这类竖屏短剧的下沉女性用户。她们对“被看不起 → 亮身份 → 当场反杀”这个节拍接受度最高，耐心最短。

两端吃的是同一种爽：**对方越嚣张，她手里那张纸越硬。**

### 3. 主角和对手

**主角：姜禾，29 岁，律所合伙人，破产管理人团队负责人。**

- 16 岁那年家里的厂被陆家做局逼破产，父亲背着“欠债跳楼”的名声死了。她随母改姓，从此和过去断干净。
- 她冷静、懂规则、不吵架，擅长把对方的嚣张变成证据。她的武器是法律文书，不是拳头和金手指。
- 她的软肋：她其实该回避这个案子，但她瞒了下来。一旦身份被认出来，陆家马上就能申请她回避，她会当场出局。

**对手：陆家。**

- **陆振海**：陆氏集团实控人，当年做局的真凶。表面体面，实际在破产前早把资产转了个干净。他是终极对手。
- **陆母周曼**：前台反派，嚣张、势利、当众羞辱人。短剧里打脸最直观的靶子。
- **陆承泽**：陆家独子，姜禾小时候的娃娃亲对象。他是唯一可能认出她的人，也是身份暴露倒计时的引信。
- **苏念**：陆承泽现任未婚妻。她名下的工作室、房产是陆家藏钱的口袋之一。

**变量：季寒**，陆氏最大债权人（一家资产管理公司）的代表。当初就是他抢先申请陆氏破产，动机不明。他是盟友还是另一个猎人？这个问题留着当中段悬念。

### 4. 核心冲突

**明面上**：姜禾依法接管陆氏，陆家用尽手段藏资产、拖程序、收买、威胁、抹黑她。

**暗面上**：她必须在身份暴露之前，把能翻案的证据和被藏的资产全部锁死。一旦被认出来，她就得出局。

两条线咬在一起：她挖得越深，陆承泽离认出她越近。每一次贴封条既是爽点，也是在给自己的暴露倒计时加速。

### 5. 开篇钩子

**陆承泽订婚宴当晚，陆氏旗下的云栖酒店。**

姜禾带着两个助理从正门进，被保安往员工通道赶。陆母周曼把她当成走错门的服务员，一杯红酒泼在她的文件袋上：“哪个部门的，这么没规矩？”

姜禾抽出被泼湿的裁定书，擦了擦，递过去：

“市中院已裁定受理陆氏集团破产清算，我是指定管理人。这家酒店是陆氏资产，从现在起由我接管。”

她转身，把第一张封条贴在订婚背景板旁边的总控室门上。

满场安静。陆承泽盯着她签字的手，手背上有一道旧疤。他说：“你很像我认识的一个人。”

**前 300 字给羞辱，前 1500 字亮身份、贴封条，第一章末埋下“他快认出我了”。** 抓手、卖点、长线悬念在第一章全部到位。

### 6. 爽点从哪来

1. **当众查封**：豪车、别墅、珠宝、婚宴场地、公司公章，一样一样封。封条就是这本书的视觉符号，短剧里一贴就是一个爽点。
2. **身份反差**：陆家把她当打工的小律师，她手里握着他们每一分钱的处置权。对方越看不起她，反杀越响。
3. **信息差挖宝**：情人名下的别墅、未婚妻的空壳工作室、陆母转给娘家的股权……每挖出一笔隐匿资产，就是一次“你以为藏住了”的打脸。
4. **规则碾压**：对方掀桌子，她拿出条文；对方找关系，她把通话录音交给法院。主角不靠运气，靠的是专业。
5. **旧账翻案**：父亲当年的死因一层层翻出来。爽点从“抄你家”升级到“送你进去”。
6. **反向身份揭晓**：卷一末身份曝光，但她已经提前把父亲的遗产债权申报进了破产程序。管理人出局了，她换个身份以债权人回到谈判桌上。这是全书第一个大反转。

### 7. 打算写多长，为什么撑得住

**网文：长篇，60-90 万字，分三卷。短剧：80-100 集，每集 1-2 分钟，对应网文卷一加卷二的前半。**

撑得住的理由：

- **破产程序本身就是天然的分卷骨架**：接管 → 债权申报 → 债权人会议 → 资产追回 → 拍卖 → 刑事移送。每个环节都有一场固定的“大戏”，比如债权人会议上的对质、拍卖会上的竞价，不用硬编节点。
- **资产是分层的，对手也是分层的**：
  - 卷一：清陆氏明面资产，打陆母、苏念这层前台反派。目标是活过回避申请，锁住第一批证据。卷末身份暴露，她从管理人变成债权人。
  - 卷二：追隐匿资产和境外转移，对手升级到陆振海和他背后的人，季寒的真实立场揭晓。
  - 卷三：父亲旧案翻案，刑事追责，终局清算。
- **引擎每推进一步都有新成本**：封一笔资产，就逼出一个更狠的对手，也离身份暴露更近一步。收益和风险同时往上涨，不会变成一章清盘的短梗。
- **短剧适配**：主场景只有酒店、陆家别墅、法院、拍卖会几个，重复利用率高。“被羞辱 → 亮文书 → 贴封条”这个单元节拍天然适合 1-2 分钟一集，每集结尾都能停在下一张封条要贴到谁身上。

**不建议拉成百万字以上的超长连载**：旧案翻完、陆家清算完，主引擎就到头了，再往后只能硬开新仇人，会散。

### 8. 风险提醒

- **专业门槛**：破产法术语多，容易写成说明书。规则一律通过动作和对白落地，比如“贴封条”“冻结”“撤销转让”。每章最多解释一个规则点，解释完必须马上兑现成爽点。
- **主角违规隐瞒**：她瞒着回避义务，道德上有灰度。要给她一个站得住的理由：案子是随机摇号摇来的，不是她争来的；她也从没做过一笔假账。这层灰度正好在卷一末身份曝光时引爆，变成戏剧张力，不要回避。
