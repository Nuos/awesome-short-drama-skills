# 选题：《冷静期》

> 备选名：《离婚冷静期，我重新执业了》《她曾是离婚律师》

## 一、一句话卖点

**当了七年全职主妇，离婚冷静期第一天，丈夫请来的律师，是我当年亲手带出来的徒弟。**

## 二、选题说明

### 1. 题材

女频都市爽文：**离婚逆袭 + 律政**。

主线是女主自己的离婚战（三十天倒计时），之后她重新执业，专替女人打离婚官司，变成"主线 + 单元案"的结构。

### 2. 写给谁看

- **核心读者/观众：25–45 岁女性**，已婚、恋爱中，或者见过身边人离婚。她们是竖屏短剧的主力付费人群，也是女频网文的稳定读者。
- 她们想看的东西：婚姻里被看轻的女人原来不好惹；骗财产的人被一笔一笔追回来；顺便学到点**真能用的婚姻法知识**（婚内转移财产怎么查、房子加名算不算数、彩礼退不退）。
- 次要人群：喜欢律政、智斗、"专业碾压"的读者，不分男女。

### 3. 主角和对手

**女主：宋青禾，34 岁**
- 明面：全职太太七年，婆家眼里的"黄脸婆""吃白饭的"，丈夫觉得她早和社会脱节了。
- 暗面：七年前是业内传说级的离婚律师，执业八年**零败诉**，正当红的时候突然退出，没人知道为什么。
- 性格：冷静，记仇但不发疯，吵架从不提高嗓门，只摆证据。

**对手（三层，由近到远）**
1. **丈夫周屿川 + 婆家**：近处的恶。表面体面的中产家庭，早就开始转移财产、外面有人，准备让她净身出户。负责前期的"受气"和"打脸"。
2. **徒弟陆衡**：核心对手，也是最有看头的关系。当年女主手把手教出来的人，现在是大所的明星律师，招数全是她教的。他认出师父的那一刻就知道这仗难打，但他有不能输的理由。师徒对决，"你会的都是我教的"。
3. **幕后：陆衡所在律所的高级合伙人**：长线反派，和女主当年退出行业有关。作为后期主线悬念，不在开篇亮底。

### 4. 核心冲突

**丈夫一家要在三十天冷静期结束前转走所有财产，让一份名义上"平分"的协议变成实际上的净身出户；她要在三十天内，把被藏起来的每一分钱找回来。**

倒计时为什么成立：两人已经去民政局递了协议离婚申请。她本想体面分开，签的是丈夫给的"平分"协议，后来才发现协议里的财产清单是假的：真正值钱的股权和房产早被代持、挂名，第三十天会全部过户完成。一旦过户到第三人名下，就算日后打赢官司，钱也很难追回来。她随时可以撤回申请改走诉讼，但在拿到证据、申请财产保全之前，一撤就会打草惊蛇。所以这三十天，她要一边假装配合，一边把证据挖出来。

- 表层：钱、房子、孩子抚养权。
- 中层：师徒对决，她要赢过一个最了解她打法的人。
- 深层：她当年为什么放下事业走进这段婚姻？她得把"宋律师"这个身份重新捡起来，不是为了谁，是为了自己。

### 5. 开篇钩子（第一章 / 短剧前 3 集）

1. **冷静期第一天**，她买菜回家，门锁换了，行李被扔在楼道，婆婆隔着门说"这房子跟你没关系"。
2. 丈夫电话里只有一句："有事找我律师。"
3. 律师上门，带着一份补充协议和搬离通知。门一开，**是陆衡**。他手里的文件掉在地上，脱口一句："……师父？"
4. 婆婆和丈夫愣住：她还有徒弟？
5. 章末/集末：她从被扔出来的纸箱底翻出一份旧案卷，扉页上写着她当年的执业证号。她把补充协议还给陆衡：**"回去告诉你的当事人，这个官司我自己打。"**

前三分钟就交代清楚身份反差、对手和倒计时，第一集结尾就是第一个"反转爽点"。

### 6. 爽点从哪来

| 爽点类型 | 怎么落地 |
|---|---|
| **身份反差** | 所有人当她是没用的家庭主妇，读者知道她是行业传说。身份每揭开一层，就打一次脸（婆家 → 丈夫 → 律所 → 整个圈子）。 |
| **专业碾压** | 用真实的法律手段反杀：查出婚内转移的财产、拆穿假债务、把"赠与"判回共同财产。每一招都有知识点，读者看得爽也学得到。 |
| **师徒对决** | 陆衡用她教的招，她用自己没教过的招。"留了一手"的经典爽感。 |
| **倒计时节奏** | 三十天，每天/每集一个回合，有明确的输赢，节奏天然紧。 |
| **婆家打脸** | 换锁、抢孩子、造谣，一个一个用证据和法条回击，不靠撒泼，靠规则赢。 |
| **单元案（中后期）** | 每个新当事人都是一个读者认得出来的婚姻困境，女主替她们赢回来，爽点不断档。 |

### 7. 打算写多长，为什么撑得住

**网文：约 100–120 万字**
- **第一卷·冷静期（约 30 万字）**：自己的离婚战，三十天倒计时，打赢丈夫和婆家，与陆衡第一次交手。
- **第二卷·重新执业（约 50 万字）**：她开了一家只做离婚案的小律所，接单元案，每案 5–8 万字。陆衡在不同案子里反复当对方律师，两人关系慢慢变化。
- **第三卷·当年（约 30 万字）**：揭开她七年前退出的真相，对上幕后合伙人，收主线。

**竖屏短剧：80–100 集，每集 1–2 分钟**
- 只拍第一卷。三十天倒计时正好是短剧要的结构：目标单一、回合清楚、每集结尾都能卡在一个反转上。
- 如果数据好，第二卷的单元案可以直接拆成续季。

**为什么撑得住：**
1. **素材取之不尽**：离婚案天然多样：凤凰男、骗婚、家暴、隐形富豪 AA 制、老年再婚抢遗产、假离婚买房……每一种都是现成的社会话题，每一案都带一个新反派。
2. **结构可续**：主线（师徒关系 + 当年真相）管长线追读，单元案管每天的爽点，不会因为主线打完就没东西写。
3. **人物有余量**：女主的成长不止"赢官司"，还有"重新找回自己"；陆衡的立场可以转变，是长线最好用的一张牌。
4. **话题性强**：离婚冷静期、婚前财产、彩礼这些都是长期热搜词，现实里的新闻能不断给故事供料，也方便短剧投流。

## 三、需要注意的

- **法律细节要找人核**：比如冷静期只适用于民政局协议离婚，冷静期内任何一方都能撤回申请，撤回后才走诉讼离婚；离婚后才发现的隐藏财产，按民法典第 1092 条还能再分（所以倒计时的压力要落在"过户给第三人后追不回来"上，不能写成"过了三十天就再也分不到"）；她作为当事人可以自己出庭，不需要先恢复执业证。爽可以，但不能硬伤，这类读者会较真。
- **不能写成"仇男"**：反派是具体的坏人，不是所有男人。陆衡的复杂性、单元案里偶尔出现的好丈夫/男方受害者，都是用来平衡的。
- **审核**：避免教唆式的违法手段，女主赢只能靠合法证据。
