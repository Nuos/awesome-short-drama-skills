# 选题：开局接手破当铺，我能看穿每件宝贝的来路

> 定稿状态：选题已定，未写大纲、正文。
> 市场依据：这次没拿到实时榜单（番茄榜单抓取不成功），方向判断基于工具箱内置的历史题材样本，属于待验证的假设。验证办法见文末。

## 1. 一句话卖点

被拍卖行栽赃开除的鉴定师，接手爷爷欠债三百万的破当铺。任何东西只要当上他的柜台，他就能看见它值多少钱、经过哪些人的手——骗子拿假货来当，他让骗子赔到倾家荡产；穷人拿传家宝来当，他让宝贝回到该回的人手里。

## 2. 选题说明

### 题材

男频都市，主线是**鉴宝捡漏**，加上**当铺单元案**和**复仇洗冤**。

- 鉴宝、捡漏是都市文里一直有人追的老题材，读者熟悉套路，不用多铺垫，第一章就能上爽点。
- 差异化有两处：
  - **场景换成当铺**。鉴宝文一般是主角去古玩街、拍卖会找东西；当铺是别人带着东西、带着难处上门，每件当品背后都有一个人急等着用钱。题材从"东西真不真"扩展到"人真不真"，案子会自己找上门。
  - **金手指看的是"来路"**。常见的透视眼只看真假，这里能看到一件东西经过哪些人的手、怎么到了这些人手里：谁偷的、谁调的包、谁拿老婆的嫁妆来当。一个能力同时管鉴定打脸和揭穿谎言。

### 写给谁看

- **网文**：番茄男频都市读者，以 25–45 岁男性为主。读者熟悉鉴宝、捡漏、打脸这一路套路，节奏要快，金手指第一章就得亮出来。
- **竖屏短剧**：当铺单元案里有大量家庭伦理冲突（争遗产、渣男偷当妻子嫁妆、不孝子当掉父母的救命钱），女性观众也能看进去。拍摄上，主场景是一间当铺，道具是瓶瓶罐罐和金银首饰，"看来路"用闪回实拍就行，不需要特效，成本低。

### 主角和对手

**主角：林砚，26 岁，前鹤鸣拍卖行首席鉴定助理。**
- 眼力是真本事，从小在爷爷的当铺柜台边长大，后来进了大拍卖行。
- 性格：嘴毒、心软、记仇。对穷人宽，对骗子狠。
- 起点：老板要他在一件假青花的鉴定书上签字，他拒绝了。随后被栽赃"监守自盗"，当众开除，被全行业封杀。爷爷刚去世，留下一间破当铺和三百万债务，债主给了三十天期限。
- 金手指：**爷爷留下的老柜台**。东西只有正式当进来（当金付了、当票开了），他才能看见它的真实价值和经手人。规则：
  1. **付多少当金，看多深**。付一千块只能看真假，付十万能看到上一任主人，付百万能一路看回源头。主角每次都得先拿真钱下注，看完才知道值不值，所以每一单都有风险。
  2. **看不到未来**，只看得到过去。下一步怎么做，还得靠他自己的眼力和算计。
  3. 开局穷，看不深，能力要跟着当铺生意一起成长。只有专业和金手指配合，才赢得了。

**对手：周鹤年，鹤鸣拍卖行老板，江城收藏协会副会长。**
- 表面上是做慈善、捐文物的儒商。暗地里管着一条做旧、造假、借拍卖洗钱的链子。
- 他栽赃林砚，是因为那件假青花已经卖给了大客户，必须找个人背锅。
- 他也一直想拿下林家当铺：二十年前他起家的第一件赃物，就是死当在林砚爷爷的柜台上的，账本至今还在铺子里。这是全书的主线谜底，也牵出爷爷真正的死因。

对手分层升级：老城区的骗子和职业"当托" → 古玩街的造假作坊 → 周鹤年的拍卖行 → 省城收藏圈和背后的资本 → 海外走私文物链（这一层的结局是国宝回归）。

### 核心冲突

林砚要在三十天内还清三百万、保住当铺，再一步步洗清污名、查清爷爷的死因。周鹤年要吞掉当铺、销毁账本，让林砚永远翻不了身。

当铺本身就在冲突中心：林砚想翻身只能靠这个柜台，而周鹤年最怕的东西就锁在柜台里。

### 开篇钩子

第一章（短剧第一集）：
1. **开场**：鹤鸣秋拍现场，林砚当众被扣上"监守自盗"的罪名，保安把他架出去，前女友站在周鹤年身后看着。
2. **转折**：他回到爷爷的破当铺，催债的已经堵在门口，限期三十天还清三百万，否则收铺。
3. **钩子**：当晚来了第一个客人，是一个戴墨镜的阔太太，要偷偷当一只翡翠镯子。林砚咬牙拿出身上最后两万块当金，柜台亮起来——这只镯子就是拍卖会上被调包的真品，阔太太是周鹤年大客户的妻子，镯子是她丈夫藏起来的。
4. **章末**：林砚开出当票，说了一句"三十天，您来赎，还是我去送？"

第一章就交代清楚了身份落差、债务倒计时和金手指，还拿到了扳倒对手的第一份筹码。

### 爽点从哪来

| 爽点 | 怎么兑现 | 频率 |
|---|---|---|
| 鉴定打脸 | 满屋子专家说是真的，他说是假的，结果揭晓；或者别人当垃圾扔掉的东西，被他当成宝贝收下 | 每个单元案至少一次 |
| 揭穿谎言 | 当来路暴露真相：偷的、调包的、骗老人的，当场拆穿 | 每个单元案的高潮 |
| 惩恶扬善 | 骗子来当，他让骗子赔得倾家荡产；穷人来当，他多给钱，赎期也宽限 | 贯穿全书，是主角立人设的地方 |
| 数字上涨 | 欠款倒计时、当铺流水、藏品估值，读者能直接看到数字往上走 | 每卷一个大数字节点 |
| 地位反转 | 被封杀的人反过来让整个收藏圈求着他掌眼，拍卖行的前同事上门求职 | 每卷卷末 |
| 国宝回归 | 后期追查流失海外的文物，送回国家 | 后期大高潮 |

### 打算写多长、为什么撑得住

- **网文**：计划 **150–200 万字**，分 5 卷，每卷对应上面一层对手。番茄都市文要长线连载才能吃到流量，这个体量够用。
- **短剧**：第一季改编第一卷，从开除到扳倒周鹤年的一个心腹，约 **80–100 集，每集 1–2 分钟**。单元案天然适合按集切，每集结尾都可以停在柜台亮起来、真相要揭开的那一刻。

**为什么撑得住：**
1. **素材源源不断**。案子靠客人上门，不靠主角出门找。每一件当品就是一个 3–8 章的案子，写到一千章也不愁没东西可当。
2. **能力有天花板，也有成长**。"付多少当金看多深"把金手指和主角的财力绑在一起，前期穷所以看得浅，后期有钱才能看得深，升级曲线和地图升级同步。
3. **主线有悬念吊着**。爷爷的老账本、二十年前的死当、爷爷的死因，每卷揭开一层，读者追单元案的同时也在追主线。
4. **对手层层升级**。从街头骗子到海外走私链共五层，每层换一个新地图、新行当（玉石、书画、钟表、名车、文物），读者不容易审美疲劳。

## 风险和开写前的验证

- **同质化**：鉴宝文数量多。差异化全靠"当铺上门"和"看来路"，黄金三章必须把这两点亮出来，不能写成又一本透视眼捡漏。
- **金手指太强**：要守住"必须正式当进来"和"付多少钱看多深"两条限制，不然主角每次都提前知道答案，悬念就没了。
- **合规**：文物买卖受国家管理。凡是出土文物、国家禁止流通的器物，情节上主角都要上交或协助追缴，把它写成爽点，不写成私下倒卖，这样网文审核和短剧过审都更稳。
- **市场没有核实**：这次没扫到实时榜单。开写前建议在能联网、开着 Chrome 的环境里跑一次番茄扫榜（阅读榜、新书榜，加上书库最热的新书），看都市鉴宝、捡漏这个方向现在有多少新书、热度怎么样。再挑一两本近期同方向的新书拆一拆。最省成本的验证是先写黄金三章，发出去看追读，追读不行就调整。
