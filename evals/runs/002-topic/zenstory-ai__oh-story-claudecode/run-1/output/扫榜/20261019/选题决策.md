## 推荐选题

### 选题 1：重生回包工头跑路前一天，工地记账员挨家讨账
- 题材组合：都市重生 + 发家 + 讨账（对账名场面）
- 目标读者：男频，对重生、打脸、发家的套路很熟，可以直接上爽点
- 核心卖点：带着前世二十年的账重生，每一笔欠薪、每一个跑路的老板、每一栋会烂尾的楼都记得，当众对账，让人赖不掉
- 能爆的原因：讨账这套机制一个单元收一笔账，可以一直重复，赌注逐卷往上加；讨薪、亲戚借钱不还是大众身边的事，不用科普就能共情（假设，`待拆文验证`）
- 差异化定位：别的重生文靠彩票、股票这类先知发财，这本靠一本记着人和钱的账；金手指不加系统，可信，拍短剧也不需要特效
- 可行性：中（内置知识模式，没有实时样本也没有上期可比）。排第一是因为它跟作者给的两个条件（网文爽文、能拍竖屏短剧）最对得上：现代实景、每集都有对账的高潮，长篇又有二十年时间线撑着
- 失败风险：都市重生同质化，黄金三章立不住「讨账」就会被淹没；时代背景写成科普；欠薪、烂尾楼题材送审敏感
- 验证动作：复扫番茄男频都市新书，搜讨薪、包工头、讨账、重生到零零年代几个方向数同类本数；先写黄金三章发出去看追读
- 建议拆的对标书：待复扫后从同方向新书里挑（优先字数少的新书）
- 篇幅/平台：一百五十万到两百万字，番茄男频都市；短剧改编第一卷加第二卷前半，约八十到一百集
- 详细选题说明：见项目根 `选题.md`

### 选题 2：女频重生，回到全家逼她把婚房让给弟弟那天
- 题材组合：女频现言 + 家庭重生 + 搞事业
- 目标读者：女频，对「扶弟魔」家庭、重生反击这类套路很熟
- 核心卖点：前世房子、存款、工作都被娘家吸干，重生后一样一样拿回来，再自己做起事业
- 能爆的原因：家庭里的不公平最容易激起情绪，拍短剧冲突密度高（假设，`待拆文验证`）
- 差异化定位：重点放在「拿回来以后怎么过好」，不停在跟娘家撕扯，避开长期被虐

- 失败风险：家庭矛盾撑不到长篇，后期容易没对手可打；容易写成长期虐主
- 验证动作：复扫番茄女频现言新书，搜重生、扶弟魔、原生家庭标签
