# 🎬 选题：《最后一份清单》

**一句话卖点：** 她是遗产管理人，每一场分家都得过她这一关：死去的人想说什么，由她念；白眼狼该拿多少，按法律算。而她要清的最后一份遗产，是十九年前被大伯一纸假遗嘱抢走的自己家。

**核心设计：**
- **题材：** 家庭伦理为主，叠加逆袭和悬疑。结构是"单元案 + 主线复仇"：每个单元是一户人家争遗产，主线是女主为自家翻案。女主的职业是真实存在的，《民法典》2021 年起有遗产管理人制度。
- **写给谁看：** 女频，30–50 岁看家庭伦理剧的观众。分遗产时亲人翻脸，很多人都经历过或见过。
- **主角和对手：** 主角许宁，律所里不受待见的继承律师。主要对手是大伯，靠假遗嘱起家的慈善企业家。中层对手是同岁的堂兄。隐藏反派是她的师父，当年那份假遗嘱就是他代写的。
- **核心冲突：** 法律对权利的保护最长二十年，故事开始时已经过了十九年。她要在一年内找到当年的两个见证人和代书人，凑齐证据起诉。
- **开篇钩子：** 灵堂上，她被大儿媳当成来倒茶的小姑娘。她亮出身份："遗嘱执行人是我。"当场替被诬陷的保姆翻盘。第一集结尾，她在保险柜里找到见证人留下的认罪信，信上写着："另外两个人，你认识。"
- **爽点：** 主要是拿证据当场反杀，配上"念遗嘱"这个固定的泪点场面。她的武器是法律，所以打脸有仪式感，也没有合规风险。
- **篇幅：** 短剧 80 集，网文约 120 万字。撑得住的原因：单元故事的素材几乎用不完；二十年时效给主线一个停不下来的倒计时；案子的标的从老破小一路涨到几十亿的集团。

**需要你确认的：**
- 按 /start 的流程，受众、基调、结局、集数这些本该由你来选。为了交一份完整的选题，我先替你定了一套（女频、爽燃加温情、大团圆、80 集），写在文件最后，也存进了 `.drama-state.json`，你随时可以改。
- 法律细节（二十年时效从哪天开始算、丧失继承权怎么适用）是按我对《民法典》的理解写的。到大纲阶段，最好请执业律师核一遍。
