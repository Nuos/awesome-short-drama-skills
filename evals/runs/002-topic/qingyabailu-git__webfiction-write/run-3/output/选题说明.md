# 选题说明：《头七之内，替死人讨债》

> 状态：草案（可随时修改，fiction-start 时锁定）
> 书名定为《头七之内，替死人讨债》｜短剧名：《我替亡人讨公道》
> 一句话卖点见 [一句话卖点.md](一句话卖点.md)

---

### 1. 题材

**都市 + 轻异能 + 单元复仇**，带一条悬疑主线。

- 主体是都市爽文：遗产争夺、不孝子女、吞家产的合伙人、骗保的配偶，全是现实里人人见过、人人恨的事。
- 异能只有一个，规则很简单：摸遗物，借本事，替死者讨债。不修炼、不升级打怪，读者不用记设定。
- 一案一债，三到八万字结一个单元；每个单元都给主线一块拼图。

**为什么是这个题材**：网文和短剧都在吃两类东西，一是"当众打脸"，二是"家庭伦理撕扯"。灵堂、遗嘱宣读、追悼会、出殡，本来就是一家子当众翻脸的地方。这个设定把两样东西装进了同一个场景。

### 2. 写给谁看

- **主力读者**：25–45 岁女性，番茄女频的都市、家庭、复仇读者。她们爱看恶人当众现形，也爱看弱者被人撑腰。
- **短剧观众**：30–55 岁、下沉市场的中老年观众。遗产、养老、以房养老骗局、子女不孝，跟她们的生活贴得最近。
- **兼容人群**：喜欢单元悬疑的泛读者，男频读者也能看。每个案子都有"死者到底怎么死的"这一层。

### 3. 主角和对手

**主角：许归，26 岁，遗物整理师**

- **处境**：三年前，父亲许正平是长生集团的财务主管，被认定挪用公款、畏罪跳楼。她背着"贪污犯女儿"的名声，正经工作都不要她，只能干没人愿意干的活：进死人的屋子，收拾死人的东西。
- **核心欲望**：给父亲翻案。她不信他是自杀。
- **核心缺陷**：信死人，不信活人。活人对她撒过太多谎，所以她独来独往、嘴硬、记仇，宁可自己硬扛也不接别人递过来的手。这个毛病会让她一次次孤立无援，也会让她错怪真心帮她的人。
- **能力**：头七之内触碰死者生前最常用的遗物，就能继承死者一项看家本事，再加上和他那笔"债"有关的记忆碎片。
  - 例：老会计的查账眼、老刑警的识人术、老裁缝一眼量出身材的手感、老律师的辩才、老骗子的话术。
- **代价（硬规则）**：
  1. 必须在死者**头七之前**把债讨完。讨完了，本事永久留下；没讨完，本事收回，她还要替死者背七天他临死前的病痛。
  2. 同一时间只能"借"一个死人的本事，已经永久留下的不算在内。
  3. 拿到的记忆只和那笔债有关，不能拿来窥探死者别的事。

**对手（三层）**

| 层级 | 人物 | 和主角的镜像关系 |
|------|------|------------------|
| 单元反派 | 每案的欠债人：吞遗产的长子、骗保的丈夫、逼死老师傅的徒弟…… | 都是"死人不会说话"的受益者。许归偏偏让死人开口 |
| 中层反派 | 顾承宗，顾家长子，长生集团的合伙股东 | 第一案的仇人。被打脸之后一路给她使绊子，后来成了长生集团的打手 |
| 终极对手 | **陆鹤年**，长生集团董事长 | 一手养老院，一手殡葬，再加寿险和以房养老，"全城人从老到死都在给他交钱"。**许归替死人讨债，陆鹤年靠死人赚钱。**许父就是因为查到了长生养老院"让老人早点走"的账，才"自杀"的 |

**感情线**：单女主，慢热，放在辅线，不抢主线。男主是市刑侦支队的沈砚，三年前许父案的经办人之一，当年就觉得这案子不对劲。他先是怀疑她，后来成了她"活人里唯一信的那个"。这条线正好用来磨主角"不信活人"的缺陷。

### 4. 核心冲突

- **单元冲突**：头七倒计时之内，许归要从有钱有势、早把证据处理干净的欠债人手里，替一个已经没法作证的死人讨回公道。
- **主线冲突**：一个背着污名、靠收拾死人东西过活的女人，对上掌控整座城"生老病死"生意的陆鹤年，要证明父亲是被灭口的。
- **内在冲突**：她只信死人，可要扳倒陆鹤年，非得学会信活人不可。

### 5. 开篇钩子

**第一场：顾家灵堂，遗嘱宣读现场。**

1. 顾家老爷子刚死，长子顾承宗拿出遗嘱：全部家产归他，伺候了老人十年的保姆和小女儿什么都没有。满堂孝子贤孙指着门口的许归说："收破烂的，晦气，赶紧把老头的东西清走。"
2. 许归戴上手套，拿起老爷子用了五十年的钢笔。下一秒，她脑子里多了顾老爷子半辈子看账、看人的眼力，还有一句临终没说出口的话：**"遗嘱是假的，药被换了。"**
3. 她当众翻开遗嘱，指出落款笔迹的三处破绽，又从待清理的旧书里抽出真遗嘱和老人亲手记的用药本，一场灵堂当场翻盘。
4. **结尾钩子**：用药本最后一页夹着一张旧照片。照片上是她父亲和顾老爷子，背面写着：**"老许不是自杀。长生的账，在我这儿。"** 再翻过来看，照片的拍摄地点是长生养老院。

> 短剧版：前 60 秒完成"被羞辱 → 摸钢笔 → 眼神一变"，第 1 集结尾卡在"遗嘱是假的"，第 2–3 集当众翻盘，第 3 集结尾翻出照片。第一个付费卡点放在这里。

### 6. 爽点从哪来

1. **身份反差打脸**：人人当她是"收破烂的""晦气东西"，可她手里攥着死者全部的底牌。最瞧不起她的人，被打脸打得最狠。
2. **借来的本事，花样翻盘**：每案换一种本事，翻盘手法就不会重样。这回用老会计的眼睛查账，下回用老刑警的直觉审人，再下回用老骗子的话术反骗骗子。
3. **天然的公开处刑舞台**：灵堂、遗嘱宣读、追悼会、墓地，全是众目睽睽的场合，亲戚、律师、记者都在场。短剧最需要的"当众翻盘"，这个设定每案自带。
4. **倒计时紧迫感**：头七只有七天。案子接到手的时候可能只剩两天，每案都有一个自带的时钟。
5. **替死者出头，泪点和爽点一起来**：债讨回来的那一刻，死者的心愿也了了。打脸爽，告慰也让人鼻酸，女频读者两样都吃。
6. **主线拼图在累进**：每案都撬开长生集团一个角，读者追单元的同时，也在追许父之死的真相。

**反套路规则（差异化）**：

- **死人不一定是好人**：有的死者讨的是"恶债"。比如死去的家暴男想让逃走的妻子付出代价。许归拒绝了，宁可自己背七天病痛。能力不是正义本身，选择才是。这一条和韩剧《我是遗物整理师》那种治愈路线、和国内入殓师猎奇文都拉开了距离。
- **本事不是外挂**：借来的本事连着死者的习惯和盲区。老会计的眼睛看得穿账本，却看不出人心。许归必须自己补上这一块。

**硬约束**：

1. 每案的翻盘必须落在**可验证的证据**上（笔迹、账目、录音、遗物），不能靠"异能说了算"。
2. 头七规则绝不打破，失败的代价必须真的落到主角身上，至少要有一案失败。
3. 能力的来源不在前期解释，留作主线后段的伏笔。

### 7. 打算写多长、为什么撑得住

**网文**：约 **120 万字**，四卷，番茄连载。

| 卷 | 范围 | 字数 | 对手层级 |
|----|------|------|----------|
| 一 | 家门里的债：遗产、婚姻、子女不孝 | ~25 万 | 单元反派 + 顾承宗 |
| 二 | 行当里的债：职场、师徒、合伙人 | ~30 万 | 顾承宗投靠长生，正面交锋 |
| 三 | 长生的债：养老院、以房养老、骗保 | ~35 万 | 陆鹤年的手下，主线全面浮出 |
| 四 | 父亲的债：许父真相、能力来源、陆鹤年 | ~30 万 | 终局 |

**短剧**：第一季 **80 集**（每集 1–2 分钟），覆盖顾家案、两到三个单元案，再加上许父线的揭露。场景集中在灵堂、老宅、殡仪馆、养老院，拍摄成本低。

**为什么撑得住**：

1. **素材不会枯竭**：每个死人都是一个新题材，婚姻、职场、校园、医闹、养老、拆迁都能写，单元可以无限往下生产，不用硬编新地图。
2. **成长曲线清楚**：讨回一笔债，留下一样本事。主角的工具箱一案比一案厚，读者看得见她在变强。
3. **主线一级一级往上走**：家庭、行业、集团、真相，每卷的对手都比上一卷高一级，不会原地打转。
4. **单元疲劳有解药**：每案都必须交出一块主线拼图（一个人证、一笔账、一段记忆）。头七倒计时和"恶债要不要讨"的选择题，也会让单元的节奏和走向变着花样来。
5. **改编友好**：单元结构天然切成短剧的季和付费卡点，一案就是一个完整的"受辱、反击、当众翻盘"循环。
