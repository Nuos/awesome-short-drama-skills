# 一句话卖点

> 书名：《头七之内，替死人讨债》｜短剧名：《我替亡人讨公道》
> 状态：草案（fiction-start 时锁定）

**被全城嫌晦气的遗物整理师，每摸一件死人的遗物，就能继承他一身本事——代价是在头七之前，替他把生前没讨回的债，当众讨回来。**

拆开看：

- **主角**：被全城嫌晦气的遗物整理师许归（身份反差）
- **金手指**：摸遗物，继承死者的本事（每案花样不同）
- **目标**：替死者讨回生前的债（每案都有明确的复仇对象）
- **阻碍**：头七倒计时，而欠债人有钱有势，死者又没法作证（时钟加上实力差）
- **爽感**：当众讨回（灵堂、遗嘱宣读这类公开打脸的场合）
