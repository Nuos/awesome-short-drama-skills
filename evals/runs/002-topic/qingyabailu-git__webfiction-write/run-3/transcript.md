**选题要点**：
- **题材**：都市 + 轻异能 + 单元复仇，另有一条悬疑主线。主力读者是番茄女频 25–45 岁女性；短剧观众是下沉市场的中老年人群，遗产、养老、以房养老这些题材离他们的生活最近。
- **主角**：许归。父亲背着"贪污跳楼"的污名死了，她只能去干收拾死人东西的活。她最想做的是给父亲翻案。她的毛病是只信死人、不信活人。

- **开篇钩子**：顾家灵堂宣读遗嘱。许归被骂"收破烂的"，她摸到老爷子的钢笔，当场认出遗嘱是假的，并且翻盘。结尾她在遗物里找到父亲的旧照片，背面写着"老许不是自杀"。
- **爽点**：身份反差带来的打脸；每案借来的本事不同，翻盘手法不重样；灵堂和遗嘱宣读本身就是当众处刑的舞台；头七倒计时；替死者出头，同时有泪点和爽点。
- **篇幅**：网文约 120 万字，分四卷，对手一级比一级高：家庭、行业、集团，最后是父亲之死的真相。短剧第一季 80 集。撑得住的理由有三条：每个死人都是一个新题材，素材不会用完；每讨回一笔债就留下一样本事，主角看得见在变强；每案都要交出一块主线拼图，单元写多了也不会腻。
