## 选题：《七年账本》（都市女频 · 婚姻律政 · 离婚逆袭）

**一句话卖点**：丈夫当众甩来"净身出户"协议，他不知道，这个当了七年全职太太的女人，曾是全城最贵的离婚律师，而且这七年的每一笔账，她都记着。

**要点：**
- **差异化**：同类书多数靠"其实是豪门千金"这类身份揭秘翻盘。这本靠专业翻盘：法条、证据加账本，读者看得懂，现实里也用得上。
- **读者**：番茄女频 25–45 岁女性，以及短剧付费主力 30–50 岁女性。共同的痛点是婚姻里被算计、付出不被承认。
- **对手分三层**：
  - 前夫、婆婆和小三，负责前期的憋屈和打脸。
  - "离婚收割机"秦衡，跟主角是镜像：同样懂法，他帮强者吞掉弱者，她帮被算计的人把账算清。
  - 前夫公司背后的资本方，后半段才揭开。
- **开篇钩子**：故事从离婚调解室开始。主角先被一家人围攻，然后三句话反杀：
  - 公司婚后七年的经营增值是共同财产。
  - 前夫转给小三的 417 万可以全部追回。
  - 按《民法典》1092 条，转移财产的一方分割时可以少分甚至不分。

  章尾她打电话回律所："我的第一个案子，是我自己的。"
- **篇幅**：网文约 80 万字，短剧 80–100 集。撑得住长篇主要靠两点：
  - 一个案件一个单元，婚姻家事纠纷的类型足够多。
  - 三层对手对应三卷，每个案件单元都给主线补一块。

文件末尾还列了四个风险和对策：法律准确性、男女对立、案件单元重复、主角太完美。

**你可以先想几件事：**
1. 你更偏女频还是男频？如果想写男频，同一个"被低估的人用专业把账算清楚"的骨架，可以换成男主版，比如被裁的老审计师、被赶出家族的鉴定师。
2. 主线要不要加孩子和抚养权？加了情绪更重，但打脸会没那么痛快，所以我暂时没加。
3. 想先看看现在番茄、红果上这类题材的行情，可以调用 fiction-scan 扫一下榜再定。

你说"就这个"，下一步我们就进主角卡和世界观。想换方向也可以直接说，我们重新讨论。
