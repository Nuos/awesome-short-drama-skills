# 选题：《账不会老》

> 状态：草案（只定选题，不含大纲与正文；fiction-start 前可随意改）
> 网文书名：《账不会老》 / 短剧名：《退休后，我把全家的账查清了》

---

## 一、一句话卖点

**被儿子赶出家门的 63 岁老会计，一眼看穿每一本假账——而十年前逼她背锅退休的那家集团，下个月就要上市。**

---

## 二、选题说明

### 1. 题材

**都市 · 银发女主 · 职业流 · 打脸逆袭**（带家庭伦理线）

- 金手指不是系统、不是重生，而是**四十年查账功夫**：她看过的账不会忘，一张报表、一份合同、一沓发票，她扫一眼就知道哪里在撒谎。
- 每个单元一桩“假账案”：阴阳合同、伪装成赠与的担保、物业维修基金被挪用、养老理财骗局、彩礼与遗产里的猫腻……题材是钱，冲突是人心。
- 差异化：同类“老年逆袭”多靠**隐藏身份**（其实是豪门、其实是大佬），本书靠**真本事**。她的身份反转（业内传奇“宋算盘”）只是锦上添花，每一次赢都是她自己算出来的。

### 2. 写给谁看

| 渠道 | 主力读者 | 他们为什么买账 |
|---|---|---|
| 网文（番茄为主） | 30–55 岁女性读者，及番茄大量的中老年免费阅读用户 | 房子、养老、子女、彩礼都是身边事；“被家里人当成没用的老人”是很多人真实的委屈 |
| 竖屏短剧 | 35 岁以上女性观众（短剧付费主力） | 银发女主逆袭是近两年短剧上升方向；“当众念出一串数字，全场哑口”非常适合竖屏的高频反转 |

不主攻年轻男频读者，这是主动取舍。

### 3. 主角和对手

**主角：宋桂芝，63 岁，人称“宋算盘”**
- 前大所审计合伙人。十年前拒绝在恒禾集团的造假审计报告上签字，被所里做局成另一项目的“重大失误”，暂停执业、提前退休，从此在外人眼里是个“出过事的老会计”。
- **欲望**：守住自己最后的房子和尊严；更深一层，是把十年前的账算清。
- **缺陷**：太要强、从不解释。十年里没跟儿子讲过当年真相，任由他以为母亲是个犯过错的失败者——这份沉默，正是儿子站到她对面的原因，她要为此付代价。
- **能力的代价**：她没有执照、没有职位、没有靠山，查出来的东西必须靠证据链和别人的嘴说出去；她越接近真相，对手越会拿“老了、糊涂了”来让她的话不作数。

**对手（分层，彼此串联）**

| 层级 | 人物 | 与主角的关系 |
|---|---|---|
| 小 | 刘国富，准亲家，小建材公司老板 | 想骗她签“赠与协议”抵彩礼，实为 320 万银行贷款的连带担保。他被恒禾长期压账期，是开篇事件的源头 |
| 中 | 周磊 & 刘佳琪，儿子与准儿媳 | 不是纯恶人，是被钱和面子推着走；儿子的“追悔”是一条贯穿全书的情感回收线 |
| 大 | 顾言，她当年的徒弟，现大所明星合伙人 | 镜像对手：同样的本事，选了钱。恒禾上市报告的签字人就是他。师徒对决是全书最高级的“专业碾压” |
| 终 | 贺东升，恒禾集团董事长 | 十年前的造局者。恒禾上市的窟窿，最后会落到一批买了“恒禾养老理财”的老人头上——其中就有宋桂芝的老同事、老邻居 |

**助力**：陈小满，25 岁，刚被裁的小会计，成为她的徒弟和“腿”——替她跑腿、替她发声，也承接年轻观众的视角。
**助力**：韩振国，66 岁，退休老刑警，她新租处的邻居。她能看出账哪里不对，却不知道怎么把它变成警方肯立案的证据——这正是老韩会的。两人之间有一条克制的黄昏恋轻甜线：短剧里作为加分项明着写，网文里点到为止，不抢母子线。

### 4. 核心冲突

- **外线**：一个“没有资格说话”的老太太，要在恒禾上市之前，把一本做得天衣无缝的假账，一层层翻到所有人面前。
- **内线**：所有人（包括亲儿子）都说她老了、糊涂了、该认命了；她要证明的不只是账是假的，还有“我没有老”。
- **一句话**：**全世界都在算她还剩几年，她在算全世界欠她几笔。**

### 5. 开篇钩子（第 1 章 / 短剧前 3 集）

1. **订婚宴**。准亲家刘国富推过来一份“房产赠与协议”：签了，彩礼就算谈妥。儿子在桌下踢她：“妈，签吧，别让我丢人。”
2. 她翻到第 3 页，三十秒，合上。
   “这不是赠与，是连带责任担保。你公司欠银行的三百二十万，我签了，就是我还。”
   满桌安静。
3. 刘家当场翻脸，说她“老糊涂、看不懂合同、存心搅黄婚事”。儿子站到了刘家那边。
4. 当晚她拖着一只行李箱离开儿子家。楼下，手机响了，是十年没联系的老同事：
   **“宋老师，恒禾下个月上市。签字的是顾言。”**

钩子要素：开场 3 分钟内完成“受辱 → 一眼识破 → 被反咬 → 更大的仇浮出水面”，第一集就交代清楚她的能力、她的处境、她的终极对手。

### 6. 爽点从哪来

| 爽点类型 | 怎么兑现 | 频率 |
|---|---|---|
| **一眼识破**（智力碾压） | 每个单元至少一次：一个周日的签字日期、一张连号发票、一笔对不上的尾数 | 网文每 2–3 章一次；短剧每集一次 |
| **当众算账**（打脸） | 在家宴、业委会、银行、董事会、发布会上，把数字一笔笔念出来 | 每个单元高潮 |
| **身份揭晓**（反转） | “疯老太太”被认出是当年的“宋算盘”——银行行长起身让座、对方律师当场改口 | 分批揭晓，不一次用完 |
| **儿子追悔**（情感回收） | 周磊一点点发现母亲当年的真相与这些年的委屈 | 慢火，关键节点爆发 |
| **钱追回来**（正义回收） | 被骗的养老钱、维修基金、血汗钱回到普通人手里 | 每个单元收尾 |
| **师徒对决**（高手过招） | 与顾言隔着报表交手，彼此都知道对方能看懂 | 中后期主菜 |

**硬规则**：每一桩假账的关键破绽，必须能用**一句外行听得懂的话**讲清楚。读者不需要懂会计，只需要看懂“这个数不对”。

### 7. 打算写多长、为什么撑得住

**计划篇幅**
- 网文：**100–120 万字**（番茄中长篇区间），约 30 个单元案。
- 短剧：**80 集左右，每集 1.5–2 分钟**，取主线 + 最强的 6–8 个单元。

**为什么撑得住**

1. **单元引擎可无限复制**：钱的骗局没有穷尽。家庭财产、小微企业、社区物业、养老理财、上市公司——每一层都有大量真实、贴身的造假手法，素材取之不尽，且每案独立成爽。
2. **有清晰的升级阶梯**，不会原地打转：

   | 阶段 | 战场 | 对手量级 | 与主线的勾连 |
   |---|---|---|---|
   | 一 | 家庭 | 准亲家 | 刘国富被恒禾压账期——第一根线头 |
   | 二 | 街坊与小店 | 小老板、骗子 | 收徒陈小满，重建口碑 |
   | 三 | 社区 | 物业、业委会 | 维修基金的钱流向恒禾关联公司 |
   | 四 | 金融 | 养老理财平台 | 受害者是她的老同事——恒禾的资金池浮出水面 |
   | 五 | 上市 | 顾言、贺东升 | 十年旧案翻盘，儿子知道真相 |

3. **主线有倒计时**：“恒禾下个月上市”在第一章就挂上了，所有单元都在给这条主线添证据，节奏有天然的紧迫感。
4. **情感线不靠恋爱撑**：母子线是最大的情感储备，从对立到追悔到和解，足够跨越全书；与老韩的黄昏恋只作调味。
5. **短剧友好**：场景集中在家宴、办公室、银行、会议室、发布会，拍摄成本低；“念数字打脸”这一招自带名场面，适合切片传播。

## 三、已知风险与对策

| 风险 | 对策 |
|---|---|
| 财务内容太专业，读者看不懂 | 执行上面的“一句话破绽”硬规则；专业细节只做背景，不做讲解 |
| 银发女主劝退部分读者 | 主动放弃年轻男频；用陈小满承接年轻视角 |
| 儿子写成纯恶人，后期和解不可信 | 开篇就给他“被面子和房贷推着走”的处境，留出回头的余地 |
| 涉及上市、审计、金融监管，平台审核 | 公司与机构全部虚构；结局走“证据交给监管与司法”，不写私刑 |
