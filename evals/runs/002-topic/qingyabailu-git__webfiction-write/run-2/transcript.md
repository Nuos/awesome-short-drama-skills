**暂定书名：《账不会老》**

**一句话卖点**：被儿子赶出家门的 63 岁老会计，一眼就能看穿每一本假账。十年前逼她背锅退休的那家集团，下个月就要上市。

**为什么选这个方向：**
- **网文和短剧都能做**：题材是都市银发女主 + 职业流，这两年在短剧里越来越热。短剧的付费主力是 35 岁以上女性，番茄上中老年读者也多。拍摄场景集中在家宴、办公室、银行、会议室，成本低。"当众念出一串数字，全场说不出话"这种场面本身就适合竖屏短剧。
- **和同类不一样**：同类老年逆袭大多靠隐藏身份（其实是豪门、其实是大佬），这本靠真本事，也就是她四十年的查账功夫。每次赢都是她自己算出来的。
- **开篇钩子**：订婚宴上，准亲家拿一份"赠与协议"让她签。她翻了三十秒就看出来，这其实是 320 万贷款的连带担保。结果对方反咬她老糊涂，儿子也站到了对面。当晚她拖着行李箱离开，楼下接到一个电话："恒禾下个月上市，签字的是顾言。"顾言是她当年带出来的徒弟。
- **为什么能写长**：骗局花样写不完，单元案可以一直出。战场有一条清楚的升级线：家庭 → 街坊 → 社区物业 → 养老理财 → 上市公司，每一层都和主线连着。另外，"上市倒计时"第一章就挂出来了，后面一直有紧迫感。计划篇幅是网文 100–120 万字，短剧 80 集左右。

文件里还写了这些：对手分四层、六类爽点各自怎么兑现和多久来一次、一张风险与对策表，以及一条硬规则：每个骗局的关键破绽，都要能用一句外行听得懂的话讲清楚。

还有两点要说明：
- 这个判断是凭我对番茄网文和短剧常见题材的了解做的，没有实时扫榜。想先验证市场热度的话，可以跑一次 fiction-scan。
- 这个方向如果不对你的口味，比如你想要男主、玄幻，或者更年轻的设定，直接告诉我，我们换个方向重新聊。如果方向可以，下一步就把主角卡、世界观、文风这几块细化。
