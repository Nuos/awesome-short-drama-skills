# 选题：《这单，我不赔》

> 方法：用已安装的 `novel-genres` skill 做选题判断（决策树、融合矩阵、选题评分表），平台和爽点部分参考了 `novel-commercialization`（番茄 / 新媒体文风格）和 `novel-pleasure-points`（智商碾压、爽点疲劳管理）的资料。

---

## 一、一句话卖点

**公司让金牌理赔调查员背下 3000 万骗保案的黑锅，她当众只用十分钟就拆穿了骗局。从此她手上每一单都是当面打脸：骗保的，一分钱都别想拿走；该赔的，一分钱都不能少。她要查的最后一单，是亲手把她推下去的师父。**

---

## 二、选题说明

### 1. 题材

**都市职场大女主（主类型 70%）+ 单元探案（副类型 30%）**

- 主类型给框架：主角被陷害、被发配，然后一路逆袭，最后清算内鬼。整部书的爽感和情绪曲线都靠这条线撑着。
- 副类型给每个单元的内容：每一单理赔案就是一个小悬案，按"出险，疑点，实地调查，当面对质"走。
- 两边的接口在主角的职业上。拆案是她的本事，每案结尾都留一条指向公司内鬼的线索，单元案和主线就接上了。
- 融合矩阵里"都市 × 悬疑"是 ★★★★（高度兼容），不用硬拼设定。

**为什么选这个，而不是赘婿、战神、神医：**
- 那几类在番茄和短剧上已经极度饱和。按 2025 年以来的微短剧管理导向，"霸总、战神、过度炫富"的包装也越来越难过审。
- 职业题材、现实背景、正向价值（反诈、维权）符合目前平台和监管鼓励的方向，但内核还是标准的"被轻视，露一手，全面碾压"爽文结构。
- 保险理赔这个职业大家都打过交道（车险、医疗险、退货运费险），却很少有人知道里面的门道，所以既容易代入，又有新鲜的行业知识可写。

### 2. 写给谁看

| 渠道 | 目标人群 | 他们要什么 |
|---|---|---|
| 网文（番茄女频 / 七猫，免费广告模式） | 女性 22–40 岁，上班族、宝妈，下沉市场占比高 | 被欺负的女人靠本事翻身，看坏人当面现形 |
| 竖屏短剧（抖音 / 红果） | 短剧付费主力：女性 28–50 岁 | 每集一个反转，每 3–5 集一次当众打脸，情绪直给 |
| 兼顾 | 男性读者 | 智商碾压和查案部分不分男女，主线无恋爱依赖，可以吸一部分男读者 |

**不适合的人群**：想看强感情线、甜宠的读者。本书感情线只做弱 CP 点缀，不当卖点。想看严谨本格推理的读者也不适合，本书推理服务于爽感，不追求完全公平线索。

### 3. 主角和对手

**主角：林照，29 岁，长衡保险（虚构公司）华东区金牌理赔调查员**
- 核心标签：冷静毒舌、过目不忘的细节控、原则感极强。
- 职业信条，也是本书的价值锚点：**"该赔的一分不少，不该赔的一分不给。"**
- 金手指不用系统，用职业能力：一眼看穿现场细节、熟悉各险种条款和行业黑话、在一线攒了七年的人脉（修车师傅、法医、交警、外卖骑手）。爽感来自"她懂行，你不懂"。
- 软肋：她当年入行，是因为父亲出事后被保险公司以"免责条款"拒赔，家里背了债。所以她最恨两种人：骗保的人，和拿条款坑老实人的公司。

**主对手：顾承山，48 岁，华东区理赔总监，林照的师父**
- 表面上带她入行、护她七年，是业内口碑最好的"老好人"。
- 实际上是公司内部骗保链的保护伞：外面勾结修理厂、医院、中介做大额骗赔，里面用"拒赔 KPI"压真实理赔，压下来的钱给自己做业绩。
- 他陷害林照，是因为她太好用，也太危险：她迟早会查到他。
- 师徒对决是全书最大的情绪张力。他教会她的每一招，最后都会被她用在他身上。

**分层对手（防止只有一个大反派撑全书）：**
1. **单元小反派**：碰瓷团伙、假装残疾骗赔的人、纵火骗保的老板、薅退货运费险的工作室、"假死"骗寿险的丈夫。每单一个，当集解决。
2. **职场中层**：抢功的同事、拿 KPI 压她的部门经理、看不起"发配户"的总部精英。负责阶段性打脸。
3. **产业链**：和顾承山勾连的修理厂老板、医院科室、理赔中介律所。中期按势力级清算。
4. **终极**：顾承山，以及他背后想拿骗赔资金池做账的资本方。

### 4. 核心冲突

- **外在冲突**：林照要洗清"内鬼"污名、回到总部，同时揪出真正的内鬼。顾承山要么把她继续当刀用，要么让她彻底闭嘴。
- **内在冲突**：她信了七年的师父就是她最恨的那种人。她的原则"该赔的赔，不该赔的不赔"，最后要用在自己最在乎的人身上。
- **每一单的小冲突**：骗子和弱者往往长得很像，哭得一样惨，委屈得一样真。她每次都要先分清"这一单该不该赔"，再当面给出答案。这个判断本身就是悬念。

### 5. 开篇钩子（前三章 / 短剧前 6–8 集）

**第一章：领奖台上被抓**
公司年会，林照刚领到"年度金牌调查员"奖杯，大屏突然切成一份审批记录：3000 万仓库纵火案的赔款已经打出去了，审批人是她的工号，后面还附着一张"受贿转账截图"。警察在会场门口等着。师父顾承山红着眼走上台，劝她"自己走出去，还能体面一点"。
她只提一个要求：**给我十分钟，和这份卷宗。**
（开篇 300 字内进入冲突，第一个画面就够短剧做第 1 集。）

**第二章：十分钟当众拆案**
- 申报烧毁的 2 万箱羽绒服：仓库地磅的过磅记录显示，入库那天货车是空车进、空车出。烧掉的是空箱子。
- 审批签字：系统显示用她工号登录的 IP 在总部，可她当天人在 300 公里外查另一个案子，高速 ETC 记录可以证明。
- 骗保老板当场被警方带走，全场哗然。第一个大爽点在第二章兑现。

**第三章：没赢干净**
骗局拆穿了，盗用她工号的人却查不出来。为了平息舆论，公司把她调去全公司最烂的部门："投诉与疑难件组"，专门处理闹事、上访、拒赔三次以上的烂摊子。
散场时，顾承山拍拍她的肩："我教你的，你都学会了。"
**章末钩子**：发配第一天，她接手的第一单是一位癌症母亲的重疾险，被公司拒赔了三次。三份拒赔意见书上的签字人，都是顾承山。

> 前三章兑现的承诺：主角很强（当众拆案），世界不公（被陷害、被发配），主线敌人已经露脸（师父），双向爽点都已经开门（打骗子、帮弱者讨赔）。

### 6. 爽点从哪来

| 爽点类型 | 具体来源 | 出现频率 |
|---|---|---|
| **智商碾压 / 当面拆穿** | 每单高潮都是一场"理赔对质会"，骗子自以为天衣无缝，被她一条证据接一条证据拆到崩溃 | 每单元 1 次大爽点，短剧每 3–5 集一次 |
| **双向打脸** | 打骗子（爽在正义），也打公司里拿条款坑人的领导（爽在以下克上）。两种轮换，不容易腻 | 交替出现 |
| **地位逆袭** | 被发配的边缘组慢慢变成全公司最难啃也最能打的部门，看不起她的人回头求她接案 | 每卷一个台阶 |
| **底层正义 / 共情爽** | 帮被拒赔的老人、病人、外卖骑手拿回该得的钱，"该赔的一分不少" | 穿插在打脸单元之间，做情绪低谷和回升 |
| **行业知识爽** | "原来骗保还能这么玩""原来这条款是这么坑人的"，读者有获得感，也方便短剧做切片传播 | 每单都有 |
| **主线收网** | 每单留一条内鬼线索，读者跟着拼图。师徒对决时，她用他教的招数反将一军 | 卷末大爆发 |

**防疲劳设计**（依据 `pleasure-fatigue-management`）：
- 类型轮换：车险、健康险、寿险、财产险、新型险种（退货运费险、航班延误险、宠物险）交替，场景不重样。
- 强度波浪：小案（碰瓷）、中案（团伙）、大案（产业链），中间插温情案缓冲。
- 规模升级：个人骗保，然后团伙，然后修理厂 / 医院产业链，然后公司内鬼，最后资本层。

### 7. 打算写多长，为什么撑得住

**网文：80–120 万字，分 5 卷**
| 卷 | 内容 | 字数 |
|---|---|---|
| 一 | 被陷害、发配，在疑难组立住脚，拿下第一批漂亮案子 | 约 20 万 |
| 二 | 破碰瓷和骗残团伙，查出修理厂链条，第一次和师父暗中交手 | 约 20 万 |
| 三 | 医院 / 中介骗保产业链，疑难组升格，她回到总部视野 | 约 25 万 |
| 四 | 公司内鬼浮出，师徒正面对决，揭开父亲旧案的真相 | 约 25 万 |
| 五 | 资本层清算，"最后一单"，她坐上师父原来的位置 | 约 15–20 万 |

**短剧：第一季 80–100 集（每集 1–2 分钟），对应第一、二卷**，以"拆穿修理厂链条，师父第一次露出破绽"收季，给第二季留钩子。

**为什么撑得住：**
1. **素材几乎用不完**：险种多，骗保手法多，现实新闻里每年都有新案例（"大学生航班延误险骗保"、"退货运费险薅羊毛团伙"这类都上过新闻）。单元案可以一直换。
2. **结构自带发动机**：单元案保证每段都有完整的起承转合和爽点，主线拼图保证读者追读。这种"单元 + 主线"结构不依赖作者硬造新地图、新境界。
3. **双向爽点不单调**：同样是拆案，有时她是挡骗子的盾，有时是替弱者讨钱的刀，读者的情绪位置一直在变。
4. **主线有天然终点**：师父倒台，再加资本层清算，故事有收口，不会无限注水。100 万字左右正好写完，不硬撑。
5. **短剧成本低**：主场景是办公室、医院、修车厂、事故现场、会议室，没有特效和古装，适合中小制作。单元案可以单独剪成切片投流。

## 三、选题评分（`novel-genres` 选题评分表）

| 维度 | 分数 | 说明 |
|---|---|---|
| 平台匹配 | 5 | 番茄女频大女主、职场复仇，短剧女频逆袭打脸，都是主力品类 |
| 作者储备 | 3 | 需要基本的保险理赔常识，靠"每单只深挖一个疑点"控制资料量，详见下方风险 |
| 读者承诺 | 5 | 一句话就能说清：看她当面拆穿骗子、替老实人讨钱 |
| 前三章钩子 | 5 | 第一章被抓，第二章拆案，第三章发配加新钩子，核心冲突前三章就兑现 |
| 差异化 | 4 | 保险理赔这个职业少见，"双向打脸"有辨识度，但"职场复仇"的大框架同类多 |
| 风险成本 | 4 | 审核风险可控，资料成本中等 |
| **总分** | **26 / 30** | **区间 24–30：可以开书** |

**最高风险：作者储备**
理赔行业的细节（条款、调查流程、骗保手法）是本书质感的来源，也是最吃作者储备的地方。

**决定：保留保险理赔职业，不换。** 理由：
- 它的差异化和"双向打脸"卖点都长在这个职业上。换成审计、二手车评估等职业，骨架能平移，但"替被拒赔的老实人讨钱"这一半爽点会变弱。
- 资料量可控。每单只围绕一个可验证的硬疑点展开（地磅记录、ETC 记录、病历时间线、维修工单），读者要的是"被拆穿的那一下"，不需要整套理赔流程。开书前备一份 10 单左右的案例库（来自公开新闻和裁判文书里的骗保案），就够支撑第一卷。
- 兜底：如果试写阶段发现资料跟不上日更，可以把主角职业平移到审计师或医疗纠纷调解员。被陷害、发配、单元拆案、清算师父这套骨架不用改。

**其他风险**
- **合规**：骗保手法只写"怎么被拆穿"，不写成可照抄的操作步骤，避免"教唆犯罪"。保险公司的负面写成"内部蛀虫"，不写成整个行业黑，避免短剧审核和行业投诉。
- **节奏**：单元案容易写成流水账。每单必须留一条主线线索，卷末必须有一次主线大推进。

## 四、下一步

选题已定稿，按评分区间可以直接进入大纲阶段（不在本步范围内）。建议的顺序：
1. 整理第一卷的案例库（约 10 单，每单标注险种、骗局手法、拆穿用的硬证据、留下的主线线索）。
2. 用 `novel-character-design` 细化林照和顾承山的人设与弧光。
3. 用 `novel-pacing` 做第一卷大纲和前三章的分章 / 分集节奏。
