## 1. 林素秋（`char_lin_suqiu`）｜女主

**61 岁｜禾茶总部 18 层的外包保洁员｜前注册会计师，江湖人称"林算盘"**

**外形锚**：身高约 158，偏瘦。花白短发齐耳，左耳后别一只黑色发卡。灰蓝色物业保洁服，戴黄胶手套；左胸口袋永远插一支红笔，内兜装着红色硬皮本。指节粗大，有老茧，那是三十年拨算盘留下的。平时眼神慢半拍，一算账就突然锐利。
**2005 年版（闪回/E50 后）**：41 岁，齐肩黑发，藏青色审计夹克，左胸别着事务所徽章（`cos_lin_audit`）。
**声线锚**：中低音，带一点江南口音，句子短、语速慢。报数字时一字一顿，从不因为激动加快。她从不喊。

### 她是谁

江城正元会计师事务所当年最年轻的高级审计经理。她查过的账没有一笔平白放过，同行说"林算盘拨一下，假账就响"。2005 年，她发现最得意的徒弟顾怀山借丈夫陈建国的厂子骗贷。顾怀山先伪造她的签字，再拿丈夫的前途逼她认罪。她选择替丈夫扛下来：执照被吊销，名声烂了二十年。丈夫第二年去世，儿子从此恨她。

此后她给小店记账，在写字楼扫地。她没离开过数字，也没再碰过真正的账。半年前确诊早期阿尔茨海默病之后，她托人进了儿子公司所在楼层的外包保洁组。她说不清自己为什么来，只知道想离儿子近一点。儿子儿媳在公司装作不认识她，她也配合着装。

### 五栏

| | |
|---|---|
| **Wants（主动追求）** | 赶在记忆消失前，阻止儿子被何骏和顾怀山做成替死鬼 |
| **Needs（长期要学会）** | 不再"替人扛"；学会让家人帮她记住，也让真相自己站出来 |
| **False belief** | "替家人把罪扛下来，就是保护他们。""病不能让任何人知道，知道了我就没用了。" |
| **Power** | 数字过目不忘、心算交叉验证；能看出"账和物对不上"；三十年的审计习惯：凡事记录、每页写校验码 |
| **Cost** | 早期阿尔茨海默：认不出新的人脸，记不住"今天几号"，压力下会断片、走失。数字和旧事最后才会忘 |

### 为什么不能一次亮牌

1. 她有前科，执照也没了，单凭她的话没有分量，只能一张一张地放物证。
2. 病一旦被发现，证言可能作废，儿子也会把她送走。
3. 说出 2005 年的真相，就等于毁掉儿子心里干干净净的父亲。

### 人物弧

隐身扛事（E1–9）→ 被迫亮明身份和病情（E10–20）→ 发现扛不住，开始让家人和盟友分担（E19、E24、E41）→ 亲口承认"替人扛，账就永远不平"（E43）→ 在"回到 2005 年"的状态下，仍然选择上台作证（E52–56）→ 名誉恢复，接受遗忘（E59–60）

### 标志动作与台词

- 拖地永远从左往右、一格一格（E3 埋下，E34 被顾怀山认出）
- 签名时"秋"字末笔多一个点（E21 用来识破伪造，E59 回收）
- **"人会忘，账不会。"**
- **"账平不平，不看谁赢，看钱去哪了。"**
- "我不知道今年是哪年。但我知道那笔钱去了哪。"（E56）

### 禁用表演

不哭喊，不撒泼，不靠倚老卖老取胜。她的威慑力全部来自平静地报出一个数。

## 2. 陈屿（`char_chen_yu`）｜儿子

**35 岁｜禾茶创始人兼 CEO**

**外形锚**：身高 180，清瘦。深色衬衫，不打领带，左腕戴一块旧电子表（父亲的遗物）。眉眼和年轻时的陈建国相似，E40 母亲把他认成亡夫要靠这一点，生产上必须锁定。
**声线锚**：偏低沉，习惯压着情绪说话。越在意，句子越短。

### 他是谁

15 岁那年家里的厂子倒闭，16 岁父亲去世。他认定是母亲"做假账"毁了这个家。18 岁离家后，他从一家奶茶小摊做到全国连锁"禾茶"，最怕别人说陈家不干净。他想靠资本证明自己，于是把专业的事全交给了"专业的人"——CFO 何骏。

### 五栏

| | |
|---|---|
| **Wants** | 拿下 B 轮，把禾茶做上市，证明陈家人是干净的 |
| **Needs** | 承认数字不能外包，真相也不能；承认父亲也会犯错 |
| **False belief** | "我妈毁了我爸，我绝不能变成她。""签字交给专业的人就行。" |
| **Power** | 创业者的韧性，团队和加盟商的信任，公司控制权（E33 失去） |
| **Cost** | 对赌协议里的个人无限连带担保：查得越深，他越可能进去 |

### 人物弧

当众切割母亲（E1–2）→ 和母亲打赌"你能证明，我就停签"（E6）→ 求她别查（E7）→ 得知病情后愧疚（E11）→ 公开说"我相信数字"（E20）→ "她是我妈，她说的账我信"（E30）→ 失去禾茶（E33）→ 读到父亲的信，二十年的恨落了空（E40）→ 每天早上向母亲做自我介绍，开始学她的方法（E41）→ 当众认下父亲的罪："今天这笔账，我们家自己认"（E57）

### 标志台词

- "她说的数，一个都别信。"（E2）
- "我相信数字。数字是对的。"（E20）
- "妈，我是陈屿，您儿子。"（E41 起每天早上说一次）

## 3. 苏蔓（`char_su_man`）｜儿媳｜第二主线

**33 岁｜禾茶品牌总监**

**外形锚**：米白色套装，低马尾，珍珠耳钉，指甲干净、没有颜色。E33 之后换成素色针织衫。
**声线锚**：清亮、职业化。紧张时语速变快，真心话会突然慢下来。

### 她是谁

退休银行行长苏启明的独生女，从小被教育"体面就是一切"。"禾茶"这个品牌是她一手做起来的。投资人做背调时会看创始人家庭，她怕一个"有前科的农村保洁婆婆"毁掉融资，所以在签约厅里说了那句"不认识"。她不坏，只是太怕被人看低。

### 五栏

| | |
|---|---|
| **Wants** | 保住这个家，保住禾茶的体面 |
| **Needs** | 明白真正的体面是敢认错，哪怕错的人是自己的父亲 |
| **False belief** | "家丑不能外扬，先私下解决就能保住所有人。" |
| **Power** | 品牌和媒体资源，银行世家的人脉，对婆婆日常的了解 |
| **Cost** | 越接近真相，越接近父亲的罪 |

### 人物弧（全剧的镜像线）

"不认识"（E1）→ 扔掉算盘，又在当晚折回去偷偷捡回来（E6，E22 揭晓）→ 派出所里第一次看见婆婆的脆弱（E9）→ 当众说"她是我婆婆"（E10）→ 在算盘里发现钥匙和父亲支行的名字，瞒了下来（E22–24）→ 趁婆婆断片带她去开箱，想先劝父亲自首（E27，E30 揭晓）→ 父亲背叛她（E32）→ 当众自证"是我拿走的"（E39）→ 交出父亲的小账本（E48）→ 在 E1 的同一个大厅说"这是我婆婆，林素秋"（E59）→ 接过红账本（E60）

**镜像设计**：林素秋当年替丈夫扛，苏蔓差点替父亲扛。婆婆用自己的二十年告诉她："替人扛，账就永远不平。"（E43）

## 4. 顾怀山（`char_gu_huaishan`）｜终极反派｜镜像敌人

**52 岁｜怀山资本董事长，怀山控股实际控制人**

**外形锚**：深灰大衣，金丝眼镜总拿在手里、很少戴上，紧张时会摘下来擦。随身带一支金色定制钢笔，笔身刻着"2005.3.17"，那是他的第一桶金到账的日子，他拿它当战利品。
**声线锚**：温和、彬彬有礼，永远叫她"师父"或"林老师"。威胁人时声音反而越来越轻。

### 他是谁

林素秋带过的徒弟里天赋最高的一个，对数字的敏感几乎和她一样。他比她更早想明白一件事：账是人写的。2005 年，他用师父丈夫的厂子骗贷 470 万，再逼师父顶罪，用这笔钱起家，做成了今天的怀山资本。二十年后，他想把同一个局再做一遍：投资禾茶、虚增业绩、并进上市的怀山控股、高位套现，让陈屿顶罪。

### 五栏

| | |
|---|---|
| **Goal** | 完成禾茶的重组套现，同时把二十年前的痕迹彻底抹掉 |
| **Leverage** | 资本、媒体、律师团、对赌协议、苏启明的把柄，还有她的病 |
| **Belief** | "账从来不平。赢的人说平了，就平了。" |
| **Learning** | E1 发现她认不出人脸 → E16 篡改她的本子 → E20 公开她的病情和前科 → E26 申请排除她的证言 → E38 报警反咬 → E44 成立"关爱基金"，把她包装成可怜的病人 → E50 利用她"回到 2005 年"的状态 → E56 把死去的陈建国拖下水 |
| **Boundary** | "我不碰人，我只改账。"一直不亲手使用暴力。终局时越过最后一条线：用死人的签名，毁掉一个活着的家 |

### 和女主的镜像

同样的天赋，相反的选择。她用数字找钱去了哪儿，他用数字决定别人看见什么。他内心深处真正想要的，是被师父承认。所以 E35 他会邀请她出任总审计师，说"您会被所有人记住"；而她回答"我会忘了所有人，但账不能忘"。最后一句交锋在 E57–58："师父，您还记得我吗？"——"不记得。但我记得你的账。"

## 5. 何骏（`char_he_jun`）｜一阶段主反派

**41 岁｜禾茶 CFO**

**外形锚**：定制西装，常戴单只蓝牙耳机。笑的时候嘴先笑，眼睛不笑。
**声线锚**：圆滑，爱用"阿姨""老人家"这类软刀子。

| | |
|---|---|
| **Goal** | 帮顾怀山做完禾茶的局，拿到怀山控股的股份，套现出国 |
| **Leverage** | 财务系统，陈屿签过的每一张签字页 |

## 6. 周小满（`char_zhou_xiaoman`）｜青年盟友｜观众代入

**25 岁｜华衡会计师事务所审计助理（入职一年），后任禾茶内审**

**外形锚**：黑框眼镜，事务所工牌，旧双肩包，格子衬衫袖口有点磨毛。
**声线锚**：说话快，紧张时会结巴，认真起来突然很稳。

农村出身，背着助学贷款，母亲的医疗费还欠着债。他怕事，但心里有一条线：自己签过字的东西必须是真的。林素秋没有执照，不能签字，他就是她"签字的那只手"；她教他的不是技巧，是"先看物，再看账"。

**弧**：E1 脱口说出"数是对的" → E3 拒签尽调报告 → E4 撞见她的病并替她保密 → E26 被华衡开除 → 加入禾茶做内审 → E45 面对收买（替母亲还债），转身录下方致远行贿的全过程 → E60 继承她的方法。

**标志台词**："……数是对的。"

## 7. 黎川（`char_li_chuan`）｜反派阵营里的暗中盟友

**34 岁｜顾怀山的特别助理（已跟了 8 年）**

**外形锚**：黑西装，面无表情，左手戴一块旧机械表（母亲的遗物）。
**声线锚**：平、短，从不多说一个字。

**表面**：顾怀山最冷静、最高效的执行者。
**真相**：母亲黎秀英是 2005 年老城支行的柜员，被苏启明拿去顶罪入狱，出狱后不久就病逝了。他进怀山就是为了找证据。

**伏笔**（每一处看起来都只是"办事公正"）：E2 逼王翠芬道歉；E3 亲手拨通"仓库"的电话；E20 寄出匿名快递；E27 雨夜第一个找到走失的她；E33 把她派到 32 层。
**揭晓**：E37。林素秋审他的账，发现他八年来每月往同一个墓园转账，户名是"黎秀英"。
**结局**：E58 把判决书放到母亲墓前。

**声线锚**：官腔，口头禅"按规矩办"。林素秋认不出他的脸，却认得这句话（E14）。

| | |

| **Belief** | "我只是按流程签了字。" |

## 9. 王翠芬（`char_wang_cuifen`）｜保洁领班｜先敌后友

**50 岁｜外包保洁公司领班（同一家公司也负责怀山大厦）**

**外形锚**：圆脸，烫小卷，腰上挂一大串钥匙，嗓门大。
欺软怕硬，爱占小便宜，但护着手下。E1 被何骏的人利用来栽赃；E2 当众道歉；E8 林素秋帮整组保洁算清被外包公司克扣的加班费，她从此死心塌地。她的保洁网络是全剧最接地气的"情报系统"：E33 介绍林素秋进怀山大厦，E36 配合"大扫除"，E46 从垃圾里翻回被偷的本子。
**标志台词**："保洁的，什么垃圾没见过？"
