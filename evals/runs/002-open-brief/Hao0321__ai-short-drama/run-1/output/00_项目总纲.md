# 《账不会忘》项目总纲

> 竖屏短剧｜60 集｜每集 1–2 分钟
> 交付清单：本文件（总纲，供参考）→ `01_主要人物小传.md` → `02_60集分集大纲.md` → `03_第1-3集剧本.md`

## 一句话推荐

**一个被儿子当众切割的外包保洁老太太，其实是二十年前被冤枉的"铁算盘"审计师。她看一眼报表就能算出假账，却得了阿尔茨海默病。她要赶在忘记儿子的脸之前，拆穿把儿子推出来顶罪的融资骗局。**

选它的原因是：
- **熟悉的爽感**：扫地老太太掀翻融资局，属于"马甲/隐藏大佬"，观众一秒就懂。
- **新鲜的机制**：她的金手指（数字过目不忘）和她的代价（记忆病）长在同一个人身上，反派还会把她的病当武器。
- **情感底座**：母子误会二十年、婆媳从"不认识"到"她是我婆婆"，这条家庭追悔线能撑到 60 集。

### 投放标题备选（包装测试用，故事不变）

1. 儿媳当众说不认识我，我一句话让 B 轮融资当场暂停
2. 扫地老太太算了一笔奶茶账，整个签约厅安静了
3. 她记得每一笔账，却开始忘记儿子的脸

```yaml
audience_promise: 每个小弧，她都用一个能看见、能验证的"账与物对不上"打一次脸，同时病情往前推一格
season_question: 她能不能赶在忘记儿子之前，把今天的账和二十年前的账一起算清？
fresh_twist: 主角的能力和代价是同一个器官。反派学会利用她的病：篡改她的外接记忆、申请排除她的证言、用"关爱基金"把她包装成可怜病人
ai_advantage: 用"数字之河"把心算过程画出来；2005 年和今天的街景叠在一起；刷单机房、废品山这类实拍成本高的奇观
ending_contract: 顾怀山伏法，二十年冤案撤销，母子和婆媳和解；病不会被治好，她终将遗忘，但她在遗忘前赢了
```

### 三层张力

- **外在**：融资骗局倒计时、对赌、重组表决。
- **人际**：儿子恨她二十年；儿媳嫌她丢人，后来又在"父亲和真相"之间摇摆。
- **内在**：她的错误信念是"替家人扛下来就是保护他们"，最后要学会让真相自己站出来，也学会让别人帮她记住。

## 世界规则：红账本与病（主角的"系统"）

| 规则 ID | 能做什么 | 不能做什么 | 代价 | 漏洞/反制 |
|---|---|---|---|---|
| R-NUM | 报表、流水、票据看一次就能记住，几秒内交叉验算 | 认不出新认识的人脸，记不住"今天几号" | 数字越清楚，人越模糊 | 反派可以利用"她不认得人"来接近她（E1、E50） |
| R-OLD | 二十年前的事、旧数字记得很牢 | 最近几天的事会断片 | 疲劳和情绪冲击会诱发短暂断片或走失 | 压力就是武器：反派故意在关键节点施压（E9、E27、E50） |
| R-BOOK | 红账本是外接记忆：每天早上读第一页，每件事都记下时间 | 本子上写什么她就信什么 | 本子一丢，她连前一天都记不住 | 本子可以被篡改（E16–17）、被偷（E46）；补丁是审计校验码（E18 起） |
| R-CHK | 每页末尾写校验码（审计师三十年的老习惯） | 不能防止整本被抢 | 每页多花时间 | 被伪造的页面会自己露馅（E46）；2005 年底稿也带同样的校验码，能证明归属（E39） |
| R-CRED | 只要出示可验证的物证，她的话就有分量 | 单凭她的话没有法律效力（前科＋病） | 每次都得找到"能放上桌的证据" | 反派申请排除证言（E26–29），在股东大会上公开测试她（E55） |

医学表述只做戏剧化处理：不写"治愈"，不宣传任何疗法。上线前请医学顾问审读涉及病情的台词。

## 风险与验证计划

| 风险 | 对策 |
|---|---|
| 病情描写失真或消费病人 | 不写"治愈"；病情只服务于选择和代价；请医学顾问审读；片尾可加关爱提示 |
| 金融犯罪手法被当成教程 | 只呈现"怎么发现"，不呈现"怎么做"；资金路径保持概念化 |
| 儿童角色（念念） | 不写涉险剧情；没有威胁儿童的桥段 |
| 老年人脸和年龄在 AI 里漂移 | 林素秋三视图优先锁定；2005 年版（41 岁）单独建 ID；陈屿和陈建国共享一部分面部特征（E40 的认错要靠这一点） |
| 监管与标识 | 按目标平台的微短剧审核、备案要求处理；AI 生成内容按规定加显式标识和隐式标识 |

**Pilot 验证（E1–3）**：
1. E1 测 premise 可读性：首帧"从保洁车里搜出金笔"和首帧"儿媳说不认识"做 A/B 包装测试。
2. E2 测第一笔爽债的回收是否让人满足：看完播率，以及进入 E3 的比例。
3. E3 测追更：公开反转之后，"七天倒计时"能不能把人带进 E4。
