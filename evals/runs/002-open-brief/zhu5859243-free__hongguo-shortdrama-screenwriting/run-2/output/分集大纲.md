### 一句话故事（主角 + 目标 + 阻碍 + 亮点）

被婆家当"帮工"使唤八年的真掌勺**沈知味**（主角），离婚后要**把自己的名字拿回每一道菜上、再把外婆的「沈记」招牌重新挂起来**（目标），对手是冒名顶替的前夫一家，和他们背后十年前吞掉沈记、如今要把老字号做成料包的餐饮资本**鼎盛**（阻碍）；她手里只有一把刻着"沈"字的刀，和一条一口就能尝出真假的舌头（亮点）。

| 3. 视觉化落地难吗？ | 难度低、辨识度高：开水白菜"一勺扫清"的视觉魔术、灶火、颠勺、菜品特写。主场景集中在 2～3 个室内景 |
| 4. 踩政策红线吗？ | 不踩。无封建迷信、无血腥；"食物中毒"是诬陷且被证伪；调查机关一律虚写；不攻击"预制菜"本身，只打"料包冒充现熬"的欺骗 |
| 5. 有市场依据吗？ | 有赛道依据：离婚逆袭、真假身份、专业碾压（神医/鉴宝类）都是平台常青赛道（见 skill 的 `genre-map.md`）。**说明：本次未扫红果实时榜单**，立项前建议对一遍当周热播/飙升榜 |

### 微创新（课 02 三法）

- **人设创新**：女主不是隐藏千金或战神，是"后厨帮工"——身份低到尘埃里，本事却实打实，观众天然站她。
- **背景创新**：老字号酒楼后厨 → 资本中央厨房。行业细节（吊汤、扫汤、料包、品控抽检）给出新鲜感。
- **金手指具体化**：不用"系统"，用"舌头"。理解成本为零，每集都能拍成名场面。

## 七、合规自查

- **价值观**：女主每一次翻盘都靠手艺与合法程序（公证、日志、抚养权变更），不靠违法手段；渣男、婆婆、资本方都有后果；不美化出轨，不写强制爱。
- **法律常识**：抚养权通过"胁迫签署+自愿变更协议"解决，不拿孩子做赌注；擂台赌约只赌名誉和职业；调查机关一律写作"检测机构""调查人员"，不出现真实机构名称。
- **行业表述**：不贬低"预制菜"品类本身，只针对"料包冒充现熬、欺骗消费者"。
- **表现尺度**：无血腥；伤害只写"烫伤、手腕抽搐、夹板"；未成年人只写被利用的后果，不渲染欺凌过程。
- **称谓与机构**：江城、鼎盛、陆氏、江城烹饪协会均为虚构。
