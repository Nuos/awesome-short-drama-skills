# 逐集规划（分集子代理的对齐基准）

单集 1.5 分钟（90 秒）。付费卡点：第 10 / 20 / 30 / 40 / 50 集——这五集集尾必须是全剧级强悬念，`hook` 字段以「【付费卡点】」开头。
场景 ID：S01 民政局 / S02 苏记点心铺 / S03 小两居 / S04 顾氏总部 / S05 顾家老宅 / S06 苏家客厅 / S07 医院病房 / S08 酒店宴会厅 / S09 老街 / S10 美食大赛演播厅 / S11 废弃仓库
马甲规则：第 1–19 集苏念不知道顾承宴是总裁；她以为他是顾氏普通项目经理（同姓是巧合，他说顾姓在本市很常见）。第 20 集集尾掉马。第 21 集起她知道。奶奶在第 1–15 集住院（S07），第 17 集出院回老宅，第 18 集寿宴前苏念不去老宅（避免掉马）。

## 第一幕 闪婚（1–10）
1. S01。苏念在民政局门口等周子昂领证。周子昂搂着苏晴来，苏晴说怀孕了，周子昂当众退婚，嘲笑苏记那破店不值他一块表。长椅上顾承宴刚挂掉奶奶电话（今天不结婚就不做手术）。苏念转身问他结不结婚，他答应。领证【B01】。集尾：两人拿着结婚证（P01）走出来，周子昂嗤笑一个打工的；顾承宴手机亮起，来电备注「奶奶·手术室」。
2. S03。顾承宴自称顾氏项目经理，拿出婚前协议（P02）：一年、互不干涉、互不动心。苏念签字。陈默连夜租好的小两居漏洞百出（总裁不会用燃气灶）。苏念发现他胃病，煮了一碗面，他尝出了味道，愣住。集尾：他说明天带她去医院见奶奶，奶奶要验货。
3. S02。继母刘美琴带苏晴上门收铺，说苏建国已把铺子抵给周家。苏念打开外婆的铁皮点心盒（P03）亮出公证遗嘱，铺子直接留给她【B02】。继母灰溜溜走。集尾：苏晴在门外打电话，说老街要拆，看她能守几天。
4. S07。苏念带桂花糕见奶奶。奶奶尝一口愣住，把传家玉镯（P04）戴到她手上，同意手术【B03】。主治医生推奶奶进手术室。集尾：奶奶对顾承宴低声说了一句，这丫头，是不是当年那家的。顾承宴没回答。
5. S03。同居日常：一张床一条地铺，半夜他胃痛，她起来熬粥。陈默送文件差点喊顾总，改口顾哥。集尾：苏念收到唐果消息，铺子出事了。
6. S09 + S02。苏记门口被泼红漆，老招牌（P07）被拆迁办经理带的人摘下。顾承宴赶到，录像取证报警，人跑了，他亲手把招牌挂回去【B04】。集尾：苏晴躲在街角拍下他上了一辆挂顾氏车牌的车。
7. S06。苏建国生日，苏念带顾承宴回家。继母和苏晴嘲讽他送的茶叶罐寒酸，周子昂炫耀名表。苏建国一闻，认出是有价无市的母树茶【B05】。集尾：苏晴宣布下周和周子昂订婚，请苏念来做点心，看看什么叫豪门。
8. S02。苏晴下订婚宴点心大单，要求苏念到场现场演示，摆明要羞辱她。唐果劝她别接，苏念接了。顾承宴看了一眼订单上的酒店名——顾氏旗下。集尾：苏晴对周子昂说，戒指的事都安排好了。
9. S08。订婚宴。苏晴的钻戒不见了，栽赃苏念偷，宾客围观。顾承宴进场，酒店经理对他弯腰称先生，当场调监控：戒指是苏晴自己塞进点心盒的【B06 major】。苏晴当众出丑。集尾：周子昂盯着酒店经理对顾承宴的态度，起了疑心。
10. S07 + S02。奶奶术后醒来，拉着苏念的手。苏念回到铺子，拆迁办经理贴出强拆通知，三天后拆，盖顾氏集团公章、落款总裁签名（P06）。苏念攥着通知说：我倒要看看这个顾总是什么人。【付费卡点】集尾：身后的顾承宴看清签名，脸色骤变——那不是他签的。

## 第二幕 升温与掉马（11–20）
11. S04。顾承宴回总部，查出是二叔顾远山伪签批的拆迁，当场叫停【B07】。二叔笑着认错说是下面人弄错了。集尾：二叔关门后打电话：那个点心铺，必须拆。
12. S02 + S09。拆迁办经理带人来又接电话撤走，苏念以为是街坊联名起了作用。顾承宴帮她做桂花糕，面粉糊了一脸，唐果在旁边越看越怀疑他不像打工的。集尾：门口进来一个穿高定的女人，要一盒桂花糕，送给她未婚夫顾承宴。
13. S02。林薇薇自称顾承宴未婚妻，说两家早有婚约，嘲讽苏念配不上。苏念亮出结婚证（P01）【B08】，林薇薇哑火。集尾：林薇薇出门给苏晴打电话，两人结盟。
14. S03。苏念吃醋质问，顾承宴解释婚约是长辈戏言。停电，黑暗中意外初吻【B09】。集尾：来电后苏念看着协议（P02）上互不动心那一条，把协议塞进抽屉最底层。
15. S07 + S02。奶奶出院前把苏念叫到病房，说寿宴要她来。苏念回铺子，林薇薇派人订了一千个点心又临时取消，想拖垮她。集尾：苏晴在铺子后门偷看外婆的铁皮盒放在哪。
16. S04。苏念给顾承宴送饭到顾氏大楼，前台（林薇薇的人）把她当蹭饭的赶出去。顾承宴下楼当众牵她进电梯【B10】，电梯门关前他按的是顶楼，他说是去天台吃饭。集尾：二叔站在走廊尽头，看着他们的背影。
17. S05 + S03。奶奶出院回顾家老宅，二叔来探望，提起老街项目，奶奶冷脸。顾承宴回小两居，决定寿宴那天向苏念坦白。集尾：他写好的坦白信被风吹到地上，压在了苏念的鞋下，她没看见。
18. S08。奶奶寿宴，苏念以孙媳妇身份到场，戴着玉镯（P04）。林薇薇和苏晴假意亲近，把她引到人少的休息区。集尾：一声脆响，玉镯碎在地上，苏晴尖叫苏念摔了传家宝。
19. S08。宾客围观指责，林薇薇要求顾家把苏念赶出去。奶奶亮出手上的真镯——寿宴前她怕人使坏，早换了位置；碎的是苏晴准备的假货。酒店经理调出监控【B11 major】。林薇薇苏晴当众出丑。集尾：主持人敲话筒：下面有请顾氏集团总裁致辞。
20. S08。苏念回头，走上台的是她的契约丈夫。全场起立叫顾总【B12 major】。她手里的蛋糕掉在地上。台上的顾承宴看着她。【付费卡点】集尾：苏念转身就走，顾承宴扔下话筒追出去，宴会厅门在他面前关上。

## 第三幕 冷战、追妻、栽赃（21–30）
21. S09 + S03。苏念在老街夜里一个人走，顾承宴追上解释，她甩开手。回到小两居收拾行李。集尾：她从他抽屉里翻出那张拆迁通知复印件——总裁签名，和结婚证上的签名一模一样。
22. S02。苏念搬回铺子住，认定他闪婚就是为了骗铺子。顾承宴每天来铺子门口站着，她不开门。陈默来解释被扫帚赶走。集尾：苏晴在铺子外看着这一幕，笑着给二叔发消息。
23. S02。顾承宴带律师来，当面做笔迹鉴定：拆迁合同（P06）上的签名是伪造的【B13】，他是被冒名。苏念动摇，问是谁。集尾：顾承宴说出二叔两个字，苏念想起外婆生前提过的某个人，却没想起来。
24. S06。苏建国来铺子劝女儿，被刘美琴拽回家吵架；刘美琴得知女婿是顾总，转头逼苏念回顾家，想沾光。苏念当场拒绝。集尾：刘美琴转身联系林薇薇，要卖苏念的消息。
25. S02 + S09。顾承宴在铺子门口支了个小桌，学做桂花糕，做坏了十几屉，引街坊围观。苏念心软，出来尝一口，说太甜了，又说回家吧【B14】。集尾：两人回家路上，一辆车远远跟着。
26. S03。和好后的甜：他第一次正式下厨，她教他。他说协议的事可以重新谈，她装没听见，耳朵红了。集尾：周子昂堵在小区门口，手里拿着苏晴的孕检单——是假的。
27. S09。周子昂发现苏晴假怀孕骗他，回头纠缠苏念说自己被骗、要复合。顾承宴下车，一个电话终止周家公司所有顾氏分包【B15】。周子昂当场跪下求饶。集尾：周子昂被拖走前喊：你以为苏晴是一个人在搞你们吗。
28. S02。苏记早上开门，几位客人吃完点心上吐下泻送医，卫生局来封店，网上骂声一片，苏念被网暴。集尾：苏念在后厨发现一包不属于她的添加剂。
29. S02 + S07。唐果翻出铺子门口的监控，凌晨有人撬后门进来，是拆迁办经理。唐果开直播放出监控，医院化验也证明是外来添加剂【B16 major】。苏记解封，舆论反转。集尾：拆迁办经理被抓前一直看着同一个方向——二叔的车。
30. S10 + S02。全市美食大赛开始报名。苏念回铺子，发现铁皮盒（P03）被撬过，秘方原件不见了。电视里，苏晴作为选手代表接受采访，说要用她的独家桂花糕秘方参赛。【付费卡点】集尾：苏晴对着镜头笑：这个方子，是我外婆传下来的。

## 第四幕 美食大赛（31–40）
31. S02 + S04。苏念决定参赛，唐果当助手。顾承宴想动用关系，她拒绝，要堂堂正正赢。二叔在办公室把一叠钱推给大赛评委。集尾：评委收下钱，问那个苏念要怎么处理。
32. S10。海选，苏晴当众嘲笑苏念的手工点心土气。苏念以海选第一晋级，苏晴压线【B17】。集尾：林薇薇以赞助商身份坐上评委席旁边。
33. S03 + S02。备赛的夜，顾承宴陪她练到凌晨，她靠着他睡着。他把外套盖在她身上。集尾：铺子的监控画面里，有人在夜里溜进了原料间。
34. S10。复赛，评委故意刁难苏念的点心外形，林薇薇带头起哄。苏念用一道外婆的老式花样说服另外两位评委，勉强晋级。集尾：半决赛前夜，原料被调包，她的糯米粉换成了普通面粉。
35. S10。半决赛，苏念打开原料才发现被换，临场改做外婆的老式酥饼，反超晋级【B18】。集尾：苏晴冲着林薇薇吼：不是说一定能拦住她吗。
36. S04 + S03。顾承宴查到评委被收买，想直接揭发。苏念说留到决赛当着全场揭。两人第一次像搭档一样定计划。集尾：二叔在董事会提出顾承宴利用赞助为妻子开后门，要他回避。
37. S10。决赛预热，评委当众质疑苏念走后门。顾承宴当场宣布顾氏退出赞助、本人回避，只坐观众席为她鼓掌【B19】。记者疯狂拍照。集尾：苏晴在后台翻开偷来的秘方，最后一页是空白的。
38. S10。决赛第一轮，苏晴照着秘方做桂花糕，颜值很高。苏念不慌，做的是一模一样的桂花糕。评委打分苏晴领先。集尾：苏念说，桂花糕还差最后一步，你知道是什么吗。
39. S10。决赛终轮，苏念做出外婆的最后一步（秘方原件上没写，只在她手里），苏晴的糕放凉就塌了。苏念夺冠，记者面前评委崩溃承认收钱【B20 major】。苏晴被取消资格。集尾：苏晴被拖下台前喊，是二爷让我偷的。
40. S02。夺冠当晚，苏念整理铁皮盒，发现盒底有夹层。夹层里一张旧照片：小时候的她牵着一个满脸是伤的少年【B21】。【付费卡点】集尾：照片背面是外婆的字——那天追来的人，叫他二爷。

## 第五幕 旧案与契约到期（41–50）
41. S03。苏念拿着照片回家，顾承宴不在。她在他书房看到同一个少年的照片。集尾：顾承宴推门进来，看见她手里的两张照片。
42. S03。顾承宴承认自己就是那个少年，十四岁被绑架逃出来躲进苏记，那块桂花糕是他十五年里尝到的唯一甜味【B22】。民政局那天他就认出了她发间的桂花发夹。集尾：苏念问那天追来的二爷，是不是二叔。
43. S05。顾承宴带苏念回老宅见奶奶，奶奶证实当年报案时绑匪提过二爷。二叔进门，看见苏念手里的照片，笑容僵了一秒。集尾：二叔离开后打电话给林薇薇：明天的董事会，提前。
44. S04。董事会，二叔联合林薇薇家股份发难，要罢免顾承宴。苏念闯进会议室，带着律师送上拆迁合同伪签鉴定和项目资金流向【B23 major】。二叔被停职，林薇薇家撤股。集尾：二叔走出会议室，对苏念说：小姑娘，你外婆当年也是这么不知死活。
45. S07 + S02。苏建国住院，苏念去看，父亲终于向她道歉，说要和刘美琴离婚。集尾：苏念回铺子，苏晴浑身湿透站在门口。
46. S02。苏晴被二叔和周子昂一起抛弃，走投无路。她把一支录音笔（P05）交给苏念：里面是二叔让她偷秘方、说要让那铺子和老太太一样消失的录音【B24】。集尾：苏念问老太太是什么意思，苏晴说，他提到你外婆的死。
47. S03。苏念把录音笔交给顾承宴，两人决定先藏起来，等找到当年绑匪一起出手。契约一周年将近，两人都想开口又都没说。集尾：苏念在日历上圈出协议到期日——后天。
48. S03 + S04。协议到期前夜，苏念给顾承宴送夜宵到公司，在门外听见他对陈默说，协议到期就结束，一天都不能多。她没进去，回家收拾行李【B25】。集尾：她给他发消息：明早九点，民政局，把手续办了。
49. S01。苏念在民政局等，顾承宴没来。民政局工作人员认出她是一年前闪婚的那位，问要不要再等等。集尾：手机响了，是陈默。
50. S01 + S07。陈默说顾承宴来民政局的路上刹车失灵出了车祸，正在抢救【B26】。苏念赶到医院，从陈默手里接过顾承宴车上的东西：一个戒指盒和一张新婚书——他说的结束，是结束契约、重新求婚。【付费卡点】集尾：手术室门开，主治医生说，病人可能醒不过来了。

## 第六幕 终局（51–60）
51. S07。苏念守在病床前，第一次说出喜欢他。二叔带着花来探望，假意关心，说集团不能一日无主。集尾：二叔走后，病床上顾承宴的手指动了。
52. S07。顾承宴醒来，和苏念、陈默定计：对外宣布他昏迷不醒，引二叔接管集团露出马脚【B27】。集尾：主治医生按计划对记者宣布病人陷入深度昏迷。
53. S04。二叔接管顾氏，第一道命令就是一周内强拆老街。林薇薇重新投靠。集尾：二叔在办公室对着空气说，大哥家的种，这次一个都不留。
54. S09 + S02。陈默在老街找到当年绑匪，如今是个瘸腿的修鞋匠，一直躲着。苏念用外婆的桂花糕打动他——当年外婆也给过他一块。他愿意作证【B28】。集尾：修鞋摊对面停着一辆车，车窗摇下，是二叔的人。
55. S09 + S11。苏念送证人去警局的路上被二叔的人截走，带进城郊废弃仓库。二叔逼她交出录音笔。集尾：二叔说，十五年前我在那间铺子门口跟丢了一个孩子，今天不会了。
56. S11。苏念拖时间，录音笔其实一直开着录音。顾承宴带警察和陈默赶到，当年绑匪当面指认，录音与证词齐出，二叔落网【B29 major】。顾承宴把苏念护在身后。集尾：二叔被押走时回头说，你们以为林家就干净吗。
57. S08。顾氏召开发布会，顾承宴复出澄清一切，林薇薇涉案被带走，周家破产，刘美琴被苏建国离婚出门。苏晴发来短信，说她要离开这座城市重新开始。集尾：记者问苏念与顾总是不是契约婚姻，台上顾承宴看着她，没有回答。
58. S02。协议到期那天，苏念拿出婚前协议（P02）放在柜台上。顾承宴当面撕掉，掏出一盒自己做的桂花糕，单膝跪下重新求婚【B30 major】。集尾：她咬了一口说太甜了，然后说好。
