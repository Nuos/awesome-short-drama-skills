# 《擦痕》主要人物小传

> 竖屏短剧 · 60 集 · 每集 1–2 分钟 · 女性悬疑 × 母女情 × 逆袭
> 一句话：女儿从富豪家露台坠亡被定为自杀，保洁员母亲隐瞒身份进那户人家做保洁——她擦掉每一处污渍，也擦出每一个谎言；但要扳倒凶手，她得先学会一件比擦地更难的事：开口求人。

---

## 人物关系总览

```
                    【江家·金湾别墅】
   江老太太（母）────────── 刘姐（管家，跟了老太太三十年）
        │
   江振海（真凶）══ 沈曼（续弦，擦掉现场的人）
        │                │
   江屿（前妻之子）      江念（12岁）
        ┊                         小芳（小保姆，目击者）
   ┊ 暗恋 ┊
   陈小满（已故，老太太的陪护）
        │ 母女
   周桂兰（主角，新来的保洁）──── 马春花（胖姐，家政中介，阿姨群群主）
        │                              │
   赵磊（民警，经办此案）          金湾别墅区阿姨互助群（487人）
```

**一张网的绑定物**：满满之死。江家每个人都因为它被绑在一起——一个是凶手，一个擦了现场，一个被栽成嫌疑人，一个是唯一的证人却说不清话，一个被逼着撒了谎。周桂兰走进这栋房子，等于走进一张所有人都不能离开的网。

**三面镜子**：周桂兰、江振海、沈曼三个人信的是同一句话——"这世上谁也靠不住，只能靠自己"。江振海靠它踩着别人爬上去，沈曼靠它把良心卖了换安稳，周桂兰靠它一个人扛了十四年，还把它教给了女儿。全剧要证明这句话是错的。

## 一、周桂兰（主角）

| 项 | 内容 |
|---|---|
| 年龄 / 职业 | 52 岁，家政保洁员，入行十八年，"金牌保洁"，会石材养护、晶面处理、各类去渍 |
| 籍贯 / 住处 | 安徽六安人，来城里二十二年，住城中村一间出租屋 |
| 外形 | 瘦，手大，指节粗，常年戴一副洗旧了的蓝色护膝（跪着擦地用）；头发全白了一半，扎得一丝不乱 |
| 单字性情词 | **忍** |
| 口头禅 | "什么脏都擦得掉，就看法子对不对。" |
| 标志动作 | 擦东西前先用指腹摸一下材质；捡到东西先拍照再收起来（"东家丢了找不着，咱得说得清"）；别人说话时她低头干活，一句都不漏 |
| 标志道具 | **护膝**（跪的象征，后来藏着关键证据）、黄色橡胶手套、手机锁屏上和女儿的合影 |

**前史**
- 2010 年冬，丈夫陈国栋在振海建设"锦江花园"工地脚手架坍塌中死亡，同死三人。包工头卷走赔偿款跑了，公司说"工人是包工头的人，跟我们没关系"。
- **原初场景**：那年腊月，她抱着六岁的小满在振海建设大门口跪了一下午，雨下个不停。一个打伞的男人路过，弯腰给了小满一颗大白兔奶糖，转头对保安说："请她们出去，别让人拍到。"没有一个人帮她。她从那天起认定：**求人没用，咱这种人只能自己扛。**
- 此后一个人拉扯女儿长大，供她读完护理专业。她以为女儿的学费里有一部分是"社会好心人资助"，从没问过是谁。

**外在目标（want）**：证明满满不是自杀，让推她的人认罪。
**内在需要（need）**：放下"一个人扛"，开口求别人帮忙。
**错误信念**："咱这种人，求谁都没用。"——这句话她教给了女儿，女儿就是一个人跑进江家、一个人去拿证据、一个人死在露台上的。她不知道这件事，直到第 59 集。

**她的本事（也是全剧引擎）**
1. **看不见**：有钱人当着保洁的面什么都说，没人正眼看她。
2. **懂脏**：什么污渍用什么药水、谁擦过哪块地、擦得专不专业，她一眼看得出——这是一个能"读现场"的人。
3. **熬得住**：她能跪着擦三个小时的地，也能忍着三个月不露一点声色。
4. **有一张网**：家政圈的老乡、姐妹、阿姨群——她一直不肯用，因为她不求人。

**她的镣铐**：没钱、没权、没学历；身份一旦暴露当天就会被赶出去；她说的话天然没人信（"死者家属情绪激动"）；对手掌握舆论。

**弧光阶梯**
1. 一个人潜入（1–10）→ 2. 一个人查，谁都不信，连江屿也只肯"利用"（11–30）→ 3. 一个人的路走到头：证据被夺、被栽赃、被网暴、被群踢（31–41）→ 4. 雨里，同一个大门口，她没有跪下去，第一次说"我想求你们一件事"（41）→ 5. 带着一群看不见的人一起开口（42–58）→ 6. 摘下护膝（60）。

**对主题的态度**：开场——"只能靠自己"；结尾——"看不见的人，一起开口，就看得见了"。
**她必须守住的一条线**：可以骗、可以藏、可以忍，但不能变成江振海。第 26 集她为套话把老太太逼到摔倒，第 57 集她有机会把江振海推下栏杆——两次她都停住了手。

## 二、陈小满（已故，贯穿全剧的"不在场的主角"）

| 项 | 内容 |
|---|---|
| 生卒 | 1999—2024，坠亡时 24 岁 |
| 身份 | 护理专业毕业，生前四个月在江家做老太太的陪护 |
| 单字性情词 | **亮** |
| 习惯 | 叫妈"老周"，从不叫"妈"；打字从来不打句号；爱吃糖醋排骨，不放葱；手机给"老周"设了专属来电铃声——她自己清唱的童谣《月亮走，我也走》 |
| 出场方式 | 回忆、60 秒语音、U 盘里的视频、江屿的速写本、老太太嘴里的"满满" |

**她做了什么**
- 高中到大学一直拿"振海助学金"。大三那年，资助人回信的落款让她查到：振海助学金的创始人江振海，就是当年爸爸出事那家公司的老板。
- 她没告诉妈。她学的是妈的那一套——自己扛。她应聘进江家当老太太的陪护，陪了四个月，教老太太唱《月亮走》，从老太太清醒的片段里拼出了当年的事：老太太曾是振海建设的会计，留着一本 2010 年的采购原始账，上面有江振海的亲笔批注"扣件按我说的买，出事我兜着"。
- 她找到了账本，藏进了这栋房子里**有钱人一辈子不会进去的地方**——保洁间，一只写着"过期勿用"的消毒液桶里，附一张字条："老周，我就知道你能找着。"
- 9 月 17 日中秋夜，她准备辞职带证据回家，在三楼露台被江振海堵住。她偷偷开了录音。23:4x 坠楼。

**她留下的三样东西**：账本（第 30 集被找到）、U 盘里的视频（第 59 集看完）、手机里的录音（第 40 集出现，第 51 集被毁）。
**她是全剧的启悟者**：最后那段视频里，是女儿告诉妈妈"以后别一个人扛了"。

## 三、江振海（真凶 / 大反派）

| 项 | 内容 |
|---|---|
| 年龄 / 身份 | 56 岁，振海集团董事长，市里有名的"江善人"，"振海助学金"创始人，资助过三百多个贫困生 |
| 外形 | 中等个，微胖，金丝眼镜，笑起来眼角很深的纹；永远穿熨得笔挺的白衬衫 |
| 单字性情词 | **伪** |
| 标志动作 | 记得每个保安、司机、保姆的名字；随身揣大白兔奶糖分给下人；思考时摘下眼镜慢慢擦 |
| 口头禅 | "人呐，要往前看。" |

**前史**
- 皖北农村出身，十六岁上工地搬砖，三十岁当包工头，四十岁成立振海建设。他饿过、跪过、被人往脸上扔过钱。
- 2010 年锦江花园项目，他为省八十万买了劣质扣件，脚手架塌了，死了三个人。他推给包工头和安全员，买通关系压了下来。母亲（当时公司会计）留下了原始账本和他的亲笔批注，从此母子之间隔着一层谁都不说的东西。
- 2011 年他成立振海助学金，第一批受助人就是三名遇难工人的孩子——**用善款买沉默，也买自己晚上睡得着**。

**过度补偿背后的自卑**：他这辈子最怕的不是坐牢，是"被人看出来还是那个工地上的农民工"。体面就是他的命。所以他宁可杀人，也不能让那个账本见光。

**他的刀**
1. 钱：随时能拿出两百万。
2. 名声：媒体、慈善、"江善人"，舆论天然站他那边。
3. 他人的饭碗：小芳的爸爸在他工地上，司机、管家、物业都靠他吃饭。
4. **他比她先知道**：第 15 集他就查到了周桂兰的身份，却不动声色，留着她——因为他翻了两个月都找不到账本，他要让"当妈的"替他找出来（第 33 集揭晓）。
5. 他对沈曼也留了一手：保险柜里那只沾满沈曼指纹的洁厕灵瓶子——真出事了，"擦现场的人"就是"杀人的人"。

**他信什么**："这世上谁也靠不住，只有钱和自己。"——和周桂兰是同一句话，走了相反的路。
**结局**：在他亲手搭的慈善晚宴上、在他推下满满的同一个露台上，自己说出了真相——被三百位宾客和四百八十七个阿姨同时听见。报应等同罪过：他最怕被人看穿，最后被所有人看穿。

## 四、沈曼（江太太 / 前半程的明面对手）

| 项 | 内容 |
|---|---|
| 年龄 / 身份 | 44 岁，江振海续弦 |
| 外形 | 高，瘦，永远一身米白或浅灰的羊绒；9 月以后一直戴薄手套，说是"手过敏" |
| 单字性情词 | **冷** |
| 标志动作 | 用脚推东西（不肯弯腰）；看人先看手 |
| 口头禅 | "少看，多擦。" |

**前史**
- 十二年前，她是江振海前妻的住家护工。前妻病逝后她成了江太太，签了婚前协议——离婚她一分钱拿不到。女儿江念 12 岁，是她唯一的东西。
- 她最看不起保姆，因为她最怕别人记得她也当过。
- 9 月 17 日夜，她看见丈夫从露台进来，白衬衫上有血。丈夫让她"把上面收拾干净"。她是护工出身，不是保洁，拿了最顺手的洁厕灵去擦大理石——酸把石头咬哑了，把她的手也烧脱了皮。
- 丈夫让她把满满的手机扔进人工湖。**她没扔**，偷偷留了下来，当作自己和女儿的"保命符"。
- 第 3 集那条"妈，别查了。"是她发的——那天警方通知江家，死者母亲申请了复查，她想把这位母亲吓回家。

**外在目标**：保住江太太的位置，保住念念。
**内在需要**：不再当共犯；作为一个母亲做一次选择。
**弧光**：敌意、试探（1–19）→ 互相捏着把柄的僵局（20）→ 拒绝交出录音（40）→ 得知丈夫要送走念念、还准备把命案栽给她（46）→ 结盟（47）→ 当众作证，承担自己的法律后果（57–58）。
**她和周桂兰**：两个擦过地的女人。一个爬上去以后假装自己从没跪过，一个跪了十四年还以为只能跪着。第 46 集周桂兰对她说："你也是擦过地的人。擦得再干净，缝里也有。"

## 五、江屿（江家大少 / 先是嫌疑人，后是盟友）

| 项 | 内容 |
|---|---|
| 年龄 / 身份 | 25 岁，江振海与前妻之子；美院肄业，在酒吧驻场画画 |
| 外形 | 高，瘦，黑卫衣，手上永远有炭笔灰 |
| 单字性情词 | **怯**（外面是浪，里面是怯） |
| 标志动作 | 随手在任何东西上画速写——餐巾纸、烟盒、手背 |

**前史**：母亲病逝后他把账全算在沈曼头上。他怕父亲，这辈子没对父亲说过一个"不"字。他暗恋满满，满满只拿他当朋友，还说过一句话扎在他心里："你连跟你爸说个'不'字都不敢。"

**9 月 17 日**：22:00 他在露台向满满表白，满满说她要辞职回家了，哭着拒绝了他。22:30 他去酒吧喝到凌晨三点（警方核实过）。满满的月亮发圈落在他车上。小芳被刘姐授意，说"看见江少和满满姐在露台吵架"——他成了家里现成的替罪羊。

**外在目标**：先是证明自己不是凶手，后是查清楚是谁。
**内在需要**：对父亲说"不"。
**弧光**：嫌疑人（4–10）→ 识破周桂兰身份却替她瞒着（10–11）→ 不肯相信父亲是凶手，和周桂兰翻脸（21）→ 动摇（23）→ 被父亲送出国，自己从机场折回（47）→ 在露台上把父亲从周桂兰身上拉开（57）。
**他的地雷**：速写本里 9 月 17 日那张画——露台上哭着的满满，身后一个看不清的人影（第 10 集引爆）。

## 十、赵磊（民警 / 讲证据的人，不是救星）

| 项 | 内容 |
|---|---|
| 年龄 | 36 岁，辖区派出所民警，经办满满"非正常死亡"的现场调查 |
| 单字性情词 | **直** |

**立场**：他私下也觉得不对劲，但"有遗言短信、没有目击、没有打斗痕迹"，他只能按证据结案。他不是被收买的人，他只是需要证据链。
**他和周桂兰**：他是她最早求过、也最早拒绝她的人（"阿姨，这个不能当证据"）；第 16 集他在江家认出她，没有揭穿；他一路告诉她"不够，还不够"，直到她把证据一样一样凑齐。
**原则**：终局里他到场，是因为周桂兰事先布好了局、通知了他——不是从天而降。

## 十一、江念（12 岁 / 沈曼的软肋）

满满给她补过课，她喜欢"满满姐姐"。第 18 集她问周桂兰："阿姨，你是满满姐姐的妈妈吗？"——全剧第一个看穿周桂兰的人是个孩子。江振海要把她送去瑞士寄宿，这是压垮沈曼的最后一根稻草。
