# 《顶替》主要人物小传

> 竖屏短剧 · 60集 · 每集1–2分钟 · 强连续剧 · 现实题材逆袭

---

## 〇、故事之核（人物设计的坐标）

**Logline：** 县城卖早点的女人去报自考，系统显示她二十年前就读完了本科。拿着她名字当大学教授的那个人，正要回母校讲"教育公平"。她只有一个女儿在读高三，离高考还有八十天。

**核心戏剧动作：** 林小满要拿回自己的名字 → 阻碍是一张盘了二十年的关系网：班主任、教育局长、市里的老领导，还有她自己的母亲。

**主题论点：** 名字可以被偷走，但只有自己开口，它才回得来。

**时代与地点：** 2026年3月—9月。虚构的河西省青禾县（贫困县，近十年才"摘帽"）及省城江州。故事的前史扎根在2005年前后：高考录取还靠纸质档案和邮寄通知书，县招办一个人就能经手档案、户籍和通知书，"顶替"这件事只需要四五个人点头。二十年后，学信网、人脸识别、短视频让旧账一夜之间可以被翻出来，可当年点头的人，如今都坐在更高的位置上。

## 一、主要人物

### 1. 林小满 —— 主角

| 项 | 内容 |
|---|---|
| 年龄 / 身份 | 38岁，县一中斜对面早点摊摊主，单亲妈妈 |
| 外形 | 身高171，在县城女人里很扎眼。常年一件洗薄了的红色羽绒背心，头发扎得很紧，指甲缝里总有面粉 |
| 标志动作 | **弯腰**：对窗口、对领导、对顾客，她总是弯着腰说话；紧张时反复在围裙上擦手 |
| 说话方式 | 短句，青禾口音，能用"嗯""行"答的绝不多说一个字。从不解释自己，先做后说 |

**前史：**
- 1987年冬生于青禾县林家沟村。父亲林有田种地、在砖窑打零工，母亲刘桂芬。
- 2002年以全乡第一考进县一中，分在高三（2）班，班主任王德贵。坐她后桌的是陈卫东。
- **2005年6月**，高考587分（当年一本线552）。她在烟盒纸上记下分数，这张纸她留了二十年。志愿填的是江州大学教育学院，想回县里当老师，志愿是王德贵"帮她参谋"填的。
- **2005年7月【Ghost】**：她站在县一中门口的红榜前，从头找到尾，没有自己的名字。王德贵拍拍她肩膀："志愿报高了，滑档了，复读一年。"
- 同年夏天父亲查出尿毒症，家里拿不出钱。9月她跟同乡去了东莞电子厂，复读的事再没提过。2006年父亲去世。
- 2007年在厂里嫁给工友赵建军，2008年生下女儿。**她坚持女儿随自己姓林**，没跟任何人解释过为什么。2013年赵建军赌博欠债，两人离婚。
- 2014年带女儿回青禾，在县一中斜对面支起早点摊，一摆十二年。摊子没有招牌，熟客喊她"老板"或者"油条西施"。

| 弧光要素 | 内容 |
|---|---|
| **Ghost（前史创伤）** | 2005年7月，红榜上没有她的名字。那一刻她学会了"认" |
| **Lie（相信的谎言）** | "我这样的人，认了才能过日子。别给人添麻烦。" |
| **Flaw（性格缺陷）** | 隐忍到麻木；不会求助，什么都自己扛；在权力面前下意识低头；为了女儿可以把自己的一切让出去 |
| **Want（外在需求）** | 起初：弄清楚怎么回事，同时保住女儿的强基推荐和高考 → 中段：拿回自己的名字 → 后段：让所有经手的人认账，包括另外三个被顶替的人 |
| **Need（内在需要）** | 承认自己的人生也值得被看见；原谅母亲，也就是原谅当年那个"认了"的自己；用自己的名字站直 |
| **矛盾性** | 外在：认命、利索、对谁都笑脸相迎 / 内在：二十年没熄的不甘。她把摊子支在母校对面，铁皮盒里的烟盒纸一直留着，这些都是她自己都不承认的证据 |
| **弧光（A → B）** | 弯着腰问"王老师，我那年考了多少分" → 站直了在台上说"我叫林小满" |

**视觉母题：**
- **弯腰 → 站直**：E1她弯腰凑近自考窗口；E60同一个窗口，她被请进门里，站着填表
- **没有招牌的摊子 → "小满早点"**
- **铁皮饼干盒**："青禾食品厂"字样锈了一半，装着烟盒纸、同学录和一个空了的准考证封套

### 2. 林苗 —— 女儿 / 第二主角

| 项 | 内容 |
|---|---|
| 年龄 / 身份 | 17岁，县一中高三（2）班，和母亲当年同一个班号。年级第六，目标是政法大学法学 |
| 外形 | 校服外套拉链永远拉到顶，耳机挂一边，手机壳贴满便利贴 |
| 说话方式 | 快，爱怼，会用网络梗但不滥用；吵架时声音越来越小，越小越狠 |

**前史：**
- 2008年生于东莞，小学一到三年级在东莞读，2014年跟母亲回青禾。（这段学籍经历在E23–24被利用来卡她的高考资格）
- 小学时被同学叫"油条妹"，从此不让母亲去学校开家长会。
- 初一起每年拿"春苗助学金"6000元，证书贴在家里墙上最中间。她不知道钱是谁出的。
- 父亲赵建军五年没联系过她。

| 弧光要素 | 内容 |
|---|---|
| **Ghost** | 被叫"油条妹"的那几年；父亲离开 |
| **Lie** | "只要我分数够高，就没人能拿走我的东西。"（对分数的绝对信仰，而母亲当年也考到了那个分数） |
| **Flaw** | 骄傲、冲动、嘴硬；嫌弃母亲的职业，又离不开母亲 |
| **Want** | 考出去，离开青禾，别活成母亲那样 |
| **Need** | 明白分数之外还得有人敢站出来；看见母亲 |
| **矛盾性** | 外在：嫌母亲丢人 / 内在：她是全家最像母亲的人，倔、能扛、认死理 |
| **弧光（A → B）** | E5拽着母亲离开杰出校友墙，怕被同学看见 → E55隔着考场铁门冲母亲举手；E57—58母亲上台时她在考场里写自己的名字 |

**戏剧功能：** 母亲的软肋，也是母亲的"嘴"。她懂网络、懂规则条文，E15直播、E28反杀前夫、E49看出"放弃声明"的破绽，三次关键反转都由她完成。

### 3. 刘桂芬 —— 母亲 / 暗线核心

| 项 | 内容 |
|---|---|
| 年龄 / 身份 | 64岁，林小满的母亲，每天凌晨三点半起来给早点摊生炉子 |
| 外形 | 瘦小，手背上有煤火烫出的旧疤。走路低头，推车很快 |
| 标志动作 | **双手背在身后**（2005年她就是这样把EMS信封藏在身后的）；码东西码得很慢、很齐 |
| 说话方式 | 话少，爱用"过去的事了""别耽误苗苗"把话题堵死 |

**前史（全剧底层真相）：**
- 2005年夏，丈夫林有田尿毒症住院，需要3万块。
- **2005年8月9日【Ghost】**：邮递员把江州大学的EMS送到林家沟，女儿在砖窑打工，**签收人写的是"刘桂芬"**。她不识几个字，揣着信封等女儿回家。
- **2005年8月11日**：王德贵上门，带着信封进了屋。他说得很清楚：通知书留下，丈夫的手术钱有人出；不留，什么都没有。她在一份"自愿放弃江州大学录取资格声明"上签了字，又签了一张3万块的收条。王德贵拿走了通知书，空信封留在了她手里。
- 那3万块让丈夫多活了八个月。2006年丈夫还是走了。
- 此后二十年，她从没对女儿说过一个字。空EMS信封藏在腌菜坛底下。她每月往一张定期存折里存钱，存够3万后再也不动，谁都不许碰。
- E2那天夜里，她从铁皮盒里拿走了女儿的准考证。之后试着烧过好几回，每回都在火边抽了回来。

| 弧光要素 | 内容 |
|---|---|
| **Ghost** | 8月9日签收，8月11日签字 |
| **Lie** | "穷人的命就是拿来换的。闺女的前程换男人的命，我没得选。" |
| **Flaw** | 用沉默和操劳赎罪；用"为苗苗好"控制全家；对孙女的高考紧张到病态 |
| **Want** | 守住秘密，让孙女平平安安考出去 |
| **Need** | 说出来 |
| **矛盾性** | 外在：全家最反对女儿"闹"的人 / 内在：全家最想让真相出来的人。她烧不掉那张准考证 |
| **弧光（A → B）** | 按灭女儿的手机屏幕 → 在纪委门口站在女儿身边："我跟你去。" |

### 4. 周婉 —— 顶替者 / 镜像对手

| 项 | 内容 |
|---|---|
| 年龄 / 身份 | 39岁，以"林小满"之名任江州大学教育学院教授、博导，"全国教育公平研究杰出贡献奖"得主 |
| 外形 | 身高158，圆脸，齐耳短发，细框眼镜，浅灰西装。和林小满站在一起差了一个头 |
| 标志动作 | 推眼镜；签名时"满"字总是先写错一笔再描 |
| 说话方式 | 书面、得体、学术腔，爱用"历史遗留问题""结构性困境"这类词。慌的时候说话反而更慢 |

**前史：**
- 1987年春生，父亲周振国。从小是"局长家的女儿"，成绩中下。
- 2005年高考410分，专科线都没过。
- **2005年8月25日【Ghost】**：报到那天，父亲在江州大学门口把通知书塞给她。她在新生登记表上第一次写"林小满"三个字，"满"字写错了一笔。照片里的她哭着。
- 2005—2009年以"林小满"读完本科。2009年父亲托人把她的户籍改成新身份证号，名字没换。之后读硕、读博、留校、评教授。**她拼命工作，研究方向偏偏是农村女孩的教育公平。**
- 2012年试图向父亲摊牌，用手机偷偷录下了那次谈话。录音一直没删。
- 2013年嫁给宋启明。2016年丈夫知道了真相，从此把这件事当成拿捏她、拿捏岳父的筹码。
- 2018年起匿名出资设立"春苗助学金"，资助青禾县的农村女孩，名单上第一个就是林苗。
- **那张录取通知书原件她一直留着，夹在办公室一本书里。**

| 弧光要素 | 内容 |
|---|---|
| **Ghost** | 在登记表上第一次写别人的名字 |
| **Lie** | "只要我比真正的她做得更好、帮更多的人，这个名字就算是我挣来的。" |
| **Flaw** | 自我说服；懦弱；依附父亲和丈夫；用补偿代替认错 |
| **Want** | 保住现在的人生：讲台、儿子、体面 |
| **Need** | 用回自己的名字 |
| **矛盾性** | 研究教育公平的顶替者；偷了一个女孩的人生，又资助了这个女孩的女儿 |
| **弧光（A → B）** | E1在颁奖台上说"我叫林小满" → E58在同一类讲台上说"我叫周婉" |

## 二、重要配角

### 6. 王德贵 —— 第一层对手 / 跑腿的人

- **61岁**，县一中校长，今年7月退休。保温杯不离手，开口闭口"娃"。
- **前史：** 2005年高三（2）班班主任。截下林小满的通知书，上门逼刘桂芬签字，拿了2万块好处费。2006年升副校长，2015年升校长。**他留了一本账本保命**，记着当年四个名字、钱数和"周局"的批示，锁在校长室二号文件柜的暗格里。
- **功能：** 催化角色。每一次施压都是他先出面。
- **弧光：** 软威胁（E2）→ 下跪求饶（E20）→ 被当成替罪羊（E38）→ 中风（E41）→ 实名作证（E49）。他最后站出来是为了自保，不是悔悟，这一点要写清楚。

### 7. 陈卫东 —— 体制内的盟友

- **38岁**，县公安局户政科副科长，林小满高中后桌。离异，女儿陈思思读高二，明年高考。
- **前史：** 2005年考上警校专科。那年暑假在当户籍员的舅舅那儿打杂，见过马国强拎着档案袋来"补材料"。2008年毕业分到县户政科。同学录上有一页林小满写给他的"前程似锦"，他夹在驾驶证里留了二十年。
- **Lie：** "端着这个碗，就别砸锅。"
- **功能：** 镜像角色。他选了安稳，走的是林小满"没得选"的另一条路。
- **微弧光：** 暗中帮忙（E3）→ 被调去看守所（E22）→ 被开除（E47）→ 作证、复职（E59）→ E60来摊上吃早饭，非要付钱。和林小满之间有一层淡淡的情感，始终不挑明。

### 8. 马国强 —— 第二层对手 / 墙头草

- **54岁**，青禾县教育局局长。
- **前史：** 2005年是县招办干事，经手档案和户籍。他的外甥马骏顶替了何建。2009年以教育局名义经办了"周婉"的身份证号更改。
- **功能：** 催化角色。表面笑脸，实际是档案的处理者（E9碎纸机）。
- **弧光：** 发现自己是下一个替罪羊（E43）→ 拿账本换"自首立功"（E50）。

### 9. 宋启明 —— 周婉的丈夫 / 中段主要施压者

- **42岁**，启明教育集团董事长，做高考培训，靠岳父的人脉拿政府项目。
- **2016年起知道真相**，把它当作婚姻和生意里的筹码。
- **功能：** 发展阶段的执行者，负责城管、合同、水军、和解协议、诉讼和软禁妻子。和周振国不同，他会直接动手。
- **弧光：** 不变。E56在电梯口被儿子挡住，退了一步，这是他唯一的"让"。
