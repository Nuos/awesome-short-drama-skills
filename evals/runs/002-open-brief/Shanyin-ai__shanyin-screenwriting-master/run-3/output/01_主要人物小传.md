# 《末班代驾》主要人物小传

> 竖屏短剧 · 全剧60集 · 每集1–2分钟 · 男频都市悬疑 / 复仇逆袭

**一句话：** 十年前，赛车手周野替富二代顶下"醉驾逃逸致人死亡"的重罪。出狱后他终生禁驾，只能借别人的号跑夜班代驾。一天凌晨，后座坐上了当年真正开车的那个人。

**全剧的核心问题：** 2016年11月7日凌晨2:01到2:48，那四十七分钟里到底发生了什么？

## 二、主要人物

### 1. 周野 —— 男主角 / 当年顶罪的人

| 项目 | 内容 |
|---|---|
| 年龄 / 身份 | 34岁。2016年拿过省拉力赛组别冠军。2017年以交通肇事罪（酒后驾驶、逃逸致人死亡）被判十年，减刑后实际服刑七年九个月，2024年7月出狱。驾照被吊销，**终生不得重新考取**。 |
| 现状 | 白天在城中村洗车行打工，夜里**借工友大刘的号**跑代驾，七三分账。出门骑一辆折叠电动车。和姐姐、女儿挤在面馆楼上的阁楼里。 |
| 外形 | 高瘦，背微微塌着，是在里面养成的。进门先看出口在哪。右手背有一道车祸留下的白疤，后脑头发底下有一道缝针的疤。右手腕系着一根褪了色的红绳。 |
| 标志动作 | ① 开车时嘴唇会动，小声念赛车路书："左三……收。"② 中控台上放一只纸杯，装半杯水，过弯时水面不动。这是他仅剩的职业尊严。③ 烟早戒了，摸口袋找打火机的手势还留着。 |
| 说话方式 | 短句，两个字能说完就不用三个字。被逼急了也不吼，声音反倒更低。从不说"对不起"，也从不说"不是我"。<br>示例："看路。""坐好。""我骑电动车。""我跑过吗？" |

**前史（Ghost）：**
2016年11月7日凌晨1:56，鸿山集团续约赞助的酒宴散场，停车场里，喝多了的沈既白抢着要开车。周野正和女友林晚通电话，林晚说："那你让他开呗，明天签赞助，你别这时候扫他兴。"周野把钥匙隔着车顶递了过去，说："开吧，没事，慢点。"
五分钟后到了滨江路三号弯。
他在医院醒来，脑震荡，后面的事一片空白。律师韩振坐在床边告诉他："你撞了人，吓得跑进了江边林子，四十多分钟后才被找到。"他什么都不记得，所以没法反驳。韩振又说："你认下来，判三年。你妈换肾的钱沈总出。"他认了。结果判了十年。母亲在他服刑第二年去世，沈家承诺的手术费只付了第一笔。

**他身上压着两份罪：**
- **钥匙**：真的。是他递的。
- **逃跑**：假的。但十年里他一直信了一半，总在想："万一我真的跑了呢？"

| 维度 | 内容 |
|---|---|
| **Lie（他相信的谎言）** | "我扛下来，家里人就安全。不说话，就不会再出事。" |
| **Flaw（性格缺陷）** | 什么都靠沉默解决：认罪，认命，认账。他以为"忍"是在保护家人，其实是在躲。 |
| **Want（外在目标）** | 一开始只想让沈家离念念远点。后来要找到那张行车记录卡，翻案。 |
| **Need（内在需要）** | 把整件事说出来，**包括自己递钥匙的那一段**。不是为了洗白自己，是要把那四十七分钟还给程家。 |
| **矛盾性** | 表面上认命、低头，什么都能咽下去。心里他最骄傲的就是"开车不晃"。方向盘被夺走了，他心里那根方向盘一直没松手。 |

**季度弧光：从"认了"到"说了"**

| 集 | 弧光节点 |
|---|---|
| E9 | 十年来第一次对人说"没有"，说给女儿听 |
| E13 | 被设局抓无证驾驶，明明能跑，他靠边停车，自己下车 |
| E15 | 拒绝两百万，决定去找真相 |
| E32 | 拿到原始病历：当晚他深度昏迷，根本跑不了 |
| E45 | **回退**：让念念跟着林晚去沈家（老谎言又回来了） |
| E48 | 在认罪书背面亲笔写下"钥匙是我递的" |
| E56 | 把一秒没剪的完整存储卡交出去 |
| E57 | 当着程母的面说出钥匙的事 |
| E60 | 重新考回驾照，第一次合法握住方向盘 |

**选角气质：** 沉默的狼，不是战神。能打，但不炫。

### 2. 沈既白 —— 当年真正的司机

| 项目 | 内容 |
|---|---|
| 年龄 / 身份 | 35岁。鸿山集团副总裁，内定接班人，**11月9日股东大会上接任董事长**。 |
| 外形 | 穿得讲究，领带永远松着一扣，眼下发青。 |
| 标志 | ① **十年没坐过驾驶座**，每晚都叫代驾，哪怕没喝酒。只坐司机身后那个位置。② 手里总有一只旧Zippo，侧面刻着"野"字。是周野的，事发当晚他从车里捡走的。他反复开合，从不点火。③ 每周四晚上让司机把车停在江城一院后门，在车里看一个卖烤红薯的老太太，从不下车。④ 每年11月7日匿名给程家寄两万块。 |
| 说话方式 | 语气轻，爱反问，笑着说狠话。喝多了话变多，只在车后座说真话。<br>示例："叫我什么？""你说还能是谁？""你也在车上。别忘了。" |

**前史（Ghost）：**
十岁丧母，父亲看不起这个"软"儿子。他玩赛车是为了让父亲高看一眼。撞人之后，他第一个电话打给了父亲，而不是120。父亲赶到后，他说过一次："爸，打120吧，她还在动。"父亲伸出手："手机给我。"他把手机交了出去。

| 维度 | 内容 |
|---|---|
| **Lie** | "不是我不救，是我爸不让。"他把自己递手机的那一秒，记成了手机被抢走。 |
| **Flaw** | 软弱。害怕的时候就去欺负比他更弱的人。永远需要别人替他开车。 |
| **Want** | 顺利接任，让"三秒视频"彻底消失，从此没人能拿那一晚要挟他。 |
| **Need** | 自己拿起电话。 |
| **矛盾性** | 对周野一家下手冷酷，却每周去看程母。他恨周野，可坐周野开的车不晕，只有在周野车上睡得着。 |

**弧光：从躲在后座的人，到自己拨出110的人**
E22 第一次让人替他买红薯 → E35 想去自首（伪变化）→ E36 父亲一句"手机是你自己递给我的"把他打回原形 → E41 亲自报案诬陷周野（最低点）→ E49 酒后对大刘说出真话 → E54 拿到原卡，打电话叫周野来接 → E56 当着父亲的面拨出110，自己拉开警车后门。

**选角气质：** 漂亮、苍白、易碎。观众会恨他，也会可怜他。

### 3. 林晚 —— 女二 / "程雨"账号背后的人

| 项目 | 内容 |
|---|---|
| 年龄 / 身份 | 33岁。2021年嫁给沈既白。周野当年的女友，周念念的生母。 |
| 外形 | 打扮素净。手表表带底下压着一根红绳，和周野那根是一对。手腕上还常年套着一根小女孩用的发圈。 |
| 说话方式 | 轻，慢，常用问题回答问题，从不直接说自己想要什么。<br>示例："你会给他们的，对吧？你这辈子只会认。""你要她听这个？" |

**前史：**
孤儿，外婆带大，十几岁就在赛车场前台打工。2016年11月7日凌晨1:57，电话里说"让他开呗"的人是她。出事后她发现自己怀孕了。2017年5月生下念念。2017年12月韩振找上门，给她五十万，条件是离开江城、永远不再联系周野。她把七个月大的念念放在周芸的面馆门口，旁边放了一罐奶粉，去了深圳。从2018年起，她每月给周芸打钱。
2020年她回到江城，进了鸿山集团的子公司。沈既白对她好，是那种带着愧疚的好。2021年她嫁给了他。
2025年3月，她代表沈家去临终关怀医院看望老司机老鲁。老鲁把一张行车记录仪的存储卡交给了她。她听完了全部四十七分钟，也听到了自己的声音。她犹豫了一年半。
2026年9月新学期，她在校门口第一次看见念念扑向来接她的周野。那之后，她用"程雨"这个名字开始行动。

| 维度 | 内容 |
|---|---|
| **Lie** | "真相只会伤人。只要挑对给出去的那一段，所有人都能活。" |
| **Flaw** | 控制欲强，什么都要自己剪辑、自己安排，把操纵当成保护。 |
| **Want** | 让沈鸿山倒台，同时藏住自己那一段。让念念叫她一声"妈"。 |
| **Need** | 把完整的卡交出去，包括她自己的声音。承认自己是当年离开的那个人。 |

**暗线身份：** 白菊头像、昵称"程雨"的匿名账号就是她。她每周给沈既白发三秒视频。10月7日凌晨，她用沈既白的手机"收藏"了代驾司机"刘大勇"，所以第1集那一单不是巧合。

**弧光：从剪辑真相的人，到交出整段真相的人**
E10 现身 → E20 承认自己是"程雨"，提条件 → E44 表面倒向沈鸿山，签下抚养申请 → E46 当着沈鸿山的面烧掉的是一张假卡 → E50 发一条消息让周野脱罪 → E51 仍然只肯给剪掉前四分钟的拷贝 → E56 在弯道上冲周野点了一下头 → E59 法庭上当庭播放她的声音，她没有低头，然后离开江城。

**选角气质：** 安静的刀，看着温柔，其实一直在算。

### 4. 沈鸿山 —— 终极反派

| 项目 | 内容 |
|---|---|
| 年龄 / 身份 | 63岁。鸿山集团创始人、董事长，货车司机出身。 |
| 外形 | 穿得朴素，鞋永远锃亮，谈事的时候常有人跪着给他擦鞋。跟人握完手，会掏出手帕一根一根擦手指。车库里停着一辆1990年的老解放卡车，周末自己拿水管冲。座驾是黑色奔驰，车牌江A·88，十年没换。 |
| 说话方式 | 慢，不带脏字，从不提高音量，爱报准确的数字。<br>示例："你一直说你不记得。不记得好。不记得的人，日子过得长。""那天晚上，手机是你自己递给我的。" |

**前史（Ghost）：** 1990年冬，他疲劳驾驶，在国道上撞死了一个骑车的人，私下塞给家属两万块现金，事情就这么过去了。从那天起他相信：一条命是有价钱的。

| 维度 | 内容 |
|---|---|
| **世界观 / Lie** | "所有事都有价钱。" |
| **Want** | 11月9日把集团平稳交到儿子手上，然后上市。让那一夜永远算在周野头上。 |
| **弧光** | **全剧唯一不变的人（反弧光）。** 他的结局是"价钱"第一次失灵：程母不收他的钱，儿子不再把手机交给他。 |

当晚他做的事：赶到现场，接过儿子的手机，下令"把他抬到林子边上去"，说了那句"再等等"。
E58 在股东大会台上被带走。
