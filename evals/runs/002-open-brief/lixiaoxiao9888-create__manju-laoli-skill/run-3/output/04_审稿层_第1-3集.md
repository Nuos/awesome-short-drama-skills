### 1.3 人情世故清单（每集 ≥3 条）

**EP01**
1. 柜员小郑不肯说收款户名，只肯说绑定手机号——户名属于客户隐私，手机号是她自己账户的信息，说了不违规。
2. 周景川没有在电话里否认，而是说「冷静期一过就转你」——他要的是她这 30 天不闹，按时去领证。
3. 婆婆留便签说「接回去住几天」而不是「带走了」——她不认为自己在抢孩子，她觉得儿媳病了，自己在帮忙。
4. 网约车司机多问一句「你没事吧」——陌生人的善意，反衬家里人一个都没问。

**EP02**
1. 前台小陶热情地说「周先生每次送您到楼下」——在她眼里这是个模范丈夫，她不会想到要怀疑。
2. 周景川带桂花糕回家、把盒子摆正——他在「体面」地结束这段婚姻，也在提醒许棠：你看，失态的人是你。
3. 周景川在家长群里抢先发声——学校、老师、其他家长都会先信「先说话的那个」；他要在许棠开口前把叙事定死。
4. 许棠删掉了「我没有生病」——她清楚一个在家长群里跟丈夫对骂的妈妈，只会坐实「她病了」。

**EP03**
1. 前台把律师调档的事说漏了嘴——她以为许棠知道，在她看来夫妻一体。
2. 方医生肯帮许棠核对签名——冒名一旦属实，她的执业记录和诊所的声誉都要受牵连，核实也是自保。
3. 冒名女人照常来复诊——周景川按次付钱，又没想到许棠会提前埋伏，所以没通知她取消。
4. 周景川第一句话是「说好我陪你上去的」——他在路人和镜头面前演的仍然是体贴丈夫。

## 四、台词拟人化过站卡（抽样 6 条）

> 依据：`dialogue-naturalization.md` §二（词汇）、§三（撒碎屑）、§一（称呼）。全部三集台词已按认症表扫过一遍：书面虚词 0 处（脚本扫描结果），单句 ≥20 字且无停顿的句子 0 处。

**① EP01 SC01**
- 【原句】「我的账户上个月的余额是一百六十万元，请你重新查询一下。」
- 【改写】「不对。上个月还有一百六十万。你再查一遍。」
- 【依据】删主语、拆成三个短句（§2.4）；「不对」先给结论，符合许棠「先报结论再报数」的语言指纹；「查询」改「查」（口语动词）。
- 【人物校验】许棠平均句长约 8 字，这三句分别是 2 / 8 / 5 字 ✅

**② EP01 SC02**
- 【原句】「你把钱转到什么地方去了，请告诉我具体的去向。」
- 【改写】「一百六十万，四笔。转哪儿了，报给我。」
- 【依据】「报给我」是许棠的专属词（会计对数据的说法）；先把数报出来，是她的武器（§五 专属词测试）。
- 【人物校验】✅

**③ EP02 SC02**
- 【原句】「你之所以不记得，是因为你那段时间生病了，这在医学上属于正常现象。」
- 【改写】「在医院，刚生完小满。那半年的事，你很多都不记得了。医生说这很正常。我不怪你。」
- 【依据】周景川说话是完整句，但每句不超过 14 字，像在给客户讲产品；「我不怪你」是他的签名句，表面宽容，实际是把「错」放到她身上（潜台词一层）。
- 【人物校验】周景川语言指纹「啊 / 你看 / 别急 / 我不怪你」✅

**④ EP02 SC02**
- 【原句】「周景川，你这样做的目的到底是什么？」
- 【改写】「……周景川。你到底想干嘛？」
- 【依据】称呼降格：从默认的「景川」切到连名带姓——这是她第一次在他面前这么叫（§1.2「恼火 / 决裂」），已登记进称呼台账；「目的」这个词太书面，改「想干嘛」；前面加省略号，是她刚把颤抖压下去。
- 【人物校验】✅

**⑤ EP03 SC01**
- 【原句】「此外，您的档案已经由一位孟姓律师调取了一份。」
- 【改写】「而且您的档案，上礼拜刚被调走一份。一个姓孟的律师，说打官司要用。」
- 【依据】前台的口吻是年轻、热情、话多：「上礼拜」「打官司」都是口语；「哦 / 呀 / 啦」分布在她其他台词里，和方医生的克制形成区分（§五 遮挡名测试）。
- 【人物校验】✅

**⑥ EP03 SC04**
- 【原句】「你不要再继续这样了，你的行为会让别人认为你确实有病。」
- 【改写】「别跑了，棠棠。你越跑，越像。」
- 【依据】掉尾（§3.2）——「越像」后面省掉的那个字（「疯子」），由观众自己补上，比说出来狠；他在全集最狠的一句台词里用的仍然是小名「棠棠」。
- 【人物校验】周景川「对方越激动，他越轻」✅

## 五、五视角审稿（定稿前自审 · 意见已落实或登记）

**【编剧视角】**
- 评估：三集各有一个完整的「发现 → 应对 → 新压力」单元，主角每集都有主动行动（查账、提前埋伏、抓扣子）。
- 问题 ①：EP02 结尾账本上写着「今日所有文书，景川代签」，几乎直接点破了伪造签名，观众会问：她为什么不立刻报警？
- 问题 ②：周景川在 EP01 电话里说「记得吃药」，有点过早亮底牌。
- 改法：① 不改正文，在大纲里补上回应——EP05 她申请调取 2018 年病历，被告知纸质档案要等十五个工作日；EP08 谭律师明确说「你自己写的账本，法院不认」。观众的疑问会在第 5–8 集得到解答。② 保留：这句是周景川有意埋话，EP02 前台说「周先生每次送您」时会和它接上，形成「他早有准备」的印象。

**【制片视角】**
- 评估：三集共 11 场，场景可复用（银行、家、咨询中心会在后面反复用）。
- 问题 ①：EP03 SC03「手伸进正在合拢的电梯门缝抓住大衣」是 AIGC 高危动作（手穿门、门夹手）。
- 问题 ②：EP01 用了真实品牌（「知味观」「浙里办」），有植入和合规风险。
- 改法：① 正文保留这个动作，但写的是「门在合拢时抓住领口」，没写夹手；**分镜阶段必须拆成两镜**：手抓领口（门还开着）/ 门合上、手心里一颗扣子，不在一个镜头里完成「抓 + 门合上」。② **已改**：「知味观」→「巷口那家」，「浙里办」→「手机上的不动产登记查询」。

**【观众视角】**
- 评估：开场 0.27 的反差足够停住手指；冒名者 + 珍珠扣让悬疑成形。
- 问题 ①：EP02 许棠删掉家长群回复，有观众会嫌她「窝囊」，弃剧风险集中在这里。
- 问题 ②：三集里女儿一句台词都没有，「抢女儿」的情感投入还没建立起来。
- 改法：① 保留删回复（这是她的核心缺陷，第 4 集会让它付出代价），但紧接着让她翻出账本、找到 ICU 记录，用一个主动行动收尾，不让「窝囊」成为她在这集留下的最后印象。② 在 EP07 前不硬塞台词，先用物件建立女儿：EP01 的小雨靴、旧兔子，EP02 的粉色头绳套到许棠手腕上、EP03 继续戴着——这根头绳登记为许棠在 ARC-1 的随身物，EP07 隔门相见时由小满认出来。

**【平台视角】**
- 评估：现实题材，无暴力、无色情；核心痛点（转移财产、抢抚养权）讨论度高。
- 问题 ①：「来访者自述：想带孩子一起走」涉及自伤与未成年人，属于平台敏感表述。
- 问题 ②：EP03 外卖骑手举手机拍摄，可能被理解为在鼓励围观拍摄、传播他人隐私。
- 改法：① 保留，因为它是反派伪造的记录，用途正是展示反派有多狠；但只以卡片文字出现一次，不在任何画面里表现自伤行为、不出现任何方式和细节，后续集只用「那份记录」指代。② 保留，作为「舆论压力」的视觉证据；后续集不让路人视频在网上发酵成情节，避免变成鼓励曝光他人隐私的戏。

**【节奏视角】**

## 七、创作笔记

① **核心情绪**：让观众先「憋」住——一个女人在一天之内发现，钱、房子、女儿，连她自己的名字，全被人拿走了，而拿走它们的人从头到尾都没提高过音量。

② **取舍**：
- 放弃了让周景川一出场就露出狰狞面目。他越温柔，观众越怕；这也是 60 集能撑住的前提——一个一出场就吼叫的反派，十集就会让人看腻。
- 放弃了「闺蜜 / 小三」这条最省事的线。林筱在第 5 集会被所有人误认成小三，第 6 集翻转——用观众的预判制造一次反转。
- 第 1 集不让许棠哭。她的第一反应是算账（「一百六，加三百八……五百四」），这是她和其他苦情女主的区别。

③ **自评不满意点**：
- **EP02 SC02 太长**。我舍不得砍掉任何一次信息翻转，结果一场戏撑了一分多钟。如果分镜阶段拆段后还是显得拖，我会优先删掉「哪个医生？」那一轮来回，让「你看，你又这样」直接接在委托书后面。
- **EP03 的冒名者出场靠巧合撑着**：她「照常来复诊、周景川没通知她」这个前提，审稿层能解释，但正文里没有一句台词交代。观众如果起疑，要到 EP11 许晴说出「按次收钱」才能得到回答，中间隔了 8 集，这是一个风险点。
- **前台小陶的戏份偏工具化**。她在 EP02、EP03 承担了两次关键信息泄露，却没有自己的动机。后续如果要回到这家心理中心，应该给她一个能改变局面的小动作（比如她自己注意到口罩女人每次都从地下车库走）。
