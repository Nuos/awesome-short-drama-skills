# 《我没死，我要离婚》主要人物小传

> 竖屏短剧 · 60集 · 每集1–2分钟 · 真人实拍
> 类型：现代都市 / 家庭 / 中年女性觉醒 + 后悔流 + 事业逆袭
> 目标受众：国内 25–55 岁女性为主
> 本剧为原创，人物、地名、公司均为虚构（临江市、程记装饰、远山城建、梧桐里小区等）。

---

## 一句话梗概

城际大巴出事，家庭主妇姜春禾被当成遇难者。两天后她从医院回来，在自家灵堂外听见丈夫在算她的一百二十万赔偿金。她推门进去，说出"我还没死"。之后她在离婚冷静期里拿回了二十五年来一直署着丈夫名字的设计图，也把自己的名字写回了自己身上。

## 一、姜春禾（女主，46岁）

**身份**：程家主妇，结婚二十五年。临江美术学院环境设计专业肄业。程记装饰过去二十五年的图纸，其实全是她在厨房饭桌上画的，署名一直是丈夫。

**外在形象 / 视觉锚点**
- 前期：低马尾，夹一枚黑色旧发卡；灰、米色开衫，袖口起球；手上有烫伤旧疤；无名指戴一枚磨得发亮的细金戒指。
- 随身道具：铁皮铅笔盒，里面都是削到很短的铅笔头。她画图有个二十五年的习惯，会把一个"禾"字藏在排水坡度线或地砖拼缝里。
- 中期以后：头发剪短，露出耳朵；衣服换成利落的深蓝、白色工装衬衫；手腕上多了一块旧男表，是母亲留下的，后来抵押过一次；戒指摘了以后，无名指上留着一圈白印。
- 允许变化：第11集离家后换装；第40集至暗期憔悴、素颜；第59–60集第一次穿正装，站上讲台。

**性格（表 / 里）**
- 表：话少、手快，什么都先照顾别人，从不争。
- 里：观察力极强，记性好，一眼能看出空间里谁会摔、谁够不着。她的隐忍是一种选择，不是天生软弱。被逼到底的时候，她不哭不闹，只把事实一条一条摆出来。

**核心公式**
- 目标：离婚，拿回属于自己的那一半财产；更要紧的是拿回二十五年的设计署名，让"姜春禾"三个字第一次出现在自己的作品上。
- 阻碍：丈夫撤回离婚申请、伪造她的签名背了三百万贷款、毁她的征信；何曼偷图、抹黑、制造工地事故嫁祸给她；儿子和婆婆拿亲情绑架她；她自己也有二十五年"先顾别人"的惯性。
- 底层动机：穿刺结果出来之前那三天，她一个人面对了"可能会死"。确认是良性以后，她说："我还能活很久，那我不想再那么活了。"

**关键关系**
- 程国栋：曾经爱过，也一直替他兜底。觉醒后不恨，只要一个清楚的结果。
- 程悦：她最心疼的孩子，也是第一个站到她身边的人。
- 程子昂：她最放不下的孩子，也是伤她最深的人（"你回来得真不是时候"）。
- 傅远山：先是甲方，后来互相欣赏。她把感情放在了自己之后。

**弧光（觉醒型）**
围着灶台转、坐在厨房门口小凳上吃饭的"程家媳妇"
→ 在灵堂外看清一切（1–3）
→ 良性结果带来重生感（7）
→ 订婚宴当众决裂（10）
→ 用自己的名字开工作室（13）
→ 经历撤诉、征信被锁、工地事故的至暗期（30–40）
→ 不替任何人兜底，靠证据反击（41–50）
→ 法庭判离，署名权胜诉（53、57）
→ 站上当年没能毕业的美院讲台，在自己的房子里坐上主位（59–60）

**标志性细节 / 台词**
- 第3集："我两天没回来，你们就把我换成了一套房的定金。"
- 第22集，丈夫第一次叫她名字时："你叫我名字，是因为你要东西。"
- 第60集："我死过一回。活回来以后，只做了一件事——把自己的名字，写回自己身上。"

**知情底线**：开局不知道丈夫和何曼同居，不知道贷款，不知道2001年美院寄来的那封"保留学籍"通知被藏了起来（第55集才知道）。

## 二、程国栋（丈夫，50岁）

**身份**：程记装饰老板，公司十五个人。对外是"临江家装金奖设计师"，实际一张图都不会画。

**视觉锚点**：小平头，鬓角发白；常穿深色Polo衫，腰上挂车钥匙；手机永远屏幕朝下扣在桌上；左手腕戴一串何曼送的沉香手串（第23集后被注意到）。
允许变化：第44集后胡子拉碴，Polo衫换成皱夹克；第50集后取保，人明显瘦了。

**性格（表 / 里）**
- 表：要面子，嗓门大，在外人面前是"顾家好男人"。
- 里：自卑。他心里清楚公司是靠妻子的图撑起来的，所以更要把这件事压住。他不是要害死妻子，只是二十五年来习惯把她当成家里的一件东西。被债逼急了，反应永远是先算钱。

**核心公式**
- 目标：保住公司、保住房子、保住"金奖设计师"的面子；后期变成保住婚姻，因为他终于发现客户和图都跟着她走了。
- 阻碍：三百万小贷下个月到期；何曼一直在掏空公司；妻子觉醒后不再配合。
- 底层动机：怕被人看穿自己是空壳。二十五年前藏信，也是因为怕她走了，自己什么都不是。

**弧光（延迟后悔型）**
轻视（1–20）→ 假意回头，用名字、百合和家庭饭局拉她回来（21–30）→ 撤回离婚、法庭表演、威胁（30–40）→ 被何曼背叛，一无所有（44–45）→ 主动交代伪造签名（49）→ 出庭承认"那些图一张都不是我画的"，交出藏了二十五年的信（55）→ 独自在出租屋照着她留下的菜谱包饺子（60）。
**他得不到原谅，也不和她复合。他的救赎只体现在说出真相这一个动作上，而且要付出代价：失去名誉、公司注销、被判缓刑。**

**标志性细节**
- 二十五年里只叫她"哎"或"孩子他妈"。第22集第一次叫"春禾"，是为了要东西。第53集再叫她名字，已经什么都不要了，她没有回头。
- 不知道她对百合过敏（第22集）。
- 冰箱里剩的最后一袋冻饺子（第21集）。

**秘密**：伪造妻子签名做三百万小贷的共同借款人；与何曼同居三年；2001年藏起美院寄来的"保留学籍通知"。

## 三、何曼（主要反派，43岁）

**身份**：程记装饰销售经理，程国栋的"老同学"，实际是同居三年的情人。离异，带一个上初中的儿子。

**视觉锚点**：大波浪，口红颜色偏正红；珍珠发夹，第2集一枚落在春禾枕头上；珍珠项链是程国栋用公司的钱买的，第9集戴着出席订婚宴，第50集作为证物装进证物袋；高跟鞋走路声音很响。
允许变化：第49–50集被捕时素颜。

**性格（表 / 里）**
- 表：周到、会来事，嘴甜，管所有人都叫"哥""阿姨"。
- 里：极度务实，不信感情，只信写在纸上的东西。她并不爱程国栋，她要的是程记这块牌子和能变现的一切。

**核心公式（具体利益与行动理由）**
- 目标：先当上程太太、拿下程记，再把钱转走、全身而退。
- 动机：前夫留下的债，加上儿子的私立学费；她觉得自己"陪一个没本事的男人三年，总得拿点什么"。
- 手段：撮合程国栋借三百万投"精装房项目"，钱当天转进弟弟的何氏建材；虚开材料发票；偷春禾的笔记本；摆拍婆婆下跪的视频引导舆论；勾结远山副总傅明哲做指定供应商，用壁厚不达标的钢管搭脚手架；哄程国栋把公司股权一元转到自己名下。

**弧光**：从步步得手（1–34），到被春禾一件件拆穿（29、43、47），最后携款出逃被抓（49–50）；在看守所里还反诉著作权，做最后一搏（51–57）。

**她最怕的"那个"**：春禾笔记本页边上随手记下的材料报价和钢管壁厚（第8集埋，第40集兑现）。

## 四、王桂兰（婆婆，72岁）

**身份**：程国栋的母亲，退休纺织女工，和儿子一家同住。

**视觉锚点**：短卷发；常穿枣红色毛背心；降压药盒永远找不到；说话爱拍大腿。
允许变化：第35集摔伤后坐轮椅，第47集后用春禾设计的助行扶手。

**性格**：嘴硬心狠，信"女人就该守着灶台"。她当年也是这样被婆婆磨过来的，所以觉得春禾受的都是"应该的"。

**核心公式**
- 目标：孙子尽快结婚、拿到婚房，程家有面子。
- 阻碍：春禾不再伺候；何曼并不打算伺候她。
- 动机：怕老了没人管，又不肯承认自己离不开这个儿媳。

**弧光**：轻视（1–16）→ 生活失控，离不开春禾（16、23）→ 摔伤住院，何曼从没露面（35）→ 被留在家里没人管（46）→ 道歉："灵堂那天，我是真盼着曼曼进门"（47）→ 搬进梧桐里的适老化房子（53）→ 托人给春禾送去一盆花（58）。

**关键罪证**：灵堂那晚挂了春禾的求救电话，还骂了一句"骗子死全家"。

## 五、程子昂（儿子，25岁）

**身份**：在一家4S店做销售，工作三年，订婚在即。

**视觉锚点**：潮牌卫衣，手机永远在手上；开一辆白色SUV，首付其实是春禾的私房钱，他一直以为是父亲出的。
允许变化：第46集后剃短发；第58集穿着工装跟老周学木工。

**性格**：被奶奶和父亲宠大，觉得母亲做什么都是理所当然。他不坏，只是从来没用过脑子去看自己的家。

**核心公式**
- 目标：在未婚妻家限定的期限前拿到婚房，顺利结婚。
- 阻碍：父亲的房子早已抵押；母亲不肯配合"演戏"。
- 动机：怕在刘家面前丢脸，也怕失去佳琪。

**弧光**：伤害（3、10、16）→ 动摇（28、32–33）→ 被退婚（32）→ 在法庭上沉默，心虚（37）→ 主动作证，戳穿何强的伪证（46）→ 学一门手艺养活自己（58）→ 第一次给母亲做了一顿饭（60）。

**关键台词（伤害）**
- 第3集："妈，你回来得真不是时候。"
- 第10集："你今天走出这个门，我就当你真死在那辆车上了。"

## 六、程悦（女儿，20岁）

**身份**：临江美术学院环境设计专业大二学生，读的正是母亲当年读过、后来退学的专业。

**视觉锚点**：齐肩短发，戴黑框眼镜；帆布包上挂着手绘徽章；随身带平板。
允许变化：第19集后搬去和母亲住；第59集坐在讲座第一排。

**性格**：直、急、爱憎分明。早年嫌母亲"一辈子围着灶台转"，她学设计就是"不想活成我妈那样"。

**核心公式**
- 目标：前期是学好设计、离开这个家；中期变成帮母亲把名字拿回来。
- 阻碍：父亲断她生活费；网络舆论攻击。
- 动机：她发现自己最崇拜的那些"程记金奖"作品其实是母亲画的，原先的愧疚和崇拜都翻了过来。

**弧光**：心疼但不理解（2–3）→ 决定把父亲的阴谋告诉母亲（8）→ 发现图角的"禾"字（17）→ 讲座上当众质问父亲（19）→ 用视频帮母亲翻盘（20）→ 成为春禾设计的第一个实习生 → 坐在台下听母亲讲课（59）。

## 七、傅远山（男二 / 情感线，52岁）

**身份**：远山城建董事长，公司做城市更新和老旧小区改造。丧妻多年，独自照顾患轻度认知障碍的母亲。

**视觉锚点**：半白短发，戴金属细框眼镜；深灰羊毛大衣；随身带一本工程笔记，是他父亲留下的。
允许变化：无大的变化，第42集被董事会停职期间换成便装。

**性格**：克制、理性，凡事讲证据，不做救世主。他欣赏春禾，不因为她救过自己的母亲，而因为她的方案"看得见住在里面的人"。

**核心公式**
- 目标：把梧桐里适老化改造试点做成标杆，同时守住公司。
- 阻碍：堂弟傅明哲在董事会里掣肘，私下收供应商回扣。
- 动机：母亲曾在家里摔断髋骨，他一直觉得那是自己的错。

**与女主的边界**：他只给机会，比如邀请投标、要求匿名评审，从不替她赢。第40集他在董事会被否决，第41集冒着失去职位的风险，把采购文件交给她。结局是开放的温暖：他说"等你装修完，我想请你吃顿饭"，她说"等我先把自己的房子装好"。

## 八、秦小梅（女主闺蜜 / 合伙人，46岁）

**身份**：春禾在美院的室友，毕业后开了一家建材店，离异，独自一人生活。

**视觉锚点**：短发，挑染了一缕紫色；常年穿冲锋衣；说话快，笑声大。

**功能与弧光**：第8集收留春禾，第21集入伙。第42–43集上演"假背叛"：她故意收下何曼的钱，套出关键录音。
**动机**：二十五年前，她眼看着全班画得最好的人退了学，心里一直憋着一口气。

## 九、老周（周德福，58岁）

**身份**：程记的木工头，带着三个工人。程记已经三个月没发他们工钱。

**视觉锚点**：耳朵上夹一支木工铅笔；旧迷彩裤；说话带乡音。

**功能**：第14集带队跟了春禾，公司一线施工由他负责。第39集脚手架坍塌，他为了护住张奶奶摔伤腿。第47集后拄拐当监工，第58集教程子昂做木工。
**动机**：女儿有哮喘，这些年记得给她送药的只有"嫂子"。
