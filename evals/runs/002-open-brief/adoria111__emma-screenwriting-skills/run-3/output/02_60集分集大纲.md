# 《被结婚的登记员》60集分集大纲

竖屏真人短剧｜60集｜每集1–2分钟｜女频 · 现实悬疑 · 逆袭

## 一、核心大纲

沈知微是江城滨江区的婚姻登记员，七年里盖过上万次钢印。5月20日，她临时顶班，叫到第520号。坐到窗口前的，是和她恋爱六年、一直说"等公司稳定就结婚"的男友陆铭，还有他的千金未婚妻温妤。系统弹出陆铭的婚史：2023年在清河县与"沈知微"登记结婚，2026年4月离婚。这两件事，她本人都不知道。

一夜之间，房子没了，离婚协议上写着"自愿赠与男方"；三百万信用贷压到她身上，是有人拿她的公务员身份贷出来的；她被停职，被网暴，母亲被催收吓进了手术室。她顺着档案追到清河县，从被人纵火的档案室里抢出半张照片。照片上那只按手印的手，虎口有一道疤，是闺蜜许晴十二岁时替她挡开水留下的。

她用自己的工号日志证明"离婚"那天她在窗口上班，那次离婚登记被撤销了。结果是她反倒成了陆铭的"合法妻子"，陆铭因此娶不了温妤。为了逼她离婚，对方让许晴顶罪，又拿母亲和债务施压。她答应协议离婚，但三十天冷静期里的撤回权攥在她手里。就在这三十天里，她挖出了真正的操盘人：温妤的继母周曼，也就是陆铭的亲生母亲。母子俩布局三年，要的是温妤25岁生日那天按遗嘱交付的15%股份。

更深的秘密藏在云岭县一份没补录进系统的纸质档案里：陆铭2016年就以本名周铭娶了苏冉，一直没离婚。她按规定把这份档案补录进系统，对方却反咬她伪造公文。档案原件失踪，她被刑事拘留。最难的时候，许晴交出了藏了三年的假身份证，温峥找到了带着孩子隐居的苏冉，还有她手里那本红色结婚证。

8月8日是温妤的生日，地点是滨江区登记大厅。陆铭在声明书上写下"本人无配偶"，温妤按住了笔，苏冉推门进来，系统刷新出一条"已婚"记录。母子二人落网。沈知微的婚姻状况恢复为"未婚"。一年后的5月20日，她第一次亲手在自己的结婚声明书上签下名字。

### 第一阶段 · 被结婚（1–10）

**第1集 · 第520号**
- **事件**：5月20日，滨江区登记处排起长队。沈知微退掉陆铭给她订的三亚机票，来替同事顶班；抽屉里藏着一枚男戒，她打算今晚自己求婚。叫号A520，坐下来的是陆铭和温妤。陆铭镇定，温妤热络地讲他们"恋爱一年了"。沈知微照流程刷身份证，屏幕弹出男方婚史：2023-06-12 清河县结婚，2026-04-16 清河县离婚，前配偶：沈知微，身份证号就是她本人的。
- **选择→后果**：她没有当场失控，继续核验，手指停在钢印上。
- **知情**：观众和沈知微同时知道她"被结婚又被离婚"；温妤不知道。
- **尾钩**：陆铭俯身压低声音："别闹。盖章。" → **兑现**：第2集开场，她把钢印推开。

**第2集 · 回避**
- **承接**：她不盖章，反问男方前配偶的姓名。
- **事件**：陆铭只能说出"沈知微"。温妤看到窗口的名牌，愣住了。陆铭抢先定性："我前妻就在这儿上班，她一直放不下。"沈知微当着排队的人说："这条记录上的女方是我。可我本人，从来没结过婚。"赵主任赶到，按规定让她回避，并以"前婚记录存疑"暂缓办理这对的登记。温妤哭着跑了。楼梯间里，陆铭把离婚协议的照片给她看：她的签名，红手印，房产"自愿赠与男方"，"女方名下债务由女方承担"。
- **选择→后果**：她拒绝私下了结："我会一条一条查。"
- **尾钩**：银行来电："沈女士，您名下六笔信用贷合计三百万，已经逾期。" → **兑现**：第3集她赶回家，发现连家都没了。

**第3集 · 换锁**
- **承接**：她打车回家，一路打陆铭电话，打不通。
- **事件**：老小区的门锁换了。母亲林秀芝坐在楼道里的行李箱上，中介正带人看房，房子4月23日已经过户给陆铭，挂牌出售。父亲遗像的相框摔裂了。母亲一度以为女儿"瞒着妈离了婚"，看到女儿的反应后信了她。许晴赶来抱住她，把母女俩接回自己家。
- **选择→后果**：她不和中介吵，只拍下挂牌单和新换的门锁，当场说要去申请产权异议登记，把看房的买家吓走了。她要证据，不撒泼。
- **知情**：特写许晴右手虎口的旧烫伤疤（埋点）。
- **尾钩**：深夜，许晴手机亮起，备注是"L"：「她在你那？稳住她。」观众先于女主起疑。 → **兑现**：第4集许晴照旧当"最可靠的人"，这条伏线到第9集收。

**第4集 · 停职**
- **承接**：清早，她去派出所报案。
- **事件**：民警说冒名登记得先拿出证据。回到单位，陆铭的投诉已经到了，罪名是"泄露隐私、骚扰当事人、滥用职权阻挠登记"，附了一段剪辑过的大厅视频。赵主任收走她的工牌，停职调查。同事唐果偷偷告诉她，原始档案在清河县。她想起当事人有权查阅本人档案，也想起三年前丢过身份证，报失日期是2023年6月14日。
- **选择→后果**：她决定自己去清河县，不等单位的调查结论。
- **尾钩**：她盯着报失回执："我报失身份证的两天前，就已经有人拿着它去结婚了。" → **兑现**：第5集清河县。

**第5集 · 清河县**
- **事件**：清河县登记员老马说"系统维护，档案外借"。温峥带着助理出现了。温妤哭着回家后，他第二天就来查陆铭的底。他手里有陆铭主动交给温家的结婚证复印件，照片里的新娘戴着沈知微同款眼镜，梳着她的发型。他认定她在演。她说："照片可以像，指纹不会。档案里有那个人的手印。"老马脸色变了。
- **选择→后果**：她当场递交书面查阅申请，要求老马写明答复期限。
- **知情**：她瞥见老马手机来电，备注"周姐"。
- **尾钩**：老马躲进档案室回电话："周姐，她要查原件。" → **兑现**：第6集不揭"周姐"是谁，但温家餐桌上出现了周曼。

**第6集 · 五十万**
- **承接**：清河县民政局门外，温峥追了出来。
- **事件**：温峥递出一张五十万的支票："离开江城，别再搅我妹妹的婚事。"沈知微把支票塞回他西装口袋："你妹妹要嫁的人，用我的名字结了婚，又用我的名字离了婚。他欠我的，是三百万，还有一个家。"温家晚餐，继母周曼温柔周到，替陆铭说话，把订婚宴定在十天后的温氏酒店。
- **选择→后果**：温峥没有阻止订婚，但让助理去查铭途科技的钱。
- **尾钩**：助理来电："铭途科技的启动资金三百万，全部来自沈知微名下的六笔信用贷。" → **兑现**：第7集温峥的怀疑开始转向，沈知微却先迎来网暴。

**第7集 · 热搜**
- **事件**：#女登记员纠缠前夫# 冲上同城热搜，她的脸和工号被扒了出来。她去温妤的花店，想当面讲清楚，被温妤泼了一杯冰咖啡。她没辩解，只留下一个能验证的问题："你去问他，2023年6月12号那天，他在哪儿。"陆铭赶到，温柔地劝她"去看看医生"。
- **选择→后果**：她不还手，不求温妤信她，只把问题留给温妤自己去查。
- **尾钩**：深夜，温妤翻到陆铭三年前的朋友圈：2023-06-12，定位清河县，"签了个大单"。身后传来陆铭的声音："在看什么？" → **兑现**：第8集开头陆铭说"去谈业务"，温妤暂时信了。这个疑点到第50集兑现。

**第8集 · 催收**
- **事件**：催收找到许晴家，在门上喷红漆："沈知微欠债还钱"。母亲受惊倒地，送医后确诊要做心脏支架，先交十五万。法院诉前保全，冻结了沈知微的工资卡。许晴塞给她五万，说是自己的"积蓄"。
- **选择→后果**：她跪在走廊里签了手术同意书，转身去缴费窗口凑钱。
- **尾钩**：缴费窗口前还差十万，身后有人问："差多少？"是温峥。 → **兑现**：第9集。

**第9集 · 火**
- **事件**：温峥垫了十万。她坚持在缴费单背面写欠条。他说："我不是帮你，是买真相。"他的律师明天带调档函去清河。当晚，唐果在同行群里看到消息：清河档案室"线路老化"，老马今晚一个人加班。沈知微冒雨开了两个小时车赶过去，档案室已经冒烟，老马从侧门跑了。她冲进去抢出2023年的档案盒，手被烫伤，温峥赶到把她拖了出来。
- **选择→后果**：她为了抢一张纸冲进火场。
- **尾钩**：半张烧焦的审查表上，现场签字照片里新娘的脸烧没了，只剩一只按手印的右手，虎口有一道旧疤。沈知微的脸一下子白了。 → **兑现**：第10集。

**第10集 · 订婚宴　💰主付费卡点**
- **承接**：闪回十二岁那年，许晴扑过来，替她挡下一锅开水。
- **事件**：沈知微打给许晴，许晴说："我在温家订婚宴上给温小姐换礼服，你别来。"她还是去了。温氏酒店宴会厅里，陆铭先发制人："她昨晚还去清河放火烧档案。"宾客哗然，保安围上来。许晴冲过来，嘴上说"我带她走"，伸手抓住了她的胳膊。
- **选择→后果**：沈知微反手扣住那只手，举到灯下。
- **尾钩（付费卡点）**："晴晴。三年前在清河县，替我签字、按手印的，是不是这只手？"许晴、陆铭、温妤三张脸定格。 → **兑现**：第11集许晴的回答。

### 第二阶段 · 反咬与反将（11–20）

**第11集 · 疤**
- **承接**：许晴抽回手，眼泪掉下来。
- **事件**："知微，你是烧糊涂了吧？这种疤谁没有。"陆铭借势把"纵火"坐实。温峥站起来，把六笔信用贷的流水拍在父亲面前："陆铭创业的钱，是用她的名字贷的。"周曼出来打圆场。温父拍板：订婚照常，结婚登记等警方的结论。沈知微被请出宴会厅。
- **选择→后果**：温峥公开站到她这一边，第一次和继母正面交锋。
- **尾钩**：酒店后廊，陆铭压低声音对许晴说："那道疤，明天之前处理掉。" → **兑现**：第13集许晴的手。

**第12集 · 嫌疑**
- **事件**：医院，母亲刚做完手术。温峥提出合作：他出律师秦朗和医药费，她出线索。她加了两条：钱是借的，要写欠条；她自己的官司，她说了算。温峥逐页看完，用自己的钢笔签了字。清河警方打来电话。
- **尾钩**：何警官："老马说，他亲眼看见是你点的火。" → **兑现**：第13集。

**第13集 · 收费站**
- **事件**：问询室里，老马说他20:10看见她进了档案室。沈知微调出自己车的ETC记录：她20:41才驶出清河收费站，而消防接警时间是20:15。纵火嫌疑解除，警方回头找老马，人已经失踪了。半张声明书上的指纹烧得只剩三分之一，没法比对。
- **尾钩**：许晴拎着汤来医院，右手缠着纱布："做饭烫着了。"那道疤没了。 → **兑现**：第14集。

**第14集 · 撕破**
- **事件**：医院楼梯间，她把五万块还给许晴："这钱是他的吧。"又说："那道疤，是替我挡开水留下的。你连它都不要了。"许晴不认，也不哭，只说了一句："你什么都有。"沈知微带母亲搬进了城中村的出租屋。
- **选择→后果**：她不再等一个解释，和许晴断了生活上的往来。
- **知情**：观众得知许晴是陆铭的情人。
- **尾钩**：许晴一个人给陆铭打电话："她知道了。你答应过我，事情办完就娶我。" → **兑现**：第18集许晴为"爱"顶罪。

**第15集 · 工号**
- **事件**：她转向那次"离婚"：2026年4月16日上午10:30，清河县办的离婚登记。那天她在滨江区窗口上班，系统里每一笔业务都有她的工号。可她停职了，拿不到日志。赵主任接到"上面"打来的电话，有些犹豫。她不求情，只讲程序：请何警官出具调取证据通知书。日志打印出来：10:28，她正在办第23号业务。
- **尾钩**："那天十点半，我在给一对聋人夫妻打手语，盖章。" → **兑现**：第16集证人。

**第16集 · 恢复**
- **事件**：聋人夫妻出面作证。清河县民政局根据公安的认定，撤销了2026年4月16日的离婚登记，离婚协议也随之失去依据。赵主任提醒她：离婚一撤销，2023年那条婚姻记录就恢复有效了。她早就算到了这一步。
- **选择→后果**：她主动让自己在法律上"重新成为陆铭的妻子"，用这段假婚姻挡住他和温妤。
- **尾钩**：她把撤销决定书拍在陆铭面前："恭喜你。你又有老婆了。" → **兑现**：第17集温家震动。

**第17集 · 原配**
- **事件**：温妤得知未婚夫"还是已婚"。周曼抢先定调：铭儿也是受害者，被许晴骗了，以为早就离了。陆铭在温妤面前跪下。温妤问起清河县那天的事，他说"去谈业务"。转过头，他去找沈知微："房子还你，债我扛，离婚。"她说："我不离。因为我根本没跟你结过。"
- **尾钩**：陆铭说："你妈的心脏，你冻住的卡，你停掉的工作，你耗得起吗？" → **兑现**：第18–20集三重施压。

**第18集 · 顶罪**
- **事件**：许晴走进派出所自首：4月16日去清河县冒名离婚的是她，因为她爱陆铭，想帮他"摆脱一段死掉的婚姻"；至于2023年结婚，"是知微本人去的"。陆铭配合说，他"以为是知微同意让人代办"。许晴被取保候审，陆铭全身而退，2023年那条记录仍被认定为真实婚姻。
- **选择→后果**：沈知微隔着询问室的玻璃，看许晴把一切揽到自己身上。
- **知情**：沈知微得知许晴和陆铭的私情。
- **尾钩**：许晴临走时低声说："你以为，他只骗了你一个？" → **兑现**：第29–31集，苏冉。

**第19集 · 周姐**
- **事件**：茶室里，周曼约见沈知微，自称是温妤的继母，开价两百万外加房子，换她协议离婚、从此不再提。周曼随口说出"六月十二号清河那天"，可这个日期从没出现在任何公开信息里。周曼离开时，替她拉开车门的司机，正是那天喷红漆的催收头目阿坤。
- **选择→后果**：沈知微拒绝了，偷偷拍下了司机。
- **尾钩**：她对上了：老马手机上那个"周姐"，就是周曼。 → **兑现**：第20集她终于看清这个局有多大。

**第20集 · 遗嘱　🔒强卡点**
- **事件**：她把照片拿给温峥看。温峥第一次说出温家的秘密：生母留下遗嘱，温妤25岁生日（8月8日）那天如果已经成家，15%的股份交到她本人手里；否则继续封存在信托里十年。沈知微把三年串了起来：用信用贷造出一个"青年创业者"陆铭，再用假离婚洗白身份，娶温妤，拿股份。与此同时，陆铭起诉离婚，主张三百万属于夫妻共同债务。秦律师直说：要撤销2023年的登记，证据还不够。母亲又要开始第二期治疗。
- **选择→后果**：她拨通了陆铭的电话。
- **尾钩**："我跟你离。"温峥愣住了。 → **兑现**：第21集揭开她的打算。

### 第三阶段 · 冷静期三十天（21–30）

**第21集 · 三十天**
- **事件**：温峥质问她，是不是要放陆铭去娶他妹妹。她摊开自己的打算：协议离婚有三十天冷静期，撤回权在她手里；先在协议里拿回房子，把债划给陆铭；这三十天里，她要证明2023年那次登记是冒名的，证明了就撤回申请，直接去撤销登记。"要是找不到呢？""那我至少能把我妈的家拿回来。"他说她这是拿温妤在赌。她说："你妹妹是成年人，不是你的资产。我也不是你们温家的防火墙。"两人不欢而散。
- **知情**：观众知道温峥打算买债，沈知微不知道。
- **尾钩**：温峥一个人打电话："那家催收公司手上的债，问问多少钱能买下来。" → **兑现**：第33集。

**第22集 · 申请**
- **事件**：6月19日，滨江区登记处，还是她原来那个窗口。赵主任亲自办理，沈知微坐在申请人那一侧。她要求加补充条款：房屋返还；六笔信用贷的逾期部分由陆铭在冷静期内结清；协议里写明"2023年6月12日双方本人亲自到场登记"。陆铭的笔尖停了三秒，签了。冷静期到7月19日。
- **选择→后果**：她让陆铭亲笔把谎言写进了官方文件，以后可以作为骗取登记的证据。
- **尾钩**：停车场里，周曼对陆铭说："三十天，够她自己先撑不住。" → **兑现**：第23集施压从职场开始。

**第23集 · 档案室**
- **事件**：停职调查结束，她复职了，却被调离窗口，去了地下档案室，是周曼托人打的招呼。陆铭结清了逾期，她的卡解冻了。在满屋灰尘里，她想起2023年金额最大的那笔信用贷（江城农商行，120万）是必须线下面签的，银行有录像。银行以"内部资料"为由拒绝提供，秦律师去申请法院调查令。
- **尾钩**：农商行副行长冯建接到周曼的电话："那段录像，处理一下。" → **兑现**：第24集抢录像。

**第24集 · 人脸比对**
- **事件**：温峥没跟她商量，以温氏集团大客户的身份要求农商行总行审计，抢先冻结了数据。调查令下来，录像调了出来：戴口罩的"沈知微"在签字。后台记录显示，人脸比对71分，未通过，人工放行。
- **选择→后果**：她知道是温峥插了手，没道谢，也没拒绝这份证据。
- **尾钩**：屏幕上一行字："人工放行人：冯建。" → **兑现**：第25集。

**第25集 · 周铭**
- **事件**：冯建扛不住审计，只承认那是"周总介绍的客户"。何警官把陆铭的户籍记录交给她：曾用名周铭，2017年从云岭县迁入江城并改名。温峥脸色变了，周曼的老家就是云岭。
- **尾钩**：沈知微在纸上并排写下两个名字："周铭。周曼。" → **兑现**：第26–30集追到云岭。

**第26集 · 试探**
- **事件**：温家晚餐，温峥随口提到"云岭"，周曼手里的筷子掉了一根。当晚，周曼把温峥和沈知微在医院、在车里的照片发给温妤，还"心疼"地对她说：那个女人在利用冷静期勒索陆铭，还想勾住你哥，拆散你们。她顺势把领证日定在8月8日，温妤生日那天，"冷静期一过就办"。温妤和哥哥大吵一架，搬去和陆铭同住。
- **尾钩**：温妤说："你要是再查他，我就当没你这个哥。" → **兑现**：第28集温峥还是去了云岭。这是他第一次违背妹妹的意愿，也是第一次和沈知微并肩。

**第27集 · 戒指**
- **事件**：许晴取保在家，婚纱店关了门，陆铭不回她消息。沈知微来了，不求她，也不劝她，只问一句："他说会娶你。那冷静期一结束，他为什么要在八月八号娶温妤？"许晴跟踪陆铭，看见他和温妤在珠宝店试婚戒。
- **尾钩**：许晴拨通沈知微的号码，又挂断了。 → **兑现**：第34集沈知微再来找她；第40集许晴写来纸条。

**第28集 · 去云岭**
- **事件**：周末，沈知微和温峥开车去云岭。车上，他说自己从不签没看完的东西；她说她以前什么都签，因为相信别人。云岭县民政局库房里，退休登记员老陈带他们翻2014到2016年那批还没补录的纸质档案。
- **尾钩**：后视镜里，一辆黑车从江城一路跟到了云岭。 → **兑现**：第29–30集。

**第29集 · 老街坊**
- **事件**：周家老屋所在的巷子里，邻居大婶认出了照片上的陆铭："周曼家的铭儿？早些年结过婚，媳妇叫小冉。"
- **尾钩**："那媳妇走的时候，肚子都大了。" → **兑现**：第30集。

**第30集 · 曼与铭儿　🔒中点大反转**
- **事件**：废弃的老屋里，墙上挂着一张褪色的合影：年轻的周曼搂着一个七八岁的男孩，背面写着"曼与铭儿 2001"。黑车上的人闯进院子，两人翻墙逃走，温峥护着她摔伤了胳膊。
- **选择→后果**：温峥不再只想"护住妹妹的婚事"，他决定拆穿自己家里的人。
- **知情**：观众、沈知微、温峥同时得知周曼是陆铭的生母。
- **尾钩**：温峥看着照片说："我爸娶的女人……是他亲妈。" → **兑现**：第31集，第二颗雷。

### 第四阶段 · 原配与陷害（31–40）

**第31集 · 2016**
- **事件**：回到库房，老陈翻出2016年3月的一页登记：周铭、苏冉，结婚。此后没有任何离婚记录，也从没补录进系统。这就是说，陆铭2023年"娶"沈知微的时候，本来就是有妇之夫。她没有私自动档案，而是请老陈写书面说明，由云岭现任登记员钱敏按规定补录。
- **选择→后果**：她用规则而不是手段，把这条记录放进了全国系统。
- **尾钩**：她查询陆铭的身份证号，屏幕上跳出两条"已婚"。"这一次，系统会替我拦住他。" → **兑现**：第32集周曼立刻有了动作。

**第32集 · 坦白**
- **事件**：周曼抢在所有人前面，含着泪向温父"坦白"：陆铭是她和前夫的儿子，怕老温多心才一直瞒着；乡下那段婚"早就私下散了，只是没去办手续"，她会让儿子补办。温父心软了："家丑不可外扬。"温峥被父亲压了下来。温父近来总觉得乏力（伏笔）。
- **知情**：温妤从周曼口中得知陆铭是她的儿子。
- **尾钩**：周曼轻声对温峥说："沈小姐那笔债，是你买下的吧？你猜她知道了，会怎么看你？" → **兑现**：第33集。

**第33集 · 债主**
- **事件**：沈知微收到一个匿名快递：催收公司手上80万的债权，已经转让给温氏旗下的一家公司，日期是她答应离婚的第二天。她当面问，温峥承认了，说是为了停掉催收，不让陆铭拿这笔债拿捏她。她说："你和他一样，替我决定我欠谁。"
- **选择→后果**：她结束了合作，两人之间只剩债务关系。
- **尾钩**："从今天起，你是债主，我是欠债的。别的，没有了。" → **兑现**：第39集温峥一个人去找苏冉；第46集他把选择权还给她。

**第34集 · 孩子**
- **事件**：她带着2016年档案的复印件去见许晴："他有老婆，还有一个九岁的儿子。"许晴笑出了眼泪："他跟我说，他不想要孩子。"许晴问她为什么要告诉自己。沈知微说："因为你也是被他签了名的人。"
- **知情**：观众知道许晴还留着假身份证。
- **尾钩**：许晴拉开抽屉，里面是一张身份证：照片是许晴，姓名和号码是沈知微。 → **兑现**：第40–41集。

**第35集 · 伪造**
- **事件**：沈知微绕开温峥，单独约见温妤，把2016年的档案交给她。温妤动摇了，回去问陆铭。陆铭和周曼一唱一和："她就在档案室上班，伪造一页纸，对她来说太容易了。"温妤选择相信未婚夫。
- **尾钩**：书房里，周曼对陆铭说："既然她拿出来了，那就让这份档案，变成她的罪证。" → **兑现**：第37集。

**第36集 · 第三十天**
- **事件**：冷静期到期了。是撤回，还是领证？她想清楚了：2016年的记录已经在系统里，就算她和陆铭离了，他也娶不了温妤；而她花了三十天证明这段婚姻是假的，就不能再拿它当盾牌。7月20日，她和陆铭领了离婚证，协议生效，房子回到她名下。她对陆铭说："别急着庆祝。你在云岭，还有一个家。"陆铭的笑僵在脸上。母女俩搬回老房子，父亲那块旧机械表却不见了，搬家那天陆铭来过。
- **选择→后果**：她选择先把自己的人生从这段假婚姻里拿回来。
- **尾钩**：当天夜里，云岭县民政局库房被撬，2016年那页登记原件不见了。 → **兑现**：第37集。

**第37集 · 反咬**
- **事件**：云岭方面称"原件查无"。钱敏在压力下改口："那页纸是沈知微自己从箱子里'找'出来递给我的。"2016年的记录被标为"存疑"，暂停显示。周曼实名举报：沈知微利用档案工作之便伪造婚姻档案，诬陷前夫。陆铭和温妤宣布：8月8日在滨江区登记处照常领证。
- **尾钩**：警察走进地下档案室："沈知微，你涉嫌伪造国家机关公文，跟我们走一趟。" → **兑现**：第38集。

**第38集 · 刑拘**
- **事件**：证据对她非常不利：原件上有她的指纹（她翻过），复印件是她复印的，钱敏出面作证，她还有"报复前夫"的动机。何警官心里有疑问，但只能依法刑事拘留。唐果和赵主任去她家照顾她母亲。
- **尾钩**：看守所铁门合上，墙上的日历是7月22日，离8月8日还有十七天。 → **兑现**：第39–40集，外面的世界。

**第39集 · 全城**
- **事件**：本地新闻滚动播报"女登记员伪造档案，诬陷前夫重婚"。母亲关掉电视："我闺女随她爸，认死理，不会造假。"温妤看着新闻，松了一口气，心里又说不出地难受。温峥找到秦律师："替我带句话：我去找苏冉。这是我自己的决定，我不替她做任何决定。"
- **尾钩**：温峥查到，九年来周曼每月往南溪县一个账户转3000元，户名苏冉。 → **兑现**：第42集。

**第40集 · 她的名字　🔒至暗时刻**
- **事件**：秦律师来会见，带来的全是坏消息：老陈中风住院，没法作证；南溪那个账户上周销了户，苏冉搬走了；检察院可能在8月4日前批捕；温家的婚礼请柬已经发出去了。沈知微在看守所的纸上一遍又一遍写自己的名字，这是她唯一还能确定属于自己的东西。
- **选择→后果**：她对秦律师说："不认。一个字都不认。"
- **尾钩**：秦律师递过来一张纸条，是许晴的字迹：「那张身份证，我还留着。」 → **兑现**：第41集。

### 第五阶段 · 反击（41–50）

**第41集 · 交出**
- **事件**：地下停车场，许晴把假身份证和三年来跟陆铭的聊天录音交给秦律师和何警官，承认2023年结婚、2026年离婚都是她冒名去办的，陆铭全程知情，周曼出钱。"我留着它，是怕有一天他不要我。现在他不要我了。"
- **选择→后果**：她选择自证其罪，换沈知微清白。
- **尾钩**：她走出停车场，一辆无牌车加速冲过来。 → **兑现**：第42集。

**第42集 · 撞**
- **事件**：许晴左腿骨折，命保住了，证据早已交到秦律师手里。何警官以2023年冒名登记和三百万贷款诈骗对陆铭立案，但录音的声纹鉴定要一周左右，暂时没法抓人。沈知微的"伪造"罪名还悬着，关键在于2016年那份档案的真假。温峥通过学籍转学记录，追到了南溪县城郊的一家早餐铺。
- **尾钩**：一个九岁的男孩端着豆浆跑出来，眉眼和陆铭一模一样。 → **兑现**：第43集。

**第43集 · 红本**
- **事件**：苏冉一口咬定不认识周铭。温峥不逼她，只说了一件事：有个女人，因为说出了你丈夫的真相，现在关在看守所里。苏冉讲出了这九年：怀孕时被丢下，周曼按月给钱，还警告她"敢露面，孩子就别想有好日子"。
- **尾钩**：她从饼干铁盒里拿出一本红色结婚证：2016年，周铭，苏冉。 → **兑现**：第44集。

**第44集 · 出来**
- **事件**：公安把红本上的钢印、编号和云岭留存的登记台账号段一比对，2016年的婚姻确认属实。钱敏看到许晴的证据后，承认自己是被施压才改的口。检察院不批准逮捕，8月3日傍晚，沈知微走出看守所。温峥在门口等她。她问："你自己的决定？""我自己的。""谢谢。"
- **尾钩**：秦律师说："2016年的记录重新补录要五个工作日，8月10日才生效。他们8月8日就领证。" → **兑现**：第45集。

**第45集 · 不越权**
- **事件**：唐果小声出主意：你有权限，今晚就能先把记录恢复。沈知微拒绝了："我要是越了这一步，他们说我伪造，就成真的了。"她和赵主任一起走正规的加急程序，需要市民政局签批。母女重逢，母亲说："你爸说过，规矩就是没人看的时候也不越线。"
- **选择→后果**：她宁可冒赶不上的风险，也不越权。
- **尾钩**：周曼找上门来，从手包里拿出那块旧机械表："想要回你爸的表吗？""规则，是给守规矩的人用的。" → **兑现**：第46集。

**第46集 · 表**
- **事件**：周曼要她8月8日别出现在登记处。沈知微拒绝了。周曼一松手，表掉在地上，表蒙裂了。沈知微蹲下捡起来，表还在走。温峥赶到，带来三样东西：酒店监控拍到撞许晴的车，是周曼的司机阿坤开的；阿坤已经被抓；还有一份债权转让协议，80万债权以一元转给她。"债权人和欠债人是同一个人，这笔债就没了。"她逐页看完才签字。
- **选择→后果**：温峥把当初替她做的决定还给了她，她第一次接受他的帮助。
- **尾钩**：阿坤手机里最后一通电话是"老马"，定位在温氏酒店员工宿舍。 → **兑现**：第47集。

**第47集 · 老马**
- **事件**：员工宿舍天台上，老马要跳楼。沈知微认得他：七年前全市业务培训，他讲过"登记员手里的章，比命还重"。她把这句话还给了他。老马崩溃，全部交代：2023年收了周曼五万，人工放行人脸核验；2026年离婚也是这样；纵火是阿坤指使的。
- **尾钩**：老马说："阿坤讲过一句，'老爷子的药已经换了三个月'。" → **兑现**：第48集。

**第48集 · 药**
- **事件**：温峥把父亲的药送去检测，心脏药被换成了低剂量的仿制品，难怪父亲从第32集起越来越虚。他告诉父亲，父亲不信。温峥在药柜里装了摄像头。
- **尾钩**：凌晨的监控画面里，周曼打开药盒，一粒一粒地换。温父看着屏幕，手在发抖。 → **兑现**：第49集，温父配合"装病"。

**第49集 · 账**
- **事件**：温峥、沈知微、何警官把账摊开：六笔信用贷 → 铭途科技 → "咨询费" → 周曼表妹名下的空壳公司 → 周曼私人账户 → 老马五万、苏冉每月三千、阿坤若干……许晴被许诺的五十万，一分都没到账。何警官说证据够抓周曼了，收网定在8日，以免她提前销毁证据或外逃；可陆铭的重婚还缺最后一环，他得亲手写下"本人无配偶"。温峥说可以等他签了再抓。沈知微摇头："温妤不是诱饵，她是当事人。她有权在签之前知道一切。"
- **选择→后果**：征得苏冉同意后，她把红本的照片和孩子的照片发给了温妤。
- **尾钩**：温妤盯着照片，手机上弹出陆铭的消息："宝贝，生日倒计时三天。" → **兑现**：第50集。

**第50集 · 温妤　🔒强卡点**
- **事件**：夜里，温妤靠在陆铭肩上问他："在我之前，在沈知微之前，你结过婚吗？""没有。"她想起了清河县那条朋友圈。他去洗澡时，她翻了他的包，里面有一份《表决权委托书》，签署日期8月8日，受托人陆铭，旁边是周曼的批注："领证后当晚让她签。"
- **知情**：温妤确认陆铭的重婚和周曼的图谋。
- **尾钩**：温妤躲进洗手间，拨通了沈知微的电话："八号上午九点，滨江区。我需要你在。" → **兑现**：第51集。

### 第六阶段 · 终局（51–60）

**第51集 · 她的计划**
- **事件**：几个人秘密碰面。温妤说："我要亲眼看着他签。"温峥脱口而出"不行"，随即停住："……你决定。"沈知微把规则讲清楚：他在登记员面前签下虚假声明，就构成骗取登记；加急补录已经拿到市局签批，8月8日上午9:30同步生效；另外还需要苏冉本人到场。
- **知情**：观众和主角团知道9:30这个时间点，陆铭和周曼不知道。
- **尾钩**：苏冉发来消息："对不起，我不能去。他们会找我儿子。" → **兑现**：第52集。

**第52集 · 两个被签了名的女人**
- **事件**：沈知微一个人去了南溪。两个女人坐在早餐铺的后院里。她不劝苏冉，只讲自己的事：被结婚，被离婚，被关进去。男孩问她："我爸爸是坏人吗？"她说："他做了坏事。你不用替他做什么，你就是你。"苏冉解下了围裙。
- **尾钩**：回江城的高铁上，两个男人隔着车厢盯着苏冉母子。 → **兑现**：第53集。

**第53集 · 八月七日**
- **事件**：江城站出站口，那两个人想抢走男孩，被温峥安排的安保和便衣当场按住。消息传到周曼那里，她只说："苏冉来了又怎样？系统上没有，登记员就得办。今天不领，就再没有'今天'了。"温父继续卧床"病重"，好让周曼放松警惕。深夜，陆铭在书房里一遍遍练签名。闪回三年前，他教许晴模仿"沈知微"三个字。
- **尾钩**：周曼替温妤挂好生日礼服，把委托书放进手包："明天之后，温家的事，我说了算。" → **兑现**：第54集。

**第54集 · 八点五十九**
- **事件**：8月8日，滨江区登记处趁吉日特别开放，大厅和第1集一样挤。唐果坐在窗口，沈知微按规定回避，站在等候区，和第1集的位置正好对调。陆铭看见她，笑了。系统显示他的婚姻状况是"离婚"。唐果宣读声明书："本人无配偶……"陆铭利落地签了名。轮到温妤，她拿着笔说："我哥说，没看完的东西不签。我再看一遍。"时间是9:28。
- **尾钩**：大厅的门被推开，苏冉牵着男孩站在门口。 → **兑现**：第55集。

**第55集 · 原配**
- **事件**：苏冉说："周铭，你的结婚证，我替你收了九年。"陆铭说："我不认识她。"男孩喊了一声："爸爸。"陆铭咬定档案是沈知微伪造的。沈知微举起红本："那这本呢？"9:30，系统刷新：已婚，配偶苏冉。唐果说："不予登记。"何警官出示拘留证，陆铭转身要跑，被按在登记台上，正是第1集他俯身说"别闹，盖章"的那张台子。
- **尾钩**：周曼起身要走，门口站着温峥，还有本该卧床的温父。 → **兑现**：第56集。

**第56集 · 周曼**
- **事件**：温父当众播放换药的监控。周曼不慌，说自己只是一个从云岭走出来、被男人抛弃过的女人，只是不想让儿子再受穷。沈知微说："所以你让我、让许晴、让苏冉，替你儿子付账。"周曼腕上的佛珠断了线，珠子滚了一地。何警官以诈骗、行贿、故意伤害等罪名对周曼采取强制措施。
- **尾钩**：警车里，陆铭隔着车窗，要求见沈知微一面。 → **兑现**：第57集。

**第57集 · 那六年**
- **事件**：陆铭说："那六年，我不是全在演。"沈知微说："那更可怕。你用我的房子、我的名字，养出了一个去娶别人的自己。"她把第1集抽屉里那枚男戒放在桌上："这是那天我准备向你求婚的戒指。现在用不上了。"说完转身离开。
- **尾钩**：赵主任来电："市局的撤销决定下来了，你回来，自己看。" → **兑现**：第58集。

**第58集 · 未婚**
- **事件**：她回到自己的窗口，输入自己的身份证号：2023年的结婚登记、2026年的离婚登记，都因冒名被撤销。婚姻状况：未婚。母亲把父亲的表重新戴到她手腕上。温妤来道谢："以后嫁谁、什么时候嫁，我自己决定。"温峥问能不能请她吃饭，她说："我请。用第一笔还款。"
- **尾钩**：秦律师提醒她：明天许晴宣判。 → **兑现**：第59集。

**第59集 · 疤**
- **事件**：许晴因自首、立功获得从轻处理，判了缓刑。法院门口，她伸出右手，新的烫伤疤盖住了旧疤。"我把替你挡开水的那道疤，自己烫掉了。"沈知微说："疤没了，事还在。我记得你替我挡过开水，也记得你替我按过手印。"不原谅，也不再恨。字幕交代：陆铭、周曼被依法追究刑事责任；苏冉带着儿子开了一家新店；沈知微牵头全区"冒名登记与历史档案补录"专项，又查出三十七条没补录的记录。
- **尾钩**：字幕："一年后，5月20日。" → **兑现**：第60集。

**第60集 · 我自己签**
- **事件**：2027年5月20日，大厅里照旧排着长队。叫号A520，坐下来的是温峥，一个人来的，材料带得整整齐齐："沈老师，我来咨询结婚登记。"她照流程回答："双方本人到场，身份证，户口本，还有，自愿。"他说："所以，我来问你愿不愿意。"她摘下工牌，请唐果接替窗口，绕过柜台，坐到申请人那一侧。她把声明书一行一行读完，亲手签下"沈知微"三个字。钢印落下。
- **结尾**："这一次，是我自己签的。"（全剧终）

## 四、连读自检

- **因果**：陆铭三年按时还款，所以沈知微一直没察觉；离婚后停止还款，所以第2集出现逾期。离婚被撤销，所以她"恢复已婚"，陆铭也就娶不了温妤。她用冷静期换来主动权，周曼就必须在三十天内让她撑不住。2016年的记录进了系统，所以周曼必须偷走原件，反咬她伪造。补录要等到8月10日生效，所以陆铭敢在8月8日硬闯。
- **情绪升级**：第1–9集六层压力，从轻到重：身份 → 房子 → 工作 → 尊严 → 名誉 → 母亲的命。第37–40集是第二轮更重的打压：自由、舆论、证人一个个失去。没有翻旧账，每一次冲突都带着新的信息。
- **不重复争吵**：沈知微和陆铭正面交锋七次（第2、7、10、16、17、22、36集，加上第57集收尾），每一次的筹码都不同；和温峥的两次裂痕（第21、33集），原因也不一样，一次是立场之争，一次是边界之争。
- **反派动机**：周曼要股权，陆铭要身份，许晴要被选中，老马和冯建要钱，阿坤听命办事。没有一个反派只是为了羞辱主角而存在。
- **原创说明**：本剧人物、情节均为原创。规则库中的结构方法（一卡十集、六层拉扯、中点反转、至暗时刻）只作为节奏参考，没有套用任何示例桥段。
