# 《离婚那天，我只带走了一坛老汤》· 主要人物小传

> 竖屏短剧 · 全剧 60 集 · 标准档（每集 90～120 秒）· 红果/抖音付费剧
> 一句话故事：给前夫的卤味连锁熬了七年汤、名字却从没上过一张纸的女人，离婚那天只带走一坛老汤。可周记十家店的味道全靠这坛汤撑着——再往深挖，这坛汤背后是她父亲被夺走的六十八年老字号。
> **情绪契约**（全剧不变的那口气）：**我熬的汤，谁喝了都得认账。**——被当成"白吃饭的"手艺人，让一个个吃她饭发家的人当众认账。

## 二、人物小传（四件套 + 赌注）

### 1. 姜晚（34）——主角

**明面**：周记卤味的"后厨老板娘"。七年里没拿过工资，社保、营业执照、股东名册上都没有她的名字。
**暗面**：老字号"姜记卤味"第三代唯一传人。她手里的黑陶坛是祖父 1958 年（戊戌年）起的母卤，到今年养了 68 年，坛底刻着"姜记・戊戌"。

**前史（只进圣经，正文里靠物证和别人的反应慢慢带出来）**：1999 年父亲姜德顺病重住院，二叔姜德茂"接手"了姜记。父亲临终前，徒弟马长福偷偷把母卤坛从店里抱出来，交给了姜晚的母亲。母亲带着坛子在文化路口摆卤味摊，供她长大，叮嘱她一句话："别挂姜记的名，你二叔会来抢。"2018 年母亲去世。2019 年她嫁给常来摊上买卤的业务员周建明，用这坛汤撑起了"周记"。婆婆一句"女人别抛头露面"，她就在后厨待了七年。

| 件 | 内容 |
|---|---|
| **欲望** | 单元A：带走老坛，接回女儿念念 → 单元B：保住"姜记"招牌 → 单元C：拿回父亲的老店和老字号 |
| **秘密/软肋** | ①坛子是姜记母卤，身世一露，二叔必来抢，所以她七年不敢挂自己的名；②女儿念念是她唯一的软肋，周家、鼎味、二叔都会拿念念压她 |
| **弧光** | **A 被动自证**（不辩解，只拿账本和味道说话）→ **B 主动入局**（第 14 集小转换：用卖配方设局；第 29 集大转换：进鼎味当技术总监取证）→ **C 掌控规则**（用法院保全维护、病历时间线、老字号复评规则反制二叔）。终点：她把"姜记"招牌挂回父亲的老店，第一碗汤给女儿 |
| **语言指纹** | 句子短，语气平，从不骂人，**用日期和数字说话**（"二〇一九年四月，房租两万四。"）。爱拿火候、起火打比方，从不讲大道理。被逼到底只说一句短话收住（"才第一天。""你签过字的。"）。对外人称"您"，对周家人七年一直叫"妈"，到第 21 集改口叫"钱阿姨" |
| **功能位** | 主角 ｜ 出场：第 1 集 ｜ 状态机：见台账 |

### 2. 周建明（37）——前夫，单元A 前台施压者

周记卤味老板，名下 10 家门店，正在谈方敬言的 3000 万 A 轮融资。

| 件 | 内容 |
|---|---|
| **欲望** | 拿下融资，把周记做成"中央厨房标准化连锁"；甩掉"灶台上的老婆"，换一个"拿得出手的合伙人" |
| **秘密/软肋** | ①周记背着 1200 万对赌债务，融资失败就得爆雷；②他早就私下见过鼎味的韩启山，何露就是韩启山推给他的人；③他心里清楚周记的味道全靠姜晚，只是七年没敢承认 |
| **赌注**（反派必填） | **要什么**：3000 万融资 + 甩掉姜晚 + 女儿抚养权（向投资人证明他"家庭稳定"）。**能付出什么**：七年夫妻情分、女儿的眼泪、自己的签名。**筹码**：周记所有证照都在他名下，外加女儿 |
| **弧光** | A：体面地狠，拿女儿当筹码 → 第 20 集当庭被自己签的协议反噬 → 第 21 集排队买她的卤，尝一口："是这个味。"当众认账 → B：周记被鼎味吞掉，他入职鼎味，被逼作伪证 → 第 36～37 集看到女儿生病，主动去派出所更正证言，自己担后果 → C：给她守了三天三夜的坛，第 60 集排在开张队伍第一个，自己掏钱买第一碗 |
| **语言指纹** | 体面商务腔，口头禅"大家都体面""你懂事一点""格局"。压低声音说狠话，从不吼。紧张时理袖扣 |

### 7. 陆砚（38）——律师，助力兼情感锚点

区法律援助工作站的签约律师，离异，独自带一个 9 岁的女儿，女儿和念念在同一所幼儿园的大班兴趣课。

| 件 | 内容 |
|---|---|
| **欲望** | 单元A：替她把"七年贡献"打成法庭上的证据 → 单元B/C：把鼎味当年压下去的那件事翻出来 |
| **秘密/软肋** | 他当过鼎味的法务。2020 年鼎味冷库改标签被投诉，公司花钱把事压了下去，他因此辞职，手里留着一份内部邮件（第 34～35 集揭开）。软肋是怕自己又一次"知道却没做" |
| **弧光** | 冷眼旁观的职业律师 → 第 14 集替她起草协议设局 → 第 35 集交出当年的邮件，赌上执业风险 → 第 59 集递给她一张手写菜单："老店开张第一桌，我订"。感情线克制，全剧没有一句告白 |
| **语言指纹** | 法条加冷幽默，口头禅"这句话，我记下了""证据说话"。每次开口必先引一条规矩（"探视权不是你家门锁"） |
