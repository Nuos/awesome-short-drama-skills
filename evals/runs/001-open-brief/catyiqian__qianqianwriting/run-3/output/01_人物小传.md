**一句话故事线**：
结婚二十九年、被全家当保姆的五十岁主妇，在生日当天发现丈夫要让她净身出户，可丈夫的连锁餐饮帝国，招牌卤味全靠她每天半夜熬出来——她向全家递上辞职信，抱走那坛卤，从夜市小摊打回属于自己的名字。

**故事亮点**：
"全家离不开的保姆"其实是"整个帝国离不开的厨神"。她一走，陈记三十二家店的味道当天就塌了。

**一段话梗概**：
沈秀禾二十岁时是老字号知味楼最年轻的掌勺，一场大火之后，她认定是自己忘了关火，从此封刀嫁人，做了二十九年家庭主妇。丈夫陈国栋靠她每晚熬的卤头，把"陈记"做成三十二家店的连锁品牌，却从没让外人知道。五十岁生日当晚，陈国栋带着怀孕的情人回家，拿出一份让她放弃全部财产的离婚协议。沈秀禾递上辞职信，只带走一把旧菜刀和那坛卤。她在夜市重新起锅，在知味楼重拾手艺，在法庭上要回二十九年的家务劳动补偿，也一步步查清三十年前那场大火的真相：火不是她放的，是陈国栋。他偷了师父的菜谱，也偷走了她的半辈子。最后，她穿上绣着自己名字的厨师服，把知味楼重新做成了一块招牌。

**主题**："我先是沈秀禾，然后才是谁的妈、谁的老婆。"

## 三、主要人物小传

### 女主：沈秀禾
50 岁，家庭主妇。前知味楼最年轻的掌勺，陈记连锁卤味的"隐形主厨"。
外表：齐耳短发，夹着几缕白发。眉眼温和，眼角有细纹。身形微胖，肩背习惯性前倾，那是低头干了二十九年活留下的。右手手背有一道旧烫疤，月牙形。
性格标签：#隐忍 #手艺人的骄傲 #外柔内刚 #一旦醒了就不回头
人物经历：二十岁时是知味楼掌柜顾鹤年唯一的女徒弟，一手卤味能让老食客排队。1996 年知味楼后厨失火，师父为救她烧伤了双手。学徒陈国栋告诉她"我亲眼看见你灶上的火没关"，她信了，从此不碰大火、封刀嫁人。婚后二十九年，她每天凌晨一点起来熬卤头，供陈记所有门店，却以为只是在"帮丈夫省钱"。
原始动力：**尊严 → 真相 → 自由**
救猫咪时刻：开场在后门给流浪橘猫撕鸡肉；把桌上最大的鸡腿夹给唯一记得她生日的孙女。
人物弧线：从"这个家的保姆"到"知味楼掌勺沈秀禾"。从怕火（不敢开大火）到在签约会现场当众颠勺爆炒。

```
固定服装：
  · 第1–2集：藏青碎花围裙 + 灰色针织开衫 + 黑布鞋
  · 第3–51集：灰色针织开衫 + 知味楼旧白布围裙（顾怀山给的）
  · 第52–60集：白色立领厨师服，左胸红线绣"沈秀禾"
标志性道具：
  · 黑陶卤坛（坛身有一道冲线裂纹，坛口缠红绳）
  · 木柄旧菜刀（刀柄刻一个"禾"字，师父所赠）
  · 手背月牙形烫疤（每次靠近大火会下意识缩手）
```

### 男一号反派：陈国栋
54 岁，陈记餐饮董事长，三十二家门店，正在谈被鼎味集团收购。
外表：背头，发际线后移，抹发胶。金丝眼镜，左腕一块金表。常穿深灰 Polo 衫配西裤，说话前习惯先推一下眼镜。
性格标签：#伪善 #精于算计 #体面控 #从不承认自己错
人物经历：1994 年进知味楼当学徒，天赋平平，嫉妒沈秀禾。1996 年一个深夜，他溜进仓房偷顾鹤年的手写菜谱，碰翻照明用的酒精炉，引发大火。他带着菜谱逃出来，又回头当了"第一个报警的人"，再对沈秀禾说是她没关火。随后他娶了她，用师父的菜谱和她的卤，起家了陈记。对外，他是"背后有个好太太"的模范企业家；对内，他把妻子当成一口不要钱的锅。
原始动力：**占有 / 体面**——他要的不是钱，是"一切都是我陈国栋挣来的"这个说法。
名场面台词："知道我为什么娶你吗？因为你会熬那锅卤。"

```
固定服装：深灰 Polo 衫 + 黑西裤；正式场合换藏蓝西装，别金色领针
标志性道具：金丝眼镜（推眼镜 = 他要撒谎了）、左腕金表、办公室墙内保险柜
```

### 女反派 → 灰色转向：许曼
32 岁，陈记品牌总监，陈国栋的情人，也是"陈记秘卤"的直播代言人。
外表：长直发，妆容精致，红唇。常穿白色西装套装，细高跟。说话时喜欢把手放在小腹上。
性格标签：#野心家 #精明 #识时务 #最怕变成另一个沈秀禾
人物经历：小镇出身，靠自己爬到品牌总监。她以为跟着陈国栋就能当上"老板娘"、拿下品牌。"怀孕"是她和陈国栋商量好用来逼离婚的谎话。直到陈国栋把收买证人的事全推到她头上，又逼她签下放弃一切的婚前协议，她才看清：自己正站在沈秀禾站了二十九年的位置上。
原始动力：**往上爬 → 自保**
关键转折：第 28 集被抛弃；第 43 集主动找沈秀禾；第 48–49 集冒险录下陈国栋的认罪。

### 男主（感情线）：顾怀山
55 岁，知味楼现任掌柜，沈秀禾的师兄。
外表：头发花白，剃得很短。高瘦，有点驼。常年一件洗旧的白厨师褂，袖口卷到小臂，围裙上永远别着一支圆珠笔。脸上没什么表情。
性格标签：#冷面热心 #嘴硬 #守诺 #一根筋
人物经历：顾鹤年的独子。火灾那晚，他锁门前查过灶台，记得沈秀禾那口灶是关着的。可她第二天就不告而别，他便以为她心里有鬼，怨了她三十年。父亲失智后，只记得一句话："小禾的卤，不能断。"火灾前，顾鹤年从母卤里分出过一坛子卤，顾怀山照着父亲的嘱咐，一天不落地养了三十年。
原始动力：**守护**（守父亲、守老店、守一个没说出口的人）
名场面台词："坛子碎了，卤没死。我替你，养了三十年。"

```
固定服装：洗旧白厨师褂（袖口卷起）+ 深蓝布围裙，围裙口袋别一支蓝色圆珠笔
标志性道具：圆珠笔（紧张时咔哒咔哒按）、知味楼后院那口老灶、一只白瓷子卤坛
```
