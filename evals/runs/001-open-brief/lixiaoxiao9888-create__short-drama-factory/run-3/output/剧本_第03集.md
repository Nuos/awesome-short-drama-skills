第【3】集：【机器会赊账？·铺子早被押了】
《六十大寿，我把账本拍在了桌上》｜标准档 90～120 秒
【所属阶段】：第一幕・入局压迫期（第 3/60 集 ｜ 单元A ｜ 往返第 1 回合收尾・证据档2/反驳档2→3）
【黄金前3秒钩子】：生死绝境（物理威胁降级版：接上集，手探进滚锅抢账本，手背当场烫红）
【冲突形态】：对话型
【情绪流变】：烫手抢回账本 ➔ 当众对日期 ➔ 收款流水作证 ➔ 王婶倒向 ➔ 诊断书被戳穿 ➔ 三十万担保说漏嘴 ➔ 铺子早被押出去 ➔ 儿子下跪
【本集物证】：蓝皮账本（湿了一角）；收款码流水截图；《担保借款合同》（抵押物一栏写着余记豆腐坊）
【质疑者配角】：陈小雨（替观众把流水举到街坊眼前）；王婶（被点名后替观众说出"那天桂兰清清楚楚的"）
【本集执念】：我没糊涂——我记的每一笔都算数
【对手要什么】：刘美娟要用诊断书让街坊和儿子都认定"她的话不算数"；刘凯要把这事搅浑，保住自己的三十万窟窿不露馅
【本集主角主动目标】：当场用账本对日期，拆掉诊断书；追问"三十万担保"到底给谁
【本集改变了什么】：关系——王婶第一次站到余桂兰这边；信息——卖铺子的真动机是给刘凯填三十万窟窿，且铺子早被写进抵押物；身体——余桂兰手背烫起水泡
【本集结算】：诊断书被收款流水和王婶当场戳穿，刘凯一句"机器自动收款"被"机器会赊账？"怼得全街哄笑，刘美娟把诊断书往身后藏——"糊涂"这顶帽子当众摘了
【本集时长】：88 秒

[场景]：外景・槐树巷余记豆腐坊门口・清晨（接上集）
[人物]：余桂兰（手背烫伤）、刘美娟（儿媳）、刘凯（中介）、陈志强（匆匆赶来）、陈小雨（孙女）、王婶（老街坊）

△ 特写：余桂兰的手探进锅沿，一把攥住账本，滚烫的豆浆溅上手背，烫出一片红。
陈小雨（扑上来｜尖叫）："奶奶！你的手！"
△ 余桂兰把账本举离锅口，书页只湿了一角。她甩了甩手，手背鼓起一串水泡。
刘美娟（后退半步｜嘴硬·发虚）："是您自己扑上去的，可别赖我。"
王婶（看着那串水泡｜压低声音）："美娟，你这下手也太狠了……"
△ 余桂兰没理任何人，把湿了的那页在围裙上按干。
余桂兰（用烫红的手翻账本｜平声）："诊断书上写，十月三号上午十点，我在体检中心面诊。"
余桂兰（停在一页｜一字一顿）："十月三号，我出摊十一个钟头，卖了四百一十二块六。"
刘美娟（抱着胳膊｜嗤笑）："账是您自己写的，想写什么写什么！"
余桂兰（不看她｜淡淡）："那就看不是我写的。小雨。"
△ 陈小雨抹了把眼泪，飞快解锁手机。
陈小雨（掏出手机举给街坊看｜急促）："这是奶奶的收款流水！早上六点到下午五点，一笔没断！"
△ 特写：手机屏幕上一长串收款记录，其中一行：十点零七分，豆腐，5.00。
余桂兰（看向人堆里的王婶｜轻声）："十点零七分那笔，凤琴，是你吧？你还赊了两块。"
王婶（被点名，端着碗僵住｜支支吾吾）："……是我。那天桂兰在摊上，清清楚楚的。"
△ 街坊们的目光齐刷刷转向刘美娟手里那张诊断书。
刘凯（抢着打圆场｜拖长音）："机器自动收款，谁知道是不是她本人……"
余桂兰（盯着他｜淡淡）："机器会赊账？"
△ 人群里爆出一阵笑。刘美娟把诊断书往身后藏，纸角捏得发皱。
刘美娟（梗着脖子｜尖声）："章是真的！人家体检中心还敢乱盖章？"
陈小雨（指着诊断书抬头｜急促）："认知障碍要去医院专科确诊，体检中心根本出不了这个诊断！"
△ 几个街坊跟着点头。王婶把豆浆碗往案板上一搁，站到了余桂兰身后。
陈志强（拎着公文包挤进人群，满头大汗｜急促）："美娟！别闹了，回家说！"
刘美娟（一把甩开他｜尖声）："回什么家！铺子不卖，你那三十万担保，下礼拜就到期！"
△ 全场一静。陈志强的脸刷地白了，公文包掉在地上，一沓纸滑出来。
余桂兰（弯腰捡起最上面那张｜轻声）："三十万担保？给谁担保？"
陈志强（嗫嚅｜声音发虚）："妈……小凯说开店周转，三个月就还……"
内心独白：他九岁偷拿两块钱，回来跪着认错。三十九岁，连头都不抬。
△ 刘凯把头扭开，往人堆外挪。
余桂兰（头也不回｜沉声）："小凯，站住。"
△ 特写：余桂兰手里是一份《担保借款合同》，借款人：刘凯，金额：三十万元整。
△ 特写：抵押物一栏写着"槐树巷十七号余记豆腐坊"，签字处：陈志强（代余桂兰）。

【本集断章卡点】：余桂兰把起泡的手背按在"余记豆腐坊"那几个字上，抬眼看着儿子，一字一顿："陈志强，你把你妈的铺子，押给了你小舅子。"陈志强"扑通"一声，跪在了豆腐摊前。（黑屏：下滑立即解锁第4集）
