# 《六十大寿，我把账本拍在了桌上》主要人物小传

> 竖屏短剧 · 60 集 · 标准档（每集 90～120 秒）
> 赛道：中性·中老年家庭伦理 × 账本清算式（恩人反杀变体）｜流派：情绪流主线 ＋ 剧情流支线（三十年前集资款悬案）
> **情绪契约**：让占了老实人便宜的人，当着众人一笔一笔还清。
> 具名角色 10 人（含 1 位已故者），其余为群演功能位。

---

## 人物关系一句话

槐树巷卖了三十年豆腐的余桂兰，被儿子儿媳逼着让出老铺子（单元A）；赶走家贼后，开发商盯上了整条巷子和她家那盘老石磨（单元B）；最后她发现，三十年前"卷款失踪"的丈夫是被人顶了罪，罪魁就是如今的慈善家董事长（单元C）。

```
                  赵德海（终极反派·原纺织厂副厂长）

                                      │ 夫妻

                    │      │                    │ 父女
              老街坊 王婶  隔壁 郑国良        陈小雨（孙女）
```

## 1. 余桂兰 —— 主角

| 项 | 内容 |
|---|---|
| 基本 | 女，60 岁。槐树巷十七号"余记豆腐坊"老板。原临州第二纺织厂会计，1996 年厂里集资款失窃、丈夫失踪后被辞退，从此推磨卖豆腐。 |
| 外形记号 | 永远系一条洗白的蓝围裙，兜里揣着房本和一支圆珠笔；手上有泡豆子泡出来的白茧。 |
| **欲望（可拍）** | 守住老铺子和那盘石磨，让欠她的人当众把账认下来。 |
| **秘密/软肋** | 她心里有一笔从没对人说过的账：她始终不信丈夫是卷款跑的，可三十年来拿不出一个证据，只能替他把三十八万一户一户还清。谁拿"陈建国是贼"戳她，她就站不稳。 |
| **弧光** | 单元A（1–22）被动自证：用账本一笔笔反证"我没糊涂"；第11集起以身入局，搬去养老院引对方露馅。→ 单元B（23–42）主动设局：从"守自家铺子"变成"替整条巷子算账"，第33集假意卖磨钓出幕后。→ 单元C（43–60）掌控规则：不再等人还公道，自己申请法院公开开磨、把三十年旧账交给法律。终点：账本最后一页写"还清了"，石磨重新转起来。 |
| **语言指纹** | ①说数字精确到角分（"四百一十二块六"）；②越生气声音越低，从不吼；③口头禅"账上有。""记着呢。"；④平时叫儿子"志强"，伤透心时叫全名"陈志强"；⑤只对郑国良叫小名"国良"，其余人一律直呼其名。 |
| 标志物 | **蓝皮账本**（养儿账/家账）、**红皮账本**（替丈夫还集资款的"还账本"，18 年逐户签收按手印）、满墙赊账木牌。 |
| 功能位 | 主角 ｜ 首出：第1集 |

|---|---|

| **欲望（可拍）** | 把替小舅子担保的三十万窟窿悄悄填上，别让单位和老婆知道自己有多窝囊。 |
| **秘密/软肋** | 他在担保合同上签了"陈志强（代余桂兰）"，把母亲的铺子写成了抵押物；他从小被街坊叫"卷款犯的儿子"，最怕别人提父亲。 |
| **弧光** | A：沉默帮凶（低头剥虾）→ 第3集当众下跪 → 第13集第一次攥住妻子扬起的手 → 第19集当庭撤回申请。B：拒绝孙启明"替你还债换石磨"的交易（第30集）。C：第56集面对"保你前程还是保你爸清白"的二选一，自己选"开磨，我的债我自己扛"——弧光封顶。 |
| **语言指纹** | 话说一半、句尾带省略号；开口先推人"美娟也是……""小凯说……"；单元C后句子变短、不再找借口。 |
| 功能位 | 情感锚点（被挽回者）｜ 首出：第1集 |

## 3. 刘美娟 —— 儿媳（单元A 前台反派 → 单元C 反转棋子）

| 项 | 内容 |
|---|---|
| 基本 | 女，40 岁。社区超市收银组长，嘴快手快，算盘全打在眼前。 |
| **欲望（可拍）** | 把槐树巷十七号过户到丈夫名下，拿拆迁款换学区房，顺手把弟弟的三十万窟窿填了。 |
| **赌注/利害（反派必填）** | 要的东西：老铺子产权（她听说要拆迁，至少值两百多万）。能付出的代价：婆媳关系、街坊名声，最后是夫妻关系。筹码：骗签的《授权委托书》、花三千块买的诊断书、收买的邻居证言、"法院认定无民事行为能力"申请。 |
| **秘密/软肋** | 她以为自己在算计婆婆，其实是被孙启明和弟弟当枪使——"铺子过户后另给二十万"的承诺是空头支票。她最怕的是"被人当傻子"。 |
| **弧光** | A：步步紧逼（逼签→挂牌→诊断书→换锁→申请认定无行为能力）→ 第20集发现自己被利用 → 第21集当众交还钥匙、搬出铺子。C：被赵德海一方抛弃后，第52集带着孙启明藏在她那里的U盘上门倒戈。终局：第60集来买豆腐，余桂兰照价收钱——"不赊"。 |
| **语言指纹** | 开口必带"妈，不是我说您"；爱用"您"带刺（"您恶不恶心"）；拖长音、反问收尾；急了就尖声吼"白纸黑字"。 |
| 功能位 | 单元A 核心施压反派 / 单元C 反转棋子 ｜ 首出：第1集 |

## 4. 陈小雨 —— 孙女（质疑者配角 · 助力）

| 项 | 内容 |

| **欲望（可拍）** | 替奶奶把道理讲到明面上——每一条都得有出处、有证据。 |

## 9. 赵德海 —— 海川置业董事长（终极反派）

| 项 | 内容 |
|---|---|
| 基本 | 男，68 岁。原临州第二纺织厂副厂长，1997 年下海，如今是本地知名企业家、慈善基金会理事长，手腕上常年一串佛珠。 |
| **赌注/利害（反派必填）** | 要的东西：那盘石磨（他怀疑陈建国当年把能定他罪的凭证藏在了余家），以及自己"慈善家"的名声。代价：三十年经营的身份与自由。筹码：陈建国被逼写下的"认罪书"、伪造的个人借条、鑫利小贷转来的志强三十万债权、对郑国良的旧把柄、雇来冒名顶替的"陈建国"。 |
| **秘密/软肋** | 1996 年他挪用职工集资款三十八万办自己的公司，被出纳陈建国发现后，逼陈写下认罪书并"离开临州"。他从没读懂陈建国在认罪书里藏的那行字。 |
| **弧光** | 第42集以"救世主"身份亮相，当众拿出认罪书，把余桂兰推入全剧至暗 → 第43集认罪书被小雨读出藏头"赵逼我写账在磨底" → 查封、冒名、威胁、毁证接连失手 → 第58集法院公开开磨，原始凭证当场取出 → 第59集因伪造证据、虚假诉讼、指使伪造拆迁文件等被公安机关依法带走，旧案由检察机关依法复查。 |
| **语言指纹** | 慈祥长辈腔，称余桂兰"嫂子"；爱说"都过去了""何必呢"；从不提高声音，转佛珠的手一停，就是要动手了。 |
| 功能位 | 终极反派 ｜ 首出：第41集集尾露面，第42集正式登场 |

## 10. 陈建国 —— 余桂兰的丈夫（已故 · 只以物证出场，不开口）

| 项 | 内容 |
|---|---|
| 基本 | 男，1962 年生。原纺织厂出纳。1996 年 11 月 8 日夜里离家，从此被认定"卷走集资款三十八万潜逃"。1997 年在外省工地事故中去世，化名"余建国"——用的是妻子的姓。 |
| 留下的东西 | ①1996 年 8 月亲手重新浇筑的石磨底座（账上记着"水泥钱十一块"）；②1996.12–1997.7 每月 200 元、共八笔的无名汇款（余桂兰记作"好心人"）；③最后一张汇款单附言"桂兰，磨要常转"；④被逼写下的认罪书，每行第一个字连起来是"赵逼我写账在磨底"；⑤磨底铁皮盒：挪用凭证原件、手写证词、一封给桂兰的信。 |
| 功能 | 全剧最大信息差的源头：观众和余桂兰一起，从"他是贼"一步步走到"他用一辈子护着这个家"。 |
| 状态 | 已故（剧中不出现对白，避免"死人开口"）。第46集出现的"陈建国"为赵德海雇来的冒名者。 |
