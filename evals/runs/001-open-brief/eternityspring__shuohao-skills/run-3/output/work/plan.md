# 《签字之前》60 集逐集计划（分集写手的唯一依据）

格式：集号｜建议场景｜建议出场角色｜剧情要点｜结尾悬念。【Bxx】= 该集落着的爽点（必须在梗概里演出来）。【卡点】= 付费卡点集，结尾悬念要最狠。

时间设定：现在是 2026 年；前世沈栀死于约五年后；母亲沈清禾死于 2006 年顾氏老厂区实验室大火（顾远山同场遇难）。

## 第一幕 重生·撕契约·退婚（1–10）

1｜S05 S01｜C01 C03 C04 C05 C11｜冷开场：前世，沈栀被锁在顾氏老厂区仓库，烟从门缝灌进来，她拍门，门缝外一点打火机火光；手机里白芷笑说配方我们收下了。她倒下。睁眼：顾家签约厅，顾家律师把笔递到她手里，顾承泽温柔催签，周婉端坐。她翻到附件——全部配方无偿转让顾氏，和前世一字不差。【B01】｜她落笔，写下的不是名字。
2｜S01｜C01 C03 C04 C05 C06 C11｜她在签名栏写下作废两个字，当着两家长辈逐字念出附件条款，把协议撕成两半。顾承泽圆场说律师弄错了，周婉冷冷说婚礼照办。沈栀反而笑着答应婚照结，附件永远别想。沈怀山吓得不敢出声。【B02】｜白芷低头悄悄给某人发消息：她好像知道了。
3｜S02｜C01 C05 C02｜回工作室，配方手稿本不见了，白芷说带回家备份。沈栀想起前世正是今晚手稿落进顾家。她不动声色，夜里写下一页假雪栀配方（关键定香剂替换成三天后会酸败的成分），夹进手稿，让白芷顺手带走。深夜门铃响，陆砚深站在门外说要定制一款香。【B03】｜他说要的味道，叫雪栀。
4｜S02｜C01 C02｜雪栀是母亲从未公开的香，沈栀震惊。陆砚深说很多年前有人送过他一瓶，不肯多说。他留下名片，只说一句别嫁给顾承泽。他走后沈栀想起前世：她死后，唯一追查顾氏的人就是陆砚深。｜他到底从哪里闻过雪栀。
5｜S02 S14｜C01 C07 C05 C03｜唐楚帮沈栀把真配方做了公证存证。晚上白芷说回老家，顾承泽说加班。沈栀跟到云栖酒店客房走廊，录音笔录下两人在门内商量：等她签了附件，就送她进去。【B04】｜房门突然打开。
6｜S13｜C01 C06｜（上集房门开，沈栀躲进消防通道脱身，一笔带过）沈家老宅，沈怀山拿着顾家的抵押文件正要签字——把清禾香料抵押给顾家做嫁妆担保。沈栀冲进来夺下文件。父女争吵，父亲说顾家得罪不起。沈栀想起前世工厂倒闭、父亲中风。｜父亲说顾太太约他明天去顾家。
7｜S01｜C01 C04 C05 C06｜白芷陪沈怀山去顾家，周婉施压。沈栀赶到，甩出顾氏拖欠清禾香料三年货款的对账单，要么先结账要么别谈担保，周婉当场收回文件。【B05】｜周婉对白芷低声吩咐：婚礼那天，把那份东西换个名字再给她签。
8｜S06｜C01 C02 C03 C04 C12｜婚礼前夜彩排宴，顾承泽当众宣布婚礼当天同步发布顾氏新品雪栀。沈栀闻样品，正是她那页假配方的味道。陆砚深作为供应商出席，与她擦肩时低声说明天他会在场。｜顾承泽当众说婚礼上还有一份惊喜要她签。
9｜S06｜C01 C05 C07｜婚礼当天化妆间，白芷递来新婚礼物——换了名头的婚后财产共管协议，附件内容一样。沈栀读完每一个字，笑着说仪式上当众签更有意义。她把一个 U 盘交给唐楚，替换掉大屏要播的爱情短片。｜白芷发现大屏 U 盘被动过，拿起电话。
10【卡点①】｜S06｜C01 C02 C03 C04 C05 C12 C13｜婚礼仪式，司仪请新人看大屏。播出的是酒店录音和换皮协议条款，满场宾客哗然。沈栀摘下戒指放在协议上，当众退婚。顾承泽伸手要抓她，陆砚深上前挡开。【B06】｜周婉走到她身边，低声说你妈当年，也是站在这个位置。

## 第二幕 契约婚姻·假配方爆雷·母亲之谜（11–24）

11｜S02 S13｜C01 C05 C06｜退婚后，顾家买水军造谣沈栀精神异常、婚内出轨陆砚深。房东受顾家施压收回工作室，白芷带人来搬东西；清禾香料被顾氏断供原料。沈栀抱着纸箱走出工作室。｜一辆黑色轿车停在她面前。
12｜S08｜C01 C02 C09｜陆砚深车内，他提出协议结婚：陆氏需要她的鼻子做新香氛品牌，她需要陆氏挡住顾家的诉讼。程野递上协议，沈栀逐条读，配方条款写着永久归沈栀个人所有、陆方永不主张。她问为什么，他不答。｜她合上协议说明早九点，民政局。
13｜S12｜C01 C02 C03 C13｜民政局门口，顾承泽带记者堵门要拍出轨实锤。陆砚深牵着沈栀走出来，当众亮出刚领的结婚证，顾承泽下不来台。【B07】（牵手→肢体接触）｜顾承泽冷笑：等雪栀上市，看你还笑不笑得出来。
14｜S04｜C03 C04 C16｜顾氏雪栀上市第三天，大面积变酸投诉，门店退货潮。顾承泽在实验室闻到酸败味，质问顾氏调香师，调香师说配方本身有问题。顾承泽这才明白偷来的是假配方。【B08】｜周婉说：那就让她来背。
15｜S03｜C01 C02 C14｜沈栀在陆氏的新调香室工作。顾氏发声明起诉她提供缺陷配方、商业欺诈。警官上门带她去问询，陆砚深要跟被拦下。｜警官说：有人证，是你的助理。
16｜S11｜C01 C07 C14 C05｜问询室，白芷作证说沈栀故意给错配方。唐楚赶到，出示真配方的公证存证，时间早于顾氏备案；并指出顾氏手里那页配方只可能是从她工作室偷走的。偷配方的人反成被告，白芷慌了。【B09】｜门外，顾承泽对白芷说：这件事，你一个人扛。
17｜S04 S08｜C03 C05 C01｜顾氏发声明，把配方事件定性为前助理白芷个人行为。白芷被顾家抛弃，深夜拦下沈栀的车要交易。沈栀开条件：交出顾承泽指使你的证据。｜白芷说：我手里的，不止是他的。
18｜S08 S13｜C01 C05 C06｜车内，白芷交出手机录音：周婉对顾承泽说，当年对清禾也是这么处理的。沈栀第一次从仇人嘴里听到母亲的名字。白芷要钱跑路，沈栀给了。她回老宅问父亲，母亲到底是怎么死的。【B10】｜父亲沉默良久，说去老街找陈伯。
19｜S10｜C01 C08｜陈伯的香料铺，陈伯拒不谈旧事，赶她走。沈栀闻出铺子里一味冷萃栀子，报出母亲惯用的配比。陈伯闻到她身上的雪栀，手抖，眼眶红了。｜陈伯说：你身上这个味道，二十年前就该跟着你妈烧没了。
20｜S10 S05｜C01 C08 C10｜陈伯讲述：雪栀是沈清禾的作品；2006 年顾氏老厂区实验室大火，沈清禾死了，雪栀从此成了顾氏的镇店之宝。火灾当晚，他看见周婉的车停在厂区外。闪回：年轻的沈清禾在实验室调香。【B11】｜陈伯说：那晚火里，还跑出来一个孩子。
21｜S03｜C01 C09 C02｜程野让沈栀去总裁办公室取文件，她在陆砚深的保险柜里看见一瓶旧玻璃瓶的雪栀原液，标签是母亲的字迹。她开始怀疑陆砚深接近她另有目的。｜陆砚深推门进来，看见她手里的瓶子。
22｜S03 S05｜C01 C02 C10｜对质。陆砚深坦白：火里跑出来的孩子就是他。那天母亲带十岁的他去找沈清禾，起火时沈清禾把他推出窗外，塞给他这瓶原液，说交给栀栀。他暗查顾氏十年，不敢靠近她，是怕她走她母亲的路。【B12】｜程野冲进来：沈先生的厂被查封了。
23｜S13 S07｜C06 C04 C01｜周婉宣布顾氏收购清禾香料全部债权，逼沈怀山破产。债主上门，沈怀山心脏病发，被送进医院。｜病房楼下，周婉的车停下。
24【卡点②】｜S07｜C01 C04 C06 C15｜周婉来探病，递出和解条件：交出雪栀原液、撤销对顾氏的全部指控，就放过她父亲。沈栀读完，说这份她不签。周婉走后，一名顾家护工进病房给沈怀山换了一袋输液。｜监护仪骤然尖响。

## 第三幕 盲闻对决·储香箱·第二场火·内鬼（25–40）

25｜S07｜C01 C06 C15 C09 C14｜抢救时，沈栀闻出输液袋里有不属于医院的异味，喊停，拔掉输液管，父亲脱险。程野调监控揪出顾家护工，警官带走。护工没供出周婉。【B13】｜护工被带走前回头：你斗不过她。
26｜S08｜C01 C02｜陆砚深安排人守病房。深夜车内，两人第一次真心交谈。沈栀说她做过一个很长的梦，梦里她死在火里，他是唯一来查的人。陆砚深没说话，把外套披在她身上。｜他说：栀品牌下周发布，顾家一定会来砸场。
27｜S03 S04｜C01 C02 C03 C04｜栀品牌筹备首发。顾承泽在网上散布栀抄袭顾氏雪栀，并备好顾氏 2006 年的雪栀配方备案，准备发布会上发难。｜周婉说：让她在全城面前，认下抄袭。
28｜S06｜C01 C02 C03 C08 C12 C13 C16｜栀品牌发布会，顾承泽带记者当众指控抄袭、亮出备案。沈栀提出现场盲闻对决：顾氏调香师认错三味原料，沈栀一一报出，包括顾氏至今做不出的冷萃栀子。陈伯登台，指出备案上的字迹是沈清禾的；陆砚深拿出雪栀原液，与栀的样品同出一源。【B14】｜记者追问顾承泽：沈清禾是谁？
29｜S04｜C03 C04 C13｜余波：顾氏股价暴跌，媒体翻出沈清禾旧照与火灾报道。顾承泽被董事会紧急召回，记者堵在顾氏大楼门口。｜周婉站在会议室门口等他。
30｜S04｜C03 C04 C05｜董事会上，周婉当众扇了顾承泽一耳光，收回他的执行权。顾承泽第一次红着眼看母亲。散会后周婉给白芷打电话，启用她。【B15】｜白芷挂了电话：我知道该怎么做。
31｜S13｜C01 C06 C02｜沈怀山出院回老宅，交出亡妻留下的铜钥匙：你妈说等你出嫁那天给你。钥匙柄上刻着顾氏老厂区的旧厂徽。｜电视新闻：顾氏宣布下周拆除老厂区。
32｜S10｜C01 C08 C05｜陈伯认出钥匙：是老厂区地下储香室的，只有他和清禾有。拆除在即，必须赶在之前进去。沈栀离开香料铺时，白芷脸上带伤出现在门口，求她收留。｜白芷说：顾家要我的命。
33｜S03｜C01 C02 C05｜沈栀收留白芷，陆砚深反对。白芷凑近时，沈栀闻到她身上有周婉专用的沉香，确认她是内鬼。沈栀当着她的面装作不经意说出钥匙和储香室，说明晚去。【B16】｜白芷躲进楼梯间发消息：明晚，老厂区。
34｜S05｜C01 C02｜当夜（提前一晚），沈栀和陆砚深摸进老厂区废墟，找到地下储香室，铜钥匙打开储香箱：母亲日记、原始配方，和一只刻着婉字的银色打火机。沈栀认出，那就是前世门缝外的火光。【B17】｜头顶传来铁门落锁的声音，烟从缝里灌下来。
35｜S05｜C01 C02｜火起，浓烟。沈栀照母亲日记里画的通风道图找到出口，陆砚深护着她爬出去，手臂被烧伤。厂区外一个人影逃走。｜爬出来后，陆砚深倒在地上，袖子烧焦。
36｜S07｜C01 C02 C09｜医院，陆砚深手臂烧伤。沈栀守在床边，说出心里话：协议到期，她不签离婚。陆砚深笑了。【B18】｜程野冲进来：调香室被翻了，日记不见了。
37｜S03｜C01 C07 C09｜日记被偷，白芷也不见了；打火机沈栀一直贴身带着。唐楚分析：光有打火机不够，证明不了是谁的、什么时候的。｜沈栀说：那就让周婉自己把证据送上门。
38【卡点③】｜S04 S03｜C01 C04 C05｜沈栀放出风声：日记里有周婉纵火的证据，明天交警方（其实日记里没写凶手名字）。周婉找白芷要日记销毁，白芷留了一手要钱，周婉翻脸。深夜，白芷打给沈栀。｜白芷在电话里哭喊：她要杀我。
39｜S15｜C01 C05 C14｜顾氏大楼天台，周婉的人把白芷逼到栏杆边。沈栀带警官赶到救下她。白芷崩溃，交出日记和周婉的通话录音（周婉在电话里说处理掉她）。【B19】｜日记最后一页写着：婉姐约我今晚谈配方，远山也会来。
40｜S03 S04｜C01 C03｜沈栀查到顾远山——顾承泽的父亲——死于同一场火。她把日记那页复印件交给顾承泽。顾承泽撕了复印件，说她疯了。｜顾承泽回到家，站在父亲遗像前。

## 第四幕 舆论反转·董事会·第三场火（41–50）

41｜S01｜C03 C04｜顾承泽在家翻父亲遗物，找到父亲死前写给沈清禾却没寄出的信：要公开雪栀的真相，还清禾一个名字。他第一次怀疑母亲。【B20】｜周婉站在书房门口：你在找什么。
42｜S04｜C03 C04 C11｜周婉先下手：让顾家律师伪造顾承泽签字，把顾氏财务造假推到他这个法人身上，并备好说辞把火灾推给死去的顾远山。顾承泽被停职，被保安请出公司。｜周婉说：明天，开记者会。
43｜S06｜C04 C13 C01｜周婉记者会上声泪俱下，称当年火灾是丈夫顾远山酒后失手，她替亡夫向沈家道歉，并高价收购栀品牌作补偿。舆论一边倒同情周婉。沈栀在台下看完。｜沈栀说：她连死人都不放过。
44｜S03｜C02 C17 C09｜网上骂沈栀吃人血馒头。陆氏董事会以撤资逼陆砚深放弃沈栀与栀品牌，陆砚深当场递交辞呈。【B21】｜程野拨通沈栀的电话：陆总辞职了。
45｜S08 S03｜C01 C02 C07｜沈栀赶去陆氏，陆砚深在车里拦她，不想她为自己低头。沈栀说这次换她来签字。她和唐楚连夜准备材料。｜董事会明早投票罢免他。
46｜S03｜C01 C02 C17｜董事会会议室，沈栀闯入，甩出栀品牌预售数据、专利估值，以及她名下全部配方的独家授权书——只授权给陆砚深本人，他走配方走。董事们收回投票。【B22】｜散会时，沈栀手机收到一张照片：父亲被绑在老厂区。
47｜S13 S08｜C01 C02 C04 C07｜老宅里只剩翻倒的椅子。周婉打来电话：拿打火机换你爸，一个人来。陆砚深要跟，沈栀让他暗中跟着；唐楚报警。｜沈栀把打火机放进左边口袋，把录音笔放进右边口袋。
48【卡点④】｜S05｜C01 C04 C06｜老厂区废墟，沈栀独自赴约，父亲被绑在柱子旁。周婉要打火机，沈栀交出，周婉接过就点燃了地上的汽油。｜火线沿着地面烧向父女俩。
49｜S05｜C01 C02 C03 C04 C06｜顾承泽一路跟踪母亲，冲进来挡在沈栀身前，逼问父亲是不是她杀的。周婉承认：他要把配方还给沈清禾，他该死。顾承泽手里的录音笔亮着。陆砚深从侧门冲进来救出沈怀山。【B23】｜警笛声里周婉笑了：录音？法庭不认的。
50｜S05 S11｜C01 C04 C07 C11 C14｜周婉被捕，却拒不认罪，顾家律师称录音是胁迫下所说，打火机来源不明是伪证。｜唐楚点出：打火机缺一环——证明它当晚就在火场。

## 第五幕 庭审·空白页·签字（51–60）

51｜S10｜C01 C08 C07｜陈伯回忆：当年消防档案里有一张物证照片，但档案早被销毁。｜陈伯说：当年出警的队长，后来提前退休回了乡下。
52｜S03｜C01 C02 C09 C18｜程野把退休消防员接到陆氏。他私藏了当年的照片底片——他一直觉得那不是意外。【B24】｜开庭前一晚，白芷失联。
53｜S09｜C01 C04 C05 C07 C19｜第一次庭审，白芷被周婉收买，翻供称沈栀逼她作伪证。局势对沈栀不利。｜法官宣布休庭三天。
54｜S10｜C01 C05｜沈栀约白芷到香料铺，不劝，只让她闻一款香——大学时两人一起调的第一款。白芷崩溃。｜白芷说：我手机里，还有她给我转账的记录。
55｜S09｜C01 C04 C05 C07 C18 C19｜再开庭。白芷当庭翻回，交出周婉收买她的转账记录；退休消防员出示照片，照片里正是那只刻婉字的打火机。【B25】｜周婉的律师起身：我方有新证据。
56｜S09｜C01 C04 C07 C19 C11｜周婉亮出沈清禾亲笔签名的配方转让协议，称雪栀早已合法转让，火灾只是意外，她没有杀人动机。签名鉴定为真，旁听席震动。｜沈栀翻开母亲日记的最后一页。
57｜S09 S05｜C01 C04 C07 C10 C19｜沈栀当庭读日记：婉姐让我在空白页上签名，说是借款担保，我没多想。闪回沈清禾签下空白页。唐楚申请鉴定：协议正文墨迹晚于签名。协议当庭作废。【B26】｜周婉回头看向旁听席上的顾承泽。
58｜S09｜C01 C03 C04 C19 C13｜宣判：周婉纵火致两人死亡罪名成立，顾氏破产清算，雪栀配方归还沈清禾名下。法院台阶上，顾承泽向沈栀道歉，沈栀不原谅，也不再报复。｜程野说：陆总没来，他在民政局等你。
59｜S12｜C01 C02｜契约到期日，民政局门口，陆砚深递来离婚协议兑现约定。沈栀逐条读到最后一页：若乙方不愿离，本协议作废。她撕了离婚协议。【B27】（拥抱→肢体接触）｜他说：那我们该补一场婚礼了。
60｜S06｜C01 C02 C06 C07 C08 C12｜云栖酒店宴会厅，正版雪栀发布，署名沈清禾；父亲、陈伯、唐楚都在。发布会后是婚礼，司仪递来婚书，沈栀读完每一个字，再签下名字。【B28】｜尾声：雪栀的香气飘过母亲的旧照片——留一个温暖的收尾，不要开新坑。
