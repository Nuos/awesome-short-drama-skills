## 一、立项单

| 项 | 内容 |
|---|---|
| 剧名 | 《六十大寿，我把账本拍在了桌上》（备选：《余记豆腐坊》） |
| 形态 | 竖屏实拍短剧 · 60 集 · **标准档**（每集 90～120 秒，前三集按递减派 104 / 92 / 88 秒） |
| 赛道 | 中性·中老年家庭伦理 × 账本清算式（恩人反杀变体）；B/C 单元叠加老街改造与三十年悬案 |
| 流派 | **情绪流主线**（观众追的是"他们什么时候认账"）＋ 剧情流支线（集资款真相，信息阶梯推进） |
| **情绪契约** | **让占了老实人便宜的人，当着众人一笔一笔还清。** |
| 一句话故事 | 卖了三十年豆腐的余桂兰，六十大寿被儿子儿媳逼签让出老铺子；她把一本记了三十年的账本拍在桌上——从家贼算到开发商，最后算出了丈夫"卷款潜逃"的真相。 |
| 目标受众 | 红果 / 抖音 35+ 下沉泛龄与 50+ 银发用户；主角就是 60 岁的本人，不是子女视角 |
| 爽点密度 | 每集一次"账本落地"小结算（当众失面 / 盘算落空）；每回合一次大反转；每单元一次闭环清算 |
| 核心物证 | 蓝皮账本（养儿账）· 红皮账本（替夫还债十八年）· 老石磨（底座藏着三十年前的证据）· 满墙赊账木牌 |
| 冲突形态 | 以①对话型为主（嘴上见血，账本就是武器）；单元B 第26集、单元C 第44集为行动外壳＋对话火力的混合集 |
| 前三集节奏型 | 递减派（单场景为主，一集一个物证，逐集收窄加压） |
| 合规定位 | 二类普通备案（都市家庭题材）；剧中民警、法官、征收办均依法公正，不涉公安/司法主线，不触发一类许可；所有反派由法律制裁，主角不动私刑 |

## 六、合规自检（广电 16 号令 · 11 条内容红线）

- **暴力复仇/私刑**：全剧无主角动手报复；第9集老郑制止盗窃只写"扣住手腕"。所有反派（刘凯、孙启明、赵德海、毁证者）均由民警、法院、检察机关依法处理。
- **公权力形象**：民警、法官、养老院院长、市场监管、区征收办全部依法、公正、及时；不出现"买通法官"，反派的不正当手段统一写成"伪造文件 / 违规商业勾结 / 虚假诉讼"。
- **恶行不过 3 集即受惩**：每集都有集内结算；5 个"反派回合"集（22、37、42、49、55）在下一集 15 秒内兑现反击。
- **反拜金**：五百万、一百万的收买全部被拒；终局落在"勤劳、公道、还清"，余桂兰连老工友要退的钱也不收。
- **弱势群体保护**：老人被逼签、软禁、剪辑抹黑的情节都在 1～2 集内被依法纠正，不展示长期虐待；小雨是成年大学生，不卷入暴力。
- **隐私**：剧中不出现真实身份证号、手机号、车牌；网络舆论情节不以"人肉搜索"作为爽点。
- **封建迷信**：无。石磨、汇款、认罪书全部是可验证的物证，按"信号 → 当场可验证 → 产生作用"闭环。
