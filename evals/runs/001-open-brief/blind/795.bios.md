# 《掌眼》主要人物小传

> 竖屏短剧 · 60 集 · 每集 1–2 分钟
> 一句话：刑满出狱的天才鉴定师，在拍卖预展上认出了三年前害她坐牢的那只汝窑——它是真的，而且它又被摆上了拍卖台。

## 沈知微 · 女主

- **年龄 / 身份**：27 岁。曾是瀚古拍卖最年轻的首席鉴定师，业内叫她「小沈眼」。现在是刑满释放人员，被鉴定协会终身除名。
- **外形识别**：短发齐耳，出狱时穿洗旧的灰外套，拎一只网兜，里面有搪瓷杯、一只旧铜放大镜（父亲留下的）和一沓退回来的信。右手小指在狱中洗衣房被机器压过，伸不直，所以上手时习惯用左手托底。
- **外在目标**：在汝窑落槌之前证明它就是三年前她签字的那一只，让它回到陆家，让她和父亲的名字干净回来。
- **被捍卫的信念**：「东西不会说谎，人会。」三年里被未婚夫、师妹、律师、舆论一层层出卖，她只信得过器物。
- **前史成因**：从小在父亲的修复台边长大，十二岁能闭眼摸出胎土。父亲死时她在看守所里，没能见最后一面，也没能去葬礼。
- **惯常策略**：把私人恩怨变成当众鉴定，让器物在所有人面前自己开口。敢赌，常拿自己做筹码，比如当众擦拭别人八百万的拍品、跟人赌一只手。
- **盲区与代价**：她只信东西，不信人，总想一个人扛，结果一次次把身边人拖进火里：秦叔的当铺被烧，小满被绑，陆既明丢了公司。她最信的那个人，又恰恰是做假的人。
- **筹码**：一双眼睛；三年前写在陆家图录上的那行字；父亲的笔记本；对周慎手艺的熟悉。
- **底线**：不做假，不替假东西签字。被逼到绝处时，人比东西重要（EP53 用证据换小满）。
- **弧线**：
  - 前段：只信东西，靠赌眼力硬闯，是一个人在打。
  - 中段：靠陆既明、小满、秦叔一步步还清冤屈，又亲手发现师伯就是凶手。
  - 后段：在器物和人之间选了人。最后的对决她没去比谁眼尖，而是利用了周慎的虚荣：「你舍不得它没有名字。」
  - 终点：不进国家鉴定组，回去重开父亲的「沈记」工坊。
- **说话方式**：句子短，几乎不辩解，一开口就是结论。紧张时会把放大镜在指间转一圈。只有对秦叔会撒娇。

## 陆既明 · 男主

- **年龄 / 身份**：31 岁，陆氏集团（港口物流、保税仓储）执行总裁。陆振山独子。
- **外形识别**：一身黑大衣，不戴表。西装内袋里一直揣着那封盖了「拒收」章的信。
- **外在目标**：弄清父亲到底是被谁骗的。如果预展上那只洗就是三年前那一只，它在法律上属于陆家。
- **被捍卫的信念**：「只认签字和合同。」父亲一辈子信人，被人骗到中风。
- **前史成因**：三年前他亲手把沈知微送进监狱。她从狱中写来十一封信，他一封没拆，全部拒收。父亲在 ICU 里拉着他的手想说什么，没说出来。
- **惯常策略**：用钱、律师和程序压人；拿合同把每段关系写死，连雇沈知微也要先签「如有不实，赔偿全部损失」。
- **盲区与代价**：太相信程序，而周慎恰恰是定程序的人。为了沈知微，他押上公司股权担保，被叔叔陆振海联合董事会停职（EP30）。
- **筹码**：资金、律师团、拍卖会登记竞买人的上手权、陆氏港口的货柜 X 光机（EP50）。
- **弧线**：
  - 先是利用她：「我要看她还能怎么骗。」
  - 再到怀疑（EP12），然后道歉（EP19）：「是我把你送进去的。」
  - 再为她失去公司（EP30），在窑火里护住她（EP43）。
  - 最后把这只洗捐给国家：「让国家来鉴。」
- **说话方式**：慢，讲条件，从不说「我相信你」，只说「我签了」。动心时说的反而是更冷的条款。

## 林晚棠 · 第一阶段主要对手，后转污点证人

- **年龄 / 身份**：26 岁。瀚古现任首席鉴定师，顾承泽的未婚妻。和沈知微同拜周慎门下，叫她「师姐」。三年前两人合租。
- **外形识别**：白西装，珍珠耳钉，指甲永远修得很干净。
- **外在目标**：守住首席的位子，进鉴定协会理事会，最终接下周慎的鉴定学院。
- **被捍卫的信念**：「眼力决定不了谁能被看见，出身才决定。」沈知微有个名修复师父亲，她只有一个摆地摊的妈。
- **前史成因**：学徒那几年，她每次都只排第二。周慎是第一个对她说「你比你师姐更适合这行」的人。
- **惯常策略**：笑着羞辱人，借规则压人；出了事先切割，给自己找证人身份（EP19 反手举报顾承泽）。
- **盲区与代价**：以为自己是周慎的继承人，其实只是他手里一枚随时能弃的棋子。周慎手里有她 2023 年调包的视频。
- **底线**：调包可以，杀人不行。她直到 EP35 前后才隐约知道沈砚之那场火有问题，从此开始害怕。
- **弧线**：
  - EP1–19：一路羞辱、设陷、切割。
  - EP26：第一次私下警告沈知微：「明天别站在他旁边。」
  - EP35–36：塞纸条、在天台上半认罪。
  - EP40：当众用一滴墨揭穿周慎的仿品，随即被周慎反手曝光，入狱。
  - EP51：在看守所里交出周慎私人 X 光机的线索。
- **说话方式**：称呼一律带敬语（「师姐」「陆总」「周老」）。越心虚，句子收尾越轻。

## 顾承泽 · 第一阶段次要对手

- **年龄 / 身份**：30 岁，瀚古拍卖总经理，顾家独子。沈知微的前未婚夫，在她被捕当天开发布会宣布解除婚约。
- **外形识别**：西装扣子永远扣着，紧张时会反复去摸扣子。
- **外在目标**：保住瀚古。瀚古负债八千万，两亿的汝窑是救命稻草。
- **被捍卫的信念**：「我没得选。」
- **惯常策略**：花钱摆平，打电话找人，把脏活交给别人干。
- **盲区与代价**：他只知道自己刷了卡，不知道东西去了哪，也不知道死了人。后来被林晚棠先卖掉，接着被警方带走（EP19）。
- **关键戏**：
  - EP4：带五百万支票来收买沈知微，被她开成了一张当票。
  - EP17：深夜醉酒，说出「卡是我刷的，可柜子打开的时候，里面已经是假的了」。
- **说话方式**：开口先报价钱。

## 周慎 · 终极对手

- **年龄 / 身份**：64 岁。江城鉴定泰斗，鉴定协会名誉会长，瀚古首席顾问，后来创办江城鉴定学院。沈砚之的师兄，沈知微和林晚棠的老师。
- **外形识别**：中式立领，手很稳，总在用一把小刻刀修印章。说话的声音比旁人轻半度，满屋子的人都会安静下来听。
- **外在目标**：让那只汝窑名正言顺归他所有。把一辈子仿出来的东西、换出来的东西，都以「捐赠国家」的名义变成他名下的传世功德。
- **被捍卫的信念**：「真假是人定的。谁的眼睛被信，谁说的就是真。」他手艺天下第一，却只能当一个没有名字的仿家。
- **前史成因**：三十年前在老窑口，是他第一个见到那只汝窑，转手被别人买走。师父说他「手比心快」，把衣钵传给了沈砚之。
- **惯常策略**：永远站在裁判席上，做鉴定人、听证会主席、司法鉴定中心主任。从来不亲手做恶，只给出「处理干净」「门锁上」这样的指令。
- **盲区**：虚荣。他舍不得让自己的得意之作没有名字，所以每一件都留了「丿」。最后一只，他把「丿」刻进了胎里，烧在釉下，以为肉眼永远看不见。
- **筹码**：协会资格的发放权、司法鉴定的话语权、陆氏董事陆振海、马金宝的做旧坊、周屹、林晚棠调包的视频。
- **弧线**：
  - 先是慈父般的师伯：「孩子，回来了。」
  - 然后是那个不肯替她作证的权威：「开片三年会延展，不能认定同一件。」
  - EP28 被她看见收刀的那一挑。从此正面开战，一夜之间切断她所有的路。
  - EP58 X 光照出胎里的「丿」，他抢过真品想摔，被沈知微接住。
- **说话方式**：永远叫她「孩子」「知微」。最狠的话说得最温柔：「你跟你爸一样，看东西太仔细。」

## 秦守义（秦叔） · 盟友

- **年龄 / 身份**：66 岁，城南老当铺「长生当」的掌柜，沈砚之的老朋友。
- **作用**：给沈知微一间阁楼住、一份看柜台的工作，替沈砚之保管了三年的樟木箱。
- **信念**：「当铺只认当票，不认人。」嘴上这么说，那只死当了三年的箱子他一直没卖。
- **代价**：EP21 当铺被纵火，他烧伤住院，保险公司又被周慎的人打点过，拒赔。
- **关键信息**：三个徒弟的名字（EP23）；「你爸当东西那天说要去见个人」（EP32）。

## 秦小满 · 盟友 / 喜剧担当

- **年龄 / 身份**：20 岁，秦叔的孙子，当铺伙计，一心想当鉴宝主播。
- **作用**：用手机直播把沈知微捧成网红「当铺姐」，私人恩怨因此有了公众裁决的场子。他也是沈知微受伤后那双替她上手的手。
- **关键戏**：
  - EP7：他的直播录屏证明那张支票是行贿，不是敲诈。
  - EP24–25：一个人去偷拍马金宝的做旧坊，被扣下。
  - EP38：拍到运输途中调包。
  - EP52–53：被周慎的人扣住，换回来的代价是那张底片。
- **说话方式**：网感重，一张嘴就是「家人们」。真遇到事，第一个冲上去的也是他。

## 周屹 · 隐藏关键人物

- **年龄 / 身份**：34 岁，周慎的养子兼司机，管学院的钥匙。
- **外形识别**：右手背上一大片烧伤疤，常年戴半指手套。
- **真相**：三年前那场火里，他想把沈砚之拖出来，手就是那时烧伤的。他按周慎的话锁了门，也偷偷录下了那通电话。每年沈砚之忌日，他都去墓前放一束白菊。
- **弧线**：
  - 先替周慎做所有脏事：送金缮碗示威、推她下楼梯、调包货箱、在窑里把人锁住。
  - EP43 他偷偷拉开烟道闸板，救了他们。
  - EP44–46 在墓前认罪，交出录音，自首。

## 马金宝 · 中段对手

- **年龄 / 身份**：45 岁，古玩城「马爷」，手腕上缠三串金刚菩提。父亲是当年三个徒弟里的马六。
- **作用**：周慎做旧坊的出货渠道。EP1 被沈知微当场揭穿的二十三号拍品就是他送拍的。
- **关键戏**：
  - EP14–15：赌眼。十件全假，真东西是他自己手里那只茶杯。
  - EP21：指使手下纵火。
  - EP25：扣押小满，被抓。
- **说话方式**：粗，一开口就要赔偿。

## 次要人物

- **郑福生**（55）：瀚古前库管。当年把门卡借给顾承泽，刷卡后一周辞职，躲进马金宝的古玩城做旧。他是「刷卡的是顾总」的目击证人（EP15–16）。
- **陆振海**（58）：陆既明的叔叔，陆氏董事，收过周慎的钱。EP30 联合董事会停了陆既明的职，把汝窑「借展」给学院。
- **吴姨**（50 多岁）：陆宅保姆。儿子在瀚古当保安，顾承泽拿给儿子转正做条件，让她去偷图录（EP3）。
- **韩教授**（60 多岁）：国家文物局鉴定组组长。只认程序，没人收买得了，最后那场公开对鉴由她主持（EP54–59）。
- **沈砚之**（已故）：沈知微的父亲，修复师，人称「江城一双手」。只在闪回、笔记本、金缮碗和合影里出现。
- **陆振山**（已故）：陆既明的父亲。只出现在图录第 88 页那行手写字里：「知微说，这是它的指纹。」

## 关系压力网

```text
                周慎（师伯 / 主谋）
           ┌──────┼──────────┬───────────┐
       控制│    养子│       收钱│        渠道│
        林晚棠   周屹       陆振海       马金宝
     未婚│   （火灾凶手）  （叔叔）    （做旧坊）
        顾承泽                │            │
     前未婚夫│               │          郑福生（库管）
           ▼                  ▼
        沈知微 ◄──── 互相利用 → 并肩 ────► 陆既明
           │
      秦守义 / 秦小满（当铺：庇护与代价）
```

- **沈知微 ↔ 陆既明**：她需要他的上手权、钱和受害者身份；他需要她的眼睛来查父亲的死因。她怕他又一次把她送回去，他怕自己当年真的冤枉了她，更怕她这次又在骗他。他手里压着她的是那份合同和「如有不实」的条款，她手里攥着的是他从没拆开的十一封信。
- **沈知微 ↔ 林晚棠**：曾经是姐妹，也是对手。林晚棠需要沈知微永远是罪人，她自己的位置才坐得住。沈知微需要林晚棠开口，可唯一能证明她那晚在家的人，就是那晚给她下药的人。
- **沈知微 ↔ 周慎**：她把他当成最后一个亲人；他把她当成沈砚之那双眼睛的延续，所以既想留着她，又不得不除掉她。
