# 《老卤》60 集分集大纲（含付费卡点）

## 一、项目定位

| 项 | 设定 |
|---|---|
| 一句话 | 上市庆功宴上被当众离婚的全职主妇，抱走亡父的老卤缸，七天后，前夫公司的味道就没了 |
| 发行假设 | 国内付费短剧，以抖音 / 快手小程序为主，可改投红果等免费平台（付费卡点改作广告解锁点）。竖屏 9:16，真人或 AI 仿真人均可拍 |
| 篇幅 | 60 集 × 60–120 秒 |
| 主引擎 | 离婚逆袭 / 中年重启 |
| 辅引擎 | ① 技能权威（味觉与老卤手艺）负责升级；② 家族企业加师门恩怨，带来情感和悬疑上的新鲜感 |
| 新鲜变量 | 隐藏的大牌不是身份或财富，而是**一口活着的卤缸，以及只有她的手才养得活它**。卤离了她的手，十二个时辰就散；卤母封过之后最多撑七天 |
| 核心不对称 | 资源加能力。全世界都以为值钱的是缸，其实值钱的是人 |
| 季问题 | 沈玉棠能不能夺回父亲的名字"沈记"，而且不靠任何男人，也不变成她最讨厌的那种"走捷径的人"？ |
| 主场景（可复用） | 酒店宴会厅、周家厨房、老街沈记旧铺（烧毁 → 修复）、夜市陈伯面摊、周味总部、医院病房、鼎香总部、墓园、听证室、发布会场 |

**卡点设计原则：**
1. 卡点前一到两集必须先**兑现一笔真爽债**，让观众觉得"已经值了"，然后再开一扇更大的门。不能只靠断在半句话上。
2. 卡点钩子每次都换类型：身份被夺（10）→ 至亲反咬（20）→ 失去底牌加旧案线索（30）→ 新危机（40）→ 真相升级加倒计时（50）。
3. 首充放在第 10 集，前 9 集免费讲完一个完整 micro-arc：离婚 → 七天 → 盲测。观众在付费前已经确认这部剧"真会打脸"。
