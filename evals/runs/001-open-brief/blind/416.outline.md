# 《离婚那天，我只带走了一坛老汤》· 60 集分集大纲（含付费卡点）

## 〇、立项单

| 项 | 内容 |
|---|---|
| 赛道 | 女频·**豪门弃妇/高调离婚逆袭**，叠加"**账本清算式**"恩人反杀变体（钩子母型2），单元B/C 掺入**身份错位**（她其实是老字号姜记传人） |
| 流派 | **情绪流**做主线（情绪契约贯穿，矛盾按单元推进）＋**剧情流**做支线（"1999 年转让书"的真相按信息阶梯一层层揭开） |
| 情绪契约 | **我熬的汤，谁喝了都得认账。** |
| 单元A 执念 | 周家不认她七年的份，要她净身出户，还要扣下女儿 |
| 爽点密度 | 每集至少 1 个小结算（反派为这一集的施压付出看得见的代价），每个回合 1 个大爽点，憋屈和释放大约 2:1 |
| 档位 | **标准档**：每集 90～120 秒，正文 480～850 字，每集场景 ≤2，每集一个回合 |
| 冲突形态 | 以①对话型为主；单元B 中后段加入③身份错位（"姜记到底是谁的"） |
| 节奏型 | 前三集用**递减派**（115→105→100 秒）：场景少、实拍成本低，信息一集比一集密 |
| 合规定位 | 现实题材，二类备案。全剧不靠私刑、不靠暴力，每一次清算都走法院、市场监管、公安、行业评审这些正规渠道；反派作恶不超过 3 集就付出代价；不渲染拜金 |
