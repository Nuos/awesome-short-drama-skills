# 《她妈来了》前置文档 · 基本信息 & 人物小传

## 一、基本信息

```
剧名：《她妈来了》
投流标题（备用）：《豪门保姆竟是丈母娘》《跪着进门的保姆，是少奶奶的亲妈》
类型：女频 · 母女复仇 / 身份反转 / 豪门悬疑
救猫咪类型：麻烦家伙 + 愚者成功（被所有人看不起的乡下保姆，以弱胜强）
体裁：竖屏微短剧（9:16，AI 写实真人风格）
集数：60 集
时长：1–2 min/集
目标平台：抖音 / 红果短剧 / 快手
目标观众：女性 30–55 岁（母亲视角，核心付费人群），兼顾 20–30 岁女性（女儿视角）
开场模式：惨剧闪回开场（一通没接的电话 + 电话里的坠楼声）
```

**故事亮点**：亲妈化名保姆，跪着进了害女儿的豪门——一滴一滴，把女儿从“植物人”里救回来。

**一段话梗概**：
退休护士长周慧兰和女儿林晚断联三年。一个深夜，女儿打来电话，她赌气没接——语音留言里，女儿说"爷爷不是病死的"，随后一声尖叫，是滚下楼梯的闷响。林晚成了"植物人"，豪门婆家以"监护人只认丈夫"为由，把这个乡下亲妈挡在门外。为了救女儿，周慧兰化名"王春花"，跪着进了顾家当护工。她很快发现：女儿的点滴里被加了镇静剂——有人不想让她醒。丈夫要拿监护权吞掉三成股份，婆婆藏着老爷子死亡的秘密，"白月光"秘书想让林晚永远消失。一个被所有人踩在脚下的保姆，用三十年护士生涯练出的本事，一滴一滴把女儿唤醒，再一个一个把凶手送上审判席。

**主题**：门当户对不是钱，是被当成人。/ 妈妈的电话，要接。

**首尾呼应**：
- 开场画面：手机亮着"晚晚"，周慧兰没接。
- 终场画面：手机亮着"晚晚"，周慧兰响第一声就接起。

## 二、主要人物小传

### 女主：周慧兰（化名：王春花）

52 岁，退休 ICU 护士长，现在在青溪县老家守着一个馄饨摊。

**外表**：短发掺着几缕白，用黑色小发卡别在耳后；眼神利，手很稳；常年值夜班留下浅浅的眼袋，笑起来眼角细纹很深。

**性格标签**：#刀子嘴豆腐心 #专业到骨子里 #能忍 #护犊子

**人物经历**：二十多岁就是省城医院 ICU 的"铁娘子"，带出过近两百个护士和规培医生。丈夫是消防员，在林晚三岁那年殉职，她辞掉省城的工作回老家，一个人把女儿拉扯大。三年前，林晚要嫁进江城顾家，她拍桌子反对："他们家门槛高，你进去了，就得跪着走！"母女俩从此断联。她每年给女儿织一件生日毛衣，一件也没寄出去。**核心创伤**：女儿出事那晚的最后一通电话，她没接。

**隐藏身份（剥洋葱式揭露）**：
1. 第一层：她不是保姆，是少奶奶的亲妈。
2. 第二层：她是做了三十年的 ICU 护士长，懂药、懂仪器、懂急救。
3. 第三层：她带出来的"兵"遍布全城各大医院，有人已经当上了科室主任。
4. 第四层：二十年前，她在抢救室救下的心梗病人，正是顾家老爷子顾鸿年。

**原始动力**：保护（救女儿）+ 赎罪（那通没接的电话）。

**人物弧线**：从"要面子、不肯先低头的妈"，变成"肯为女儿跪下、也敢带女儿站起来的妈"；最后学会尊重女儿自己的选择。

**习惯动作**：碰到谁的手腕，两根手指会下意识地搭上去数脉搏——这个职业病两次差点让她暴露。

```
固定服装（潜伏期）：褪色碎花衬衫 + 灰色护工罩衫 + 黑布鞋，头发别黑色小发卡
固定服装（真身期，第44集起）：藏青色针织开衫 + 白衬衫 + 黑色直筒裤，胸前别着挂表
标志性道具：一块银色护士挂表，表背刻着一个"晚"字（林晚十岁时用零花钱找人刻的）
```

### 女二：林晚

26 岁，周慧兰的独生女，顾家少奶奶，原江城某医院护士。

**外表**：鹅蛋脸，眉眼温和，长发；昏迷期面色苍白、颧骨凸出，嘴唇干裂。

**性格标签**：#外柔内刚 #倔 #心软 #有正义感

**人物经历**：嘴上说"我才不要像我妈一样"，最后还是当了护士。在医院照顾过来体检的顾承泽，被他的温柔追求打动，不顾母亲反对闪嫁顾家。婚后被婆婆嫌弃出身，被丈夫冷落，唯一真心待她的是瘫痪在床的爷爷顾鸿年。她发现爷爷的药被人换了，正给三年没联系的妈妈打电话求救时，被人从楼梯上推了下去。

**秘密**：爷爷临终前交给她一枚平安扣，里面藏着银行保险柜的编号，柜里锁着真遗嘱和爷爷的录像——**必须本人到场才能开**。

**原始动力**：活下去 + 回家。

**人物弧线**：从"被动的受害者"到"装睡的同谋"，再到亲自站上股东会说出"我醒了"的人。

```
固定服装：白色病号服（昏迷期）/ 浅蓝色护士服（结局）
标志性道具：脖子上一根红绳系着的白玉平安扣
```

### 男反派：顾承泽

31 岁，顾氏集团总经理，林晚的丈夫。

**外表**：清瘦白净，无框眼镜，头发一丝不乱，说话轻声细语，看着像个好人。

**性格标签**：#体面 #自私 #演技派 #妈宝

**人物经历**：从小活在强势母亲的阴影下，能力平平。爷爷早看穿他守不住家业，把三成股份留给了孙媳林晚。林晚坠楼那晚，他站在楼梯口看了四十分钟，才叫救护车。之后他在网上经营"守护植物人妻子"的深情人设，短视频动辄百万点赞，用来稳住股价，同时向法院申请当林晚的监护人，好名正言顺地吞掉她的股份。

**原始动力**：贪（股份）+ 怕（怕失去母亲的认可）。

```
固定服装：深灰色修身西装 + 白衬衫，无框眼镜
标志性道具：自拍杆 + 环形补光灯；西装内袋里一瓶眼药水（"深情眼泪"的来源）
```

### 女反派：沈曼丽

56 岁，顾家主母，顾承泽的母亲，林晚的婆婆。

**外表**：盘发一丝不苟，红色指甲，常穿酒红或墨绿色旗袍，脖子上永远挂着一串珍珠项链。

**性格标签**：#势利 #控制狂 #好面子 #狠

**人物经历**：小门户出身，靠嫁进顾家翻身，所以比谁都看不起"穷人"。多年挪用集团资金填娘家的窟窿，被老爷子察觉。为了不让老爷子改遗嘱、揭穿自己，她偷偷换了老爷子的药，老爷子半年前"病逝"。林晚坠楼后，她选择帮凶手掩盖，并收买家庭医生给林晚用镇静剂。

**秘密**：老爷子的死是她做的。

**原始动力**：控制（家产与儿子）+ 恐惧（怕被打回原形）。

```
固定服装：酒红色或墨绿色丝绒旗袍 + 珍珠项链 + 珍珠耳钉
标志性道具：一把象牙白团扇，生气时"啪"地合上；她送给白若薇的一条珍珠手链（关键物证）
```

### 女反派：白若薇

28 岁，顾承泽的秘书兼"青梅竹马"，以"帮忙照顾林晚"为名住进顾家。

**外表**：长卷发，白色连衣裙，声音软，一口一个"姐姐"。

**性格标签**：#白莲花 #野心 #嫉妒 #演

**人物经历**：从小喜欢顾承泽，却眼看他娶了一个"小护士"。坠楼那晚，是她戴着沈曼丽送的珍珠手链，伸手推了林晚——手链断了一颗珠子。她和婆婆目标不同：婆婆要林晚"活着当植物人"好吞股份，她要林晚**死**，好让自己当上顾太太。

**秘密**：推林晚下楼的人是她。

**原始动力**：嫉妒 + 上位。

```
固定服装：白色或米色连衣裙，长卷发
标志性道具：粉色手机壳；坠楼前常戴、之后再也不戴的珍珠手链
```

### 男二（盟友 / 感情线）：秦岳

55 岁，顾家园丁，右腿微跛，话少。

**外表**：高大，皮肤黝黑，鬓角花白，常年戴一顶旧草帽，手上全是老茧。

**性格标签**：#沉默 #忠诚 #嘴硬心软 #靠谱

**人物经历**：真实身份是顾鸿年的贴身助理兼司机，跟了老爷子二十年，腿是当年替老爷子挡车祸落下的。老爷子死得蹊跷，他不肯走，自降身份留在顾家当园丁暗中调查。妻子多年前病逝，名字里也有一个"晚"字。一开始把新来的保姆当成婆婆派来的眼线，后来成了周慧兰最可靠的同盟，也是她晚年迟来的那份温柔。

**原始动力**：忠义（替老爷子讨个公道）。

```
固定服装：藏蓝色工装 + 旧草帽 + 劳保胶鞋
标志性道具：一把修枝剪；口袋里一支老爷子留下的旧录音笔
```

**对立核心**：周慧兰（要女儿醒）⟷ 顾家三人（各有理由不想让林晚醒）
- 沈曼丽：要林晚**活着但不醒**——监护权到手才能吞股份；林晚一死，乡下亲妈还要分一份遗产。
- 顾承泽：要林晚**被法院认定为无民事行为能力**——这样他就是监护人。
- 白若薇：要林晚**死**——这样她才能当上顾太太。

三个反派的目标互相冲突，是后半程"狗咬狗"的引信。
