# 《离婚后，婆家招牌菜做不出来了》· 主要人物小传

> 竖屏短剧 ｜ 标准档（每集 90～120 秒）｜ 全剧 60 集 ｜ 女频·大女主事业复仇（厨艺专业碾压）｜ 情绪流
>
> **情绪契约（全剧不变的那口气）**：手艺是我的——谁偷的，谁当着所有人的面还回来。
>
> 具名角色共 10 人（核心 5 人：沈知味 / 顾承宇 / 林振东 / 陆砚 / 林薇薇），其余全部为无名群演或功能位（检测员、评委、老食客、保安、助理），符合「核心 3～5 人、具名 ≤12」的配额。

---

## 一、核心人物

### 1. 沈知味 —— 女主

| 项 | 内容 |
|---|---|
| 年龄 / 外形 | 32 岁。素面，常年挽袖，右手腕一道旧烫疤。 |
| 明面身份 | 顾记酒楼"后厨帮工"、顾家儿媳 |
| 真实身份 | 顾记八年来的真正掌勺；江城老字号「沈记」末代掌柜沈玉茹的外孙女，从小在沈记灶台边长大 |
| 欲望（可拍的） | 让自己的名字回到每一道菜上；把女儿小满接回身边；最终把「沈记」的招牌重新挂起来 |
| 秘密 / 软肋 | ① 右手腕旧伤，连续颠勺半小时就抖——她一直用技巧瞒着，第三幕复发成"底牌失效"；② 外婆留下的手写菜谱缺最后一页，她不知道那页写了什么；③ 小满——所有反派都拿女儿当筹码 |
| 金手指（低理解成本） | 舌头极准：一口汤能尝出加了什么、凉过没有、火候差几分钟。不是系统，不是超能力，是三十年灶台边练出来的 |
| 弧光 | **单元A 被动自证**（"汤是我吊的"）→ **单元B 主动入局**（假意投靠鼎盛当"沈记总厨"，从内部取证）→ **单元C 掌控规则**（手废了也能掌勺：用舌头指挥一整个后厨，立自己的招牌）。终点：从"想要被承认"变成"不需要谁来承认" |
| 语言指纹 | 话短，不骂人；越生气语速越慢；爱用灶上的话打比方——"汤浑了，就得重吊""火候没到""最后一扫，你自己来"。标志动作：拇指抹过刀背上的"沈"字 |
| 记忆点 | 开水白菜的"最后一扫"——一勺鸡茸压下去，浑汤清得像白水。全剧三次关键翻盘都落在这一扫上（第1集留着不扫、第21集当众一扫、第58集左手一扫） |
| 一句话为什么必须存在 | 她是"隐形劳动被署了别人名字"这一共鸣的化身 |

### 2. 顾承宇 —— 前夫 / 单元A 前台反派

| 项 | 内容 |
|---|---|
| 年龄 / 身份 | 35 岁，顾记酒楼老板，对外是"开水白菜传人""江城名厨" |
| 欲望 | 把顾记卖给鼎盛换股份，娶林薇薇进林家 |
| 秘密 | 他根本不会吊汤，连"扫汤"这一步都不知道怎么下勺；顾记账上亏空，急着卖店还债 |
| 弧光 | 体面 → 慌 → 撕破脸 → 被林家收编当"沈记挂名主厨"（单元B，给前妻打下手）→ 被林家当弃子 → 作伪证 → 败露，最后在别家后厨洗碗 |
| 语言指纹 | 体面腔："为你好""顾全大局""别闹"。**心虚就摸袖扣**——这个小动作第 52 集被小满当众点破 |
| 功能位 | 证据阶梯推动者：每次出场都拿出一档新"证据"（协议 → 手写菜谱 → 名厨证书 → 起诉 → 伪证） |

### 3. 林振东 —— 鼎盛餐饮集团董事长 / 终极反派

| 项 | 内容 |
|---|---|
| 年龄 / 身份 | 56 岁，鼎盛餐饮集团董事长，江城最大的餐饮资本 |
| 欲望 | 把江城老字号一家家吞下来做成"标准化品牌"；拿到沈记"头汤"的完整方子 |
| 秘密 | ① 他是沈玉茹当年的大徒弟，因偷方子被逐出师门；② 十年前用"借款+后补转让条款"的套路吞了沈记，转让书正文是事后打印的；③ 他撕走的菜谱最后一页，正面是头汤方子，背面是沈玉茹左手写的"借款不卖招牌"声明和手印——他一直没读懂那几行歪字，因为贪那面方子，一直没舍得毁 |
| 弧光 | 旁观者（尝汤的收购方）→ 单元B 幕后主使 → 单元C 正面终极对手 → 被自己的贪心亲手亮出铁证 |
| 语言指纹 | 笑面，语速慢，讲"规矩"和"标准化"。口头禅："手艺，是要变成钱的。" |
| 一句话为什么必须存在 | 他是"偷手艺"这份恶的源头。顾家偷她的名，他偷整个沈记——换层不换欲 |

### 4. 陆砚 —— 男主 / 助力

| 项 | 内容 |
|---|---|
| 年龄 / 身份 | 34 岁，陆氏餐饮总裁（鼎盛的竞争对手） |
| 欲望 | 找到八年前在市一院门口给他病重的母亲送汤的姑娘。母亲临终前只咽得下那一碗 |
| 秘密 | 他父亲陆鸣是十年前沈记转让书上的见证人，收过林振东的钱。陆砚查到后买下了要被拆的沈记老楼，原样保住老灶，却一直不敢告诉她 |
| 弧光 | 沉默食客（每天来喝第一碗）→ 关键证人（第10集行车记录仪）→ 借门不借灶 → 第43集身份被揭、信任崩塌 → 第50集自曝家丑交出原始录像，还沈家清白 |
| 语言指纹 | 话少，只问不答，句末从不带语气词。"这汤，谁做的。""明早，第一碗。" |
| 设计原则 | **他不替女主赢**。他只提供"门"和"证据"，灶前的每一次翻盘都是沈知味自己完成的 |

### 5. 林薇薇 —— 林振东之女 / 舆论施压者 → 反转棋子

| 项 | 内容 |
|---|---|
| 年龄 / 身份 | 27 岁，美食网红"薇薇吃遍江城"，顾承宇的新欢；单元B 任鼎盛"沈记"品牌主理人 |
| 欲望 | 证明自己不是靠爹 |
| 秘密 | 鼎盛"沈记"料包线是她负责的；她用沈知味的电子签章倒签了"料包研发确认单" |
| 弧光 | 直播造谣（单元A）→ 架空总厨、甩锅（单元B）→ 被父亲当众推出去顶罪（第41集）→ 当场反手播放父亲语音（第42集）→ 单元C 带着账本倒戈、投案自首 |
| 语言指纹 | 直播腔"家人们"，甜嗓转刻薄只要半秒；永远把手机镜头怼到别人脸上 |

## 二、关键配角

### 6. 周桂芬 —— 婆婆

58 岁，市井刻薄。口头禅："吃我们顾家的饭""一个外人"。
**秘密**：当年是她看中沈知味是沈记的外孙女，才撺掇儿子娶她——"娶回来的是一双手"。
**功能**：单元A 前台施压（扔帽、搜身、烧刀、砸招牌、教小满说谎）。结局不被羞辱，只是端着空碗来讨一碗汤——打脸留给主要反派，不践踏已经失势的人。

### 7. 秦师傅（秦德厚）—— 老厨工 / 反转棋子

61 岁，顾记烧火的老厨工，其实是当年沈记的学徒，看着沈知味长大。
**软肋**：孙子在鼎盛实习，被顾承宇拿来要挟。
**弧光**：沉默 → 被逼当众作伪证（第17集）→ 擂台上解下围裙倒戈（第21集）→ 单元B 去鼎盛中央厨房卧底 → 单元C 带着孙子一起站上金灶宴。
**语言指纹**：叫她"知味"，叫沈玉茹"老掌柜"；话说一半就咽回去。

### 8. 唐小棠 —— 闺蜜 / 律师

31 岁，社区律所律师，把亡父留下的小饭馆借给沈知味开"知味小馆"。
**功能**：所有"程序"上的反驳都由她落地——抚养权变更、公证、调取签章日志、当场比对手印。保证女主每次赢都**有法律逻辑**，不是靠一张嘴。
**语言指纹**：快、直、带术语，"证据链""先公证"。

### 9. 小满 —— 女儿 / 情感锚点

6 岁，爱画画，把妈妈做的每道菜都画下来。
**功能**：痛点来源（被拽走、被教着说"爸爸做的汤"、被同学叫"骗子的女儿"）和情绪释放口（第17集手表语音、第22集扑进妈妈怀里、第60集踩着小板凳完成"最后一扫"）。
**合规**：涉及未成年人的情节只写被大人利用的"后果"与反派被惩罚，不渲染伤害。

### 10. 王伯 —— 王记面馆老板 / 单元C 群像代表

67 岁，江城老字号王记的老板，第44集在鼎盛收购签约台上手抖。
**功能**：揭开林振东"借款+后补转让"的通用套路，让单元C 从"沈家一家的冤"升级为"一城老字号的账"。高潮集只带他一个具名，其余老字号老板做群演。
